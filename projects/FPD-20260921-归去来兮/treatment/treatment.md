## COMPLETE TREATMENT

[ASSUMED] 影片从“归”这个看似简单的动作进入。开始时，“归”只是离开眼前的位置、回到熟悉地方的意思，整体感受轻盈而有召唤力。叙述不先介绍朝代和人物履历，而是先提出一种共同处境：有些人一生向前追逐，有些人却会在某个瞬间突然明白，自己真正想去的方向是回去。

[RESEARCHED + ASSUMED] 张翰首先出现。他身处洛阳与齐王冏府中的仕途位置，名爵仍有继续上升的可能；秋风却唤起他对吴中菰菜、莼羹和鲈鱼脍的记忆。影片不把这一刻处理成单纯嘴馋，而让故乡的具体滋味与官场中抽象的名爵形成反差。他选择离开，兑现“人生贵在适志”的判断。随后只交代足以改变观众理解的信息：齐王冏不久败亡，时人认为张翰有见机之明。这个结果不被解释成张翰预知未来，而是让他的归去同时具有乡思、适志和远离风险的多重意味。至此，“归”仍是一件来得及做、也真正做成了的事。

[RESEARCHED + ASSUMED] 张翰的轻盈转身把问题交给陶渊明：如果归去意味着放弃维持生活的现实位置，人是否仍会选择回去？陶渊明不是从天然超脱开始，而是因家贫和家庭需要进入仕途。他得到官职，却逐渐确认自己的本性与这种生活相违。《归去来兮辞并序》提供的不是一时赌气，而是求仕、违己、早有归意、家事触发和最终离任共同组成的选择。Treatment 不裁定督邮与程氏妹去世哪一个才是“唯一原因”，而让观众理解他已经长期站在归与不归之间。最终，他不再让精神被现实身份役使，接受离开职位之后的清贫与不便，以“归去来兮”确认自己的方向。经过这一段，“归”不再只是思乡，而变成即使有代价，也要回到本性的主动决定。

[RESEARCHED + ASSUMED] 当观众已经把“归去”理解为一种洒脱和清醒时，王献之使这个理解突然变重。影片先让他以世人熟悉的身份存在：年少有盛名，书法成就显著，后来尚新安公主并位至显职。外部看来，他的人生不断向上，没有理由回头。故事不重演未经证实的离婚过程，也不替郗氏、新安公主或王献之虚构私下言行，只让公开成就与最后的私人自陈相遇。病重之际，在需要回顾一生过失时，他没有谈功名和书法，只留下传世记载中的那件事——仍记得与郗家离婚。此时“归”第一次失去行动可能：张翰可以回乡，陶渊明可以归田，王献之想回到的却是一段已经被时间关闭的关系。

[ASSUMED] 结尾不把三人评判为谁更高洁，也不声称王献之的一生只剩爱情遗憾。三种“归”在同一命题下并置：有人听见秋风便回去了，有人付出代价才回到自己，有人拥有名望与位置，却直到最后才说出再也回不去的地方。影片最后把问题留给观众——最难的或许不是离开，而是在尚能回去的时候，能否认出自己的归处。结束状态不是悲剧高潮，而是对时间的克制警醒；“归去来兮”也由一句潇洒的文学表达，变成关于选择、代价和来不来得及的人生命题。

## NARRATIVE SEQUENCE MAP

### Sequence 1｜“归”作为共同问题

- **Start State｜起始状态：** 观众尚未认识三个人物，把“归”理解为普通的返回。
- **Process / Action｜过程或行动：** 叙述提出人在不断向前时，也可能突然发现真正方向是回去。
- **Choice / Response｜选择或反应：** 不给答案，先让张翰成为第一个回应者。
- **Consequence｜后果：** 建立统一立意，避免后续三段成为人物简介拼盘。
- **Information Change｜信息变化：** “归”被提示为一种人生选择，而不仅是空间移动。
- **Emotional Movement｜情绪运动：** 好奇 → 轻微向往。
- **Provenance｜来源：** [LOCKED] 用户立意；[ASSUMED] 创作连接。

### Sequence 2｜张翰：看见归路便转身

- **Start State｜起始状态：** 张翰身在洛阳仕途中，名爵仍有吸引力。
- **Process / Action｜过程或行动：** 秋风唤起吴中食物与故乡记忆，适志与羁宦形成冲突。
- **Choice / Response｜选择或反应：** 他选择离开并归乡。
- **Consequence｜后果：** 他完成了现实中的“归”；齐王冏随后败亡，使这一选择又获得见机避险的历史回声。
- **Information Change｜信息变化：** 观众从“因乡味归去”进一步理解到“主动放下名爵”。
- **Emotional Movement｜情绪运动：** 轻盈 → 洒脱 → 一点清醒。
- **Provenance｜来源：** [RESEARCHED] CLM-001, CLM-002；[ASSUMED] 信息压缩与连接。

### Sequence 3｜陶渊明：为了归去承受代价

- **Start State｜起始状态：** 陶渊明因家贫与家庭需要进入仕途，并非天然与现实无关。
- **Process / Action｜过程或行动：** 官职缓解生计，却加深本性与现实身份的冲突；归意逐渐成为无法回避的选择。
- **Choice / Response｜选择或反应：** 他最终离任归田，用《归去来兮辞》确认自己的决定。
- **Consequence｜后果：** 他重新获得与本性一致的生活，也接受清贫和不便继续存在。
- **Information Change｜信息变化：** 观众意识到“归”不是漂亮姿态，而是有实际代价的自我选择。
- **Emotional Movement｜情绪运动：** 清醒 → 犹疑的重量 → 释然。
- **Provenance｜来源：** [RESEARCHED] CLM-003, CLM-004；[ASSUMED] 不裁定唯一触发原因的叙事组织。

### Sequence 4｜王献之：明白时已经不能归

- **Start State｜起始状态：** 王献之以盛名、书法和显贵身份出现在观众认知中。
- **Process / Action｜过程或行动：** 公开成就不断累积，直到临终自陈把被遮蔽的私人遗憾显露出来。
- **Choice / Response｜选择或反应：** 他承认始终记得与郗家离婚；不虚构进一步补救行动。
- **Consequence｜后果：** “归”从仍可选择的行动变成再也无法实现的愿望。
- **Information Change｜信息变化：** 观众对“圆满显贵人生”的初始判断被重新解释。
- **Emotional Movement｜情绪运动：** 稳定 → 意外停顿 → 克制的失落。
- **Provenance｜来源：** [RESEARCHED] CLM-005, CLM-006, CLM-007；[ASSUMED] 公开成就与私人自陈的并置。

### Sequence 5｜归处与时间

- **Start State｜起始状态：** 三种“归”已经形成能归、选择归与不能归的差别。
- **Process / Action｜过程或行动：** 叙述把差别从人物轶事提升为“是否认得归处、是否还来得及”的共同问题。
- **Choice / Response｜选择或反应：** 不给人物排名或道德答案，把问题交还给观众。
- **Consequence｜后果：** 短片在本片内完成认知闭合，同时保留余味。
- **Information Change｜信息变化：** “归去来兮”的含义从归田扩展为对所有归处的追问。
- **Emotional Movement｜情绪运动：** 失落 → 回望 → 克制警醒。
- **Provenance｜来源：** [LOCKED] 用户立意；[ASSUMED] 本项目原创收束。

## CHARACTER PROGRESSION

- **张翰：** 从仍在名爵路径中的人，变为在秋风触发下主动离开的人；其结束位置是“尚能归，也敢于归”。[RESEARCHED + ASSUMED]
- **陶渊明：** 从为生计进入仕途的人，变为承认本性不可长期违背并承担归田代价的人；其结束位置是“以选择完成归”。[RESEARCHED + ASSUMED]
- **王献之：** 从公开认知中的盛名与显贵人物，变为显露私人遗憾的人；不是安排传统人物弧，而是改变观众对其人生的理解。[RESEARCHED + ASSUMED]
- **叙述声音：** 从提出“归向何处”，发展到发现“是否来得及”，最终不作裁决。[ASSUMED]

## INFORMATION & CAUSALITY MAP

- 先让观众知道张翰的乡思与选择，再补充齐王冏败亡，使“归乡”从感性冲动增加清醒含义。
- 再让观众知道陶渊明因贫求仕，才能使归田具有代价；如果先把他呈现成天然隐士，选择便失去重量。
- 王献之段必须先建立公开成就，再出现临终自陈；若提前解释离婚悲剧，核心认知反差会消失。
- 三段的因果不互相连接，连接的是观众对“归”的理解：可行动 → 有代价的行动 → 已无行动可能。

## WORLD / RULE USE

- 三位人物分属西晋至东晋的不同时间与空间，不制造同时发生或互相影响的错觉。
- “归”是叙事关联原则，不是历史上三人共同提出的概念体系。
- 文学原文、史书转述与创作旁白在剧本阶段必须具有可识别的来源层级。
- 诗意意象负责传递感受，不能被当作证明人物动机的历史证据。

## GROUNDING & RECONSTRUCTION MAP

- **Sequence 1：** 用户锁定的立意与原创连接，无新增历史事实。
- **Sequence 2：** 秋风、吴中食物、适志、归乡与齐王冏败亡来自 CLM-001、CLM-002；人物连续动作与情绪停顿属于重构。
- **Sequence 3：** 因贫求仕、本性冲突、归意、离任与《归去来兮辞》来自 CLM-003、CLM-004；不裁决不同文本中的唯一直接诱因。
- **Sequence 4：** 王献之盛名、书法身份、尚公主与临终忆离婚来自 CLM-005、CLM-006；离婚幕后原因保持 CLM-007 的争议状态。
- **Sequence 5：** “尚能回去时认出归处”是本项目原创立意收束，不冒充古人结论。

## PRODUCTION FEASIBILITY

- **Duration Allocation｜时长分配：** [ASSUMED] 开题 6–8 秒；张翰 14–17 秒；陶渊明 20–24 秒；王献之 24–28 秒；收束 8–10 秒。总时长约 72–87 秒，后续剧本可在 60–90 秒范围内微调。
- **Character Load｜角色负担：** 3位核心历史人物；其他人物不承担完整叙事功能，避免增加面貌与关系连续性负担。
- **Location Load｜地点负担：** 三个人物各需一组“外部身份所在”与一组“归处或缺席归处”的概念空间；Treatment 不指定具体场景数量。
- **Time Span｜时间跨度：** 跨西晋至东晋，并在王献之段压缩较长人生跨度；必须用人物身份和意象区分，不能伪装成连续时间。
- **Complex Action｜复杂行动：** 无战争、群体运动或复杂动作；主要变化来自离开、返回、书写、停顿和信息揭示等低复杂度行为。
- **Continuity Risks｜连续性风险：** 三张核心人物面貌、各自年龄阶段、服装时代和书写物件容易混淆；王献之若同时出现青年与病重阶段，需要明确年龄连续性。
- **Reusable Asset Candidates｜潜在复用资产：** “归”字、风声、水路、门与墨迹可作为叙事连接资产；不得用完全相同的空间和服饰把三人视觉同质化。

## DECISION REGISTER

### LOCKED

- 单支 60–90 秒独立短片。
- 张翰、陶渊明、王献之三人，以“归”为共同立意。
- 允许艺术加工，但关键事实、人物关系、历史结果和有出处原文保持边界。
- 影片必须有主旨，不做人物资料拼接。

### OPEN

- 最终旁白全文与结尾原句。
- 三人的具体文字引用及字幕密度。
- 最终时长、平台与画幅。

### ASSUMED

- 成片目标约 75–85 秒。
- 顺序为张翰 → 陶渊明 → 王献之。
- 篇幅由短到长，情绪由轻到重。
- 使用“归乡—归田—归情不得”完成统一递进。
