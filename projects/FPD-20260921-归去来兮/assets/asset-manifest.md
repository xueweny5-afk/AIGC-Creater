## BLOCKING DECISIONS

1. **GEN-GATE-001｜呈现媒介：** 用户已确认“写实历史电影质感、克制诗意”，并于 2026-09-22 接受三张 v2 人物面貌。后续侧背与状态必须从 v2 主参考派生，不得重新随机设计。
2. **HIS-GATE-001｜服饰证据：** 已建立 `assets/costumes/costume-evidence-brief.md`，可支持宽衫大袖、博带、官员冠帻与私居幅巾等方向；具体冠高、冠式、腰间制度物和官阶色彩仍未逐件定案，因此三张 v2 的衣着只是时代特征候选，不是正式服装批准。
3. **ID-GATE-001｜基础面貌：** 史料不能提供三人的可靠写实肖像。实际生成时应创建原创、非特定真人的面貌候选，由用户从低戏剧性的身份参考中选择主参考；不得把后世画像当本人写真。
4. **ID-GATE-002｜人物区分：** 用户复核确认 CHR-001 v1 与 CHR-002 v1 面貌、须发和轮廓过近。v2 必须同时改变脸部几何、体态、须发和身份服装轮廓，不能只换颜色。
5. **VIEW-GATE-001｜三视图：** 已从用户批准的 v2 主参考派生正、左侧、背面三视图。自审确认三人的体态、须发和面部主锚点没有明显互换；服饰结构可供后续制作参考，但冠式仍是研究推定，须经用户视觉复核后才能升为 APPROVED。
6. **STATE-GATE-001｜状态对照：** 用户已于 2026-09-22 接受三视图。三人的三阶段状态板已从批准资产派生；张翰初版归途衣物因过度破旧被内部否决并返工。当前状态板等待用户复核，不进入镜头生成。
7. **STATE-GATE-002｜用户决定：** 用户于 2026-09-22 接受三组状态对照板。三位核心人物资产升级为 APPROVED；冠巾服制仍保留研究推定标记，不对外宣称精确复原。
8. **LOC-GATE-001｜西晋官署：** 用户于 2026-09-22 接受 v1 空间板的功能拓扑；建筑细部仍为汉晋范围推定，不宣传为西晋齐王府精确复原。
9. **LOC-GATE-002｜南归舟船：** v1 因拱形篷造成后世化风险被拒绝；用户于 2026-09-22 接受移除篷体后的 v2 开放式人力木舟方向。
10. **PRP-GATE-001｜印信：** 用户于 2026-09-22 接受 v1 铜印的尺度、鼻钮、系带和握持方向；角色对应官职与印文未知，底面继续保持不可读。
11. **LOC-GATE-003｜彭泽工作间：** v1 的工作案、门口与俯视拓扑可支持 S003；家具和建筑细节仅为东晋小型地方工作空间候选，等待用户确认。
12. **LOC-GATE-004｜陶宅归径：** v1 的门、门槛、窄径、行囊落点和儿童等待位可读；松菊与住宅形制均为克制艺术加工，等待用户确认。
13. **PRP-GATE-002｜文书与家书：** 晋代纸本传统支持纸作为材料范围，但不能证明陶渊明具体家书形制。用户于 2026-09-22 明确允许真实可读的创作书法与大胆艺术加工；v2 家书使用原创道具文字“家中粗安、兒常候門、願君早歸”，须标注为电影创作而非史料引文或陶渊明真迹。
14. **LOC-GATE-005｜王献之书斋：** 用户手动生成的 v1 正反与俯视关系基本一致，书案、公文、水盆和出口可支持 S005；建筑及家具只作为东晋高门空间的低断言候选。
15. **LOC-GATE-006｜王献之病榻空间：** 用户手动生成的 v1 能区分病榻、现用书写区、独立旧砚和沿墙守候区；夜间灯源可解释，无道教奇观。空间细节仍属创作重构。
16. **PRP-GATE-003｜盛年书写组：** v1 的工具、新墨、横向长纸和双端托举逻辑成立；纸面字迹只批准为书写密度与运动参考，未经逐字校对不得用于停留近景。
17. **PRP-GATE-004｜临终书写组：** v1 能区分湿润现用砚与干涸旧砚，悬笔手势可用；章表文字未可靠呈现锁定标题“上章首過”，正式近景前必须另做校字版。
18. **B3-APPROVAL｜用户决定：** 用户于 2026-09-23 接受 LOC-005、LOC-006、PRP-003、PRP-004 的功能、材料和视觉方向。四项升级为 APPROVED；批准不包含纸面文字逐字准确性，任何停留近景仍须单独校字。
19. **B2-APPROVAL｜用户决定：** 用户在审阅 B2 后仅对书法边界提出调整，并于创作书法版提交后明确确认“可以”。LOC-003、LOC-004 与 PRP-002 v2 的功能、材料和视觉方向于 2026-09-23 正式收口为 APPROVED；家书文字属于电影原创层。
20. **CST-GATE-001｜张翰服装：** 自动生成后已定向降低在职冠体高度，并修复归途衣摆的破损感；三状态身份和穿脱连续性通过自审。具体一梁冠形制仍为研究推定。
21. **CST-GATE-002｜陶渊明服装：** 自动生成后已降低县令状态冠体高度；三状态保持同一人物和基础衣层，归家状态不贫困化。县令冠式与日常衣层比例仍为研究推定。
22. **CST-GATE-003｜王献之服装：** 自动生成后已降低正式公职冠体高度；书写、公职、病中三状态连续，绛服、墨绶与玉佩方向可读。两梁冠、绶带与玉佩的精确制度形态仍为研究推定。
23. **CST-APPROVAL｜用户决定：** 用户于 2026-09-23 确认三张服装状态板“没问题”。CST-001、CST-002、CST-003 升级为 APPROVED；批准范围是电影视觉、人物辨识和状态穿脱逻辑，不等同于晋代冠服制度的精确考古复原。
