## DIRECTOR THESIS

- **Audience Endpoint：** 观众最终理解的不是“三位晋人都想回去”，而是“归去需要在仍有行动权时认出自己的归处”；张翰尚能转身，陶渊明愿意承担代价，王献之已经失去行动可能。
- **Directing Path：** 让“归”的变化通过人物与职务物、门槛和可通行空间的关系完成：张翰交还后立即跨出；陶渊明先把未完秩序收束，再走回仍需生活的家；王献之从能在书斋与官职之间移动，缩减为只能卧榻回答。
- **Anti-default Decision：** 不把三人统一导演成洒脱名士，不让风、慢动作或伤感表情替人物作决定。三段的行为重心依次为“交还并离开”“承担后离开”“已无法离开”。

## CONTINUITY CONTRACT

- 三人属于不同年代与地点，不使用共同辅助人物、同一显眼空间或相同职务物制造连续事件错觉。
- 张翰的官印/职务物在 S001 交出后不得在 S002 回到他身上；其归途状态采用已批准的减层服装。
- 陶渊明的官印和未完文书留在 S003；S004 只携简单行囊。归家后衣物可有使用褶皱，不得出现撕裂、乞者化或无忧仙化。
- 王献之 S005 与 S006 必须保持同一骨相、发际线和须发关系；病重只改变软组织、肤色、体力和服层。
- S005 的新墨与 S006 的干涸旧砚承担不同功能；道士现用笔砚必须与旧砚分开。
- 风的作用逐段减弱：S001 推动衣袖和叶，S002 推动水面，S004 只轻动草木，S006 只影响灯焰；不得成为超自然预兆。
- 可见古代文字可作为大胆的电影创作层使用，但必须区分“可靠引文”和“原创道具文字”。原创家书允许清晰可读，需另行校对并不得冒充史料原件或人物真迹。

## SCENE DESIGNS

### S001｜洛阳官署庭院·秋日

- **Source Range：** `screenplay.fountain` S001 全场
- **Direct Cause：** 秋风使张翰正在履行的官署秩序与“适志”发生可见冲突。
- **Scene Function：** 建立“归”是可执行的选择；让张翰以交还和离开，而非解释性回忆，完成第一种转身。
- **Entry State：** 张翰衣冠完整，仍持官牒并占据工作位置；属吏和往来官吏默认他会继续履职；职务物仍归他控制。
- **Character Objectives：** 张翰要结束当前职务关系并离开，不把决定变成协商；属吏要接住突然转交的职务物并确认秩序是否仍能运作。
- **Obstacle / Pressure：** 官牒仍在手、属吏仍按日常流程行动、名爵路径仍然开放；张翰的决定没有外部仪式替他完成。
- **Initial Tactics：** 张翰先停止阅读，把官牒端正归位，以完成手头责任而不是摔弃；属吏依惯例靠近，等待下一项指示。
- **Shift Trigger / New Tactics：** 秋风打断纸面和衣袖的静止；张翰不再继续处理，改为解下并交出职务物，以不可逆动作结束关系。属吏从等待指示转为双手承接。
- **Performance Actions：** 张翰确认官牒位置、松手、解下、递交、说完原句后直接越过出入口；属吏先要确认，再因物件已到手而守在原位，不追问、不阻拦。
- **Blocking & Spatial Power：** 工作案是制度控制点，出入口是张翰唯一需要跨越的边界。张翰开始时在案与廊柱形成的工作范围内；交还发生在该范围边缘；属吏接过物件后留在制度一侧，张翰单独越过门槛。其他官吏继续原有路线，显示空间并未因一人离开而停摆。
- **Audience Beat：** 先看见一个仍属于秩序的人，再看见他不用争执便退出；轻盈来自行动清楚，不来自狂喜。
- **Information Design：** 观众知道张翰主动辞归；张翰知道自己的选择；属吏只知道决定已发生；齐王冏后来的败亡此时必须隐藏。
- **Sound / Silence / Time：** 脚步、纸张、衣料和短促秋风构成场内节奏。张翰放回官牒时让文书声短暂停止；台词说完后不安排回应，保留他离开与属吏停住之间的一段空白。整场行动连续，不用反复犹豫延长决定。
- **Required Assets / State Changes：** CHR-001 在职→离任；CST-001；LOC-001；PRP-001；GRP-001；FX-001。职务物从张翰控制转为属吏控制。
- **Must Show / Withhold / Avoid：** 必须显示官牒归位、职务物被接住、张翰跨出；隐藏政治结局；避免摔印、怒斥、仰天大笑、散发敞衣和众人跪拦。
- **Turn / Exit State：** 张翰已不再属于官署；空间秩序仍运行，属吏持有其交还物。
- **Next-scene Trigger：** “离开职位”必须在 S002 变成真实距离和不可逆行程。

### S002｜南归水路·日

- **Source Range：** `screenplay.fountain` S002 全场
- **Direct Cause：** S001 的离开需要被证明不是姿态，而是已经进入南归行程。
- **Scene Function：** 完成张翰的现实归乡，并用后来的政治结果重新加重他的选择，但不把他写成预知者。
- **Entry State：** 张翰已离职，穿减层行旅服；简单行囊随船；洛阳官署与职务物均已退出其可及范围。
- **Character Objectives：** 张翰只需继续向吴中移动，不再解释或证明决定；船上功能人物只维持航行，不参与主题表达。
- **Obstacle / Pressure：** 距离和行程尚未完成；观众可能仍把前场理解成一时乡思。
- **Initial Tactics：** 张翰保持身体朝向水路去向，让船的持续移动承担“没有返回”的事实。
- **Shift Trigger / New Tactics：** 一片被风带来的叶子进入他的可及范围；他短暂接住后放入水中，不收藏、不追逐，让其顺流离开。
- **Performance Actions：** 接住、看清、放下；随后把注意重新交给前方水路。动作不承担神秘预兆，只确认他已接受流动。
- **Blocking & Spatial Power：** 小舟的去向固定，行囊靠近人物但不遮挡身体；张翰处于能接触水面、又不妨碍航行的位置。岸线与船保持方向关系，不能让船像停在无方向的风景中。
- **Audience Beat：** 从“他敢走”变成“他真的走了”；旁白补充齐王败亡后，观众才意识到这次归去还避开了政治风险。
- **Information Design：** 观众在本场后半才知道齐王败亡和时人“见机”的解释；不得让张翰提前表现出知道结局；他的真实动机保持多义。
- **Sound / Silence / Time：** 水声、船体轻响和风声替代官署脚步。旁白说到“也许”时环境声不停止，以声音继续流动拒绝定论。时间允许压缩旅途，但必须保留船持续前进这一状态。
- **Required Assets / State Changes：** CHR-001 归途状态；LOC-002；经核验的小型行旅船；简单行囊；FX-001。
- **Must Show / Withhold / Avoid：** 必须显示方向明确的水路、已离职状态和叶随流远去；隐藏具体航线断言；避免吴中美食宴席、旅游式水乡、预知灾祸的神情和豪华画舫。
- **Turn / Exit State：** 张翰成为“尚能归且已经归去”的人，第一层主题闭合。
- **Next-scene Trigger：** 观众已看到轻盈的归乡，S003 必须提出更现实的问题：若归去会失去生计，是否仍然离开。

### S003｜彭泽县衙·黄昏

- **Source Range：** `screenplay.fountain` S003 全场
- **Direct Cause：** 张翰的归去相对轻盈，需要由陶渊明的生计和长期归意增加代价。
- **Scene Function：** 让陶渊明先完成手中秩序，再以留下官印和拒绝冠带完成离任；同时保留督邮、家事和长期归意之间的证据边界。
- **Entry State：** 陶渊明独处工作案；公务未完、旧家书已被多次阅读；官印仍代表其县令身份；县吏带冠带停在门口。
- **Character Objectives：** 陶渊明要把当前公务停在可交接状态，然后离开；县吏要让他按制度准备或至少承认冠带要求。
- **Obstacle / Pressure：** 未完公务、官印、冠带和家书同时把责任、生计、礼制与归意拉在一起；没有单一物件可以替他决定。
- **Initial Tactics：** 陶渊明继续完成眼前步骤，整理并合上文书，不以冲动中断工作；县吏保持在门口，用等待而不是逼迫施加制度压力。
- **Shift Trigger / New Tactics：** 陶渊明看见冠带，又看见门外天色已暗；他停止继续处理，改为将官印端正置于案中央，以位置变化声明交还。
- **Performance Actions：** 合上、对齐、放置、起身、经过门口而不接冠带；县吏略作让路，仍捧着冠带，不追赶、不劝说。
- **Blocking & Spatial Power：** 工作案控制官印、文书和家书；门口由县吏和冠带占据，形成制度边界。陶渊明必须从案后起身、绕开工作面、经过县吏才能离开。县吏不能主动进入案后，也不能把冠带塞给他。
- **Audience Beat：** 观众先感到他不是天然隐士，而是正在承担工作与生计的人；因此离开才有重量。
- **Information Design：** 观众知道他因生计入仕、归意早已存在、督邮之事亦见于传记；必须隐藏“唯一直接原因”的裁决。家书以原创书法“家中粗安、兒常候門、願君早歸”强化家庭等待，但不宣称史料出处。
- **Sound / Silence / Time：** 文书摩擦、印落案面的实声和门外晚间环境构成节奏。县吏不说话，沉默意味着等待他接受制度动作；陶渊明经过时不安排解释。黄昏压缩可用时间，但不做倒计时威胁。
- **Required Assets / State Changes：** CHR-002 彭泽令→离任；CST-002；LOC-003；PRP-001；PRP-002；GRP-001。
- **Must Show / Withhold / Avoid：** 必须显示未完公务、旧家书、官印端正留下、冠带未被接走；可短暂读到家书原创文字，但隐藏唯一辞官诱因；避免摔印、撕文书、县吏跪求、督邮正面冲突和“五斗米”戏剧化复述。
- **Turn / Exit State：** 陶渊明离开官职，但失去收入和未来生活压力没有消失；县吏、冠带、官印留在制度空间。
- **Next-scene Trigger：** S004 必须显示他返回的是仍需重新生活的家，而不是抽象自由。

### S004｜陶渊明居所与荒径·清晨

- **Source Range：** `screenplay.fountain` S004 全场
- **Direct Cause：** S003 的离任只有在真实归处和现实代价中才能完成意义。
- **Scene Function：** 兑现《归去来兮辞》的归家意象，把“归田”定义为重新进入家庭和生活，而非逃离现实。
- **Entry State：** 陶渊明结束行旅，携简单行囊来到欠维护但仍有人居住的家门；孩子在门内外可相认的范围等待。
- **Character Objectives：** 陶渊明要重新进入家庭空间；孩子要确认来人并缩短距离，不承担安慰成人的任务。
- **Obstacle / Pressure：** 荒径、欠维护院落和行囊提醒观众，归家并未消除生计问题；门仍需由他亲手推开。
- **Initial Tactics：** 陶渊明沿窄径接近，把注意放在家门和等待者；孩子先确认身份，再离开等待位置。
- **Shift Trigger / New Tactics：** 孩子向他跑来；陶渊明先放下行囊，降低身体高度接住，随后与孩子共同朝门移动。
- **Performance Actions：** 放下、俯身、承接、牵住、推门；孩子跑近、停入怀抱、跟随。拥抱不延长为治愈性表演。
- **Blocking & Spatial Power：** 窄径连接外部行旅与家门；孩子从居住一侧越过短距离迎接，陶渊明在门槛外先放下行囊，再与孩子共同进入。松、菊、荒草服务路径和生活状态，不封堵行动。
- **Audience Beat：** 归家带来身体松脱，但观众同时看到荒径和有限生活条件；释然与代价并存。
- **Information Design：** 观众知道他完成了归田，并通过作品原句听见其自我确认；不得把清晨、孩子或菊解释成此后无忧的保证。
- **Sound / Silence / Time：** 脚步擦过草、行囊落地、衣料和木门构成场内声音；孩子不必呼喊姓名。原文声音出现时保留生活声，不让文学文本把现实空间抹平。
- **Required Assets / State Changes：** CHR-002 归家状态；儿童功能人物；LOC-004；简单行囊；家门；FX-001。
- **Must Show / Withhold / Avoid：** 必须显示荒径、居住痕迹、行囊先被放下、人物共同进门；隐藏未来生活是否顺遂；避免金色仙境、花海、满院丰收、白发隐士、酒壶和孩子承担“治愈父亲”的表演。
- **Turn / Exit State：** 陶渊明完成第二种归：回到家庭和本性，但代价仍可见。
- **Next-scene Trigger：** 当观众已相信“只要选择便能归”，S005 必须先建立一个看似无需回头的圆满公共人生，为最后反转准备。

### S005｜王献之书斋与公职过渡空间·日

- **Source Range：** `screenplay.fountain` S005 全场
- **Direct Cause：** 前两人主动离开公共身份，王献之必须先以公共成就不断向前，形成不同方向。
- **Scene Function：** 建立书法盛名与中书令身份同时成立的公开人生；让观众暂时把他理解为完整、稳定、持续向前的人。
- **Entry State：** 王献之处于盛年书写状态；长卷尚在工作面，门生等待接手；公文与门外侍者提示下一项公共职责。
- **Character Objectives：** 王献之要完成当前书写并无损地交给门生，再整理为可进入公职空间的状态；门生要安全接过长卷；侍者要等待他完成转换。
- **Obstacle / Pressure：** 私人创作与公共职责争夺同一段时间，但本场不把两者写成冲突或痛苦来源。
- **Initial Tactics：** 王献之完成最后一笔并等待墨迹稳定；门生保持距离，不提前触碰；侍者留在门外，不打断。
- **Shift Trigger / New Tactics：** 门生可靠地托起长卷，工作面被清空；王献之由书写者转换为任官者，洗去指间墨色并整理外层衣冠。
- **Performance Actions：** 收笔、确认墨迹、允许接手、清洁手指、整理、离开；门生共同托举并移向收存位置；侍者在王献之接近时让出通道。
- **Blocking & Spatial Power：** 书案是私人技艺中心，公文区与门外是公共职责方向。王献之开始时控制书案，门生只能在获得允许后进入工作边界；交接完成后，他主动离开书案并走向出口。侍者始终不侵入书写区。
- **Audience Beat：** 观众看见才华、秩序和显位彼此配合，形成“此人一直向前且人生圆满”的暂时判断。
- **Information Design：** 观众知道其书法声名和官职；王献之只处理眼前事务；婚姻、离婚和临终遗憾必须完全隐藏，不能用信物、女性剪影或异常停顿预告。
- **Sound / Silence / Time：** 笔离开承载物、墨水与清水、织物整理、长卷被托起的细声建立专注。门外等待不以催促声制造焦虑。让书写结束与公共身份开始之间有一次明确的声音转换，但不加入胜利性宣告。
- **Required Assets / State Changes：** CHR-003 盛年书写→公开任官；CST-003；LOC-005；PRP-003；GRP-002。
- **Must Show / Withhold / Avoid：** 必须显示新墨、门生接手、洗去指间墨色、公共职责在门外等待；隐藏婚姻信息；避免发光书法、夸张长指、悬空纸张、复制传世法帖、满室收藏和皇室奢华。
- **Turn / Exit State：** 王献之离开书写工作面，走向公共身份；观众形成关于成功人生的稳定初判。
- **Next-scene Trigger：** S006 以“多年以后”撤去公共成就和行动能力，只留下他必须回答的问题。

### S006｜王献之宅内病榻空间·夜

- **Source Range：** `screenplay.fountain` S006 全场至 FADE OUT
- **Direct Cause：** S005 建立的公开圆满需要被史载临终自陈重新解释；时间已让“归”失去行动路径。
- **Scene Function：** 让王献之以极短回答公开不可挽回的私人遗憾，并把三种“归”收束为“是否还来得及”的问题。
- **Entry State：** 多年以后，王献之病重卧榻、行动范围极小；家人守候但不主导；道士控制现用章表与笔；干涸旧砚位于王献之能看见但无法借其改变过去的位置。
- **Character Objectives：** 道士要完成仪式记录，获得可写下的回答；王献之要只说自己愿意留下的事实，不展开解释；家人要维持守候，不替他说话。
- **Obstacle / Pressure：** 道士的问题要求回顾一生，但任何回答都不能恢复过去；王献之体力有限，公开身份和书法成就都不能代替这次回答。
- **Initial Tactics：** 道士展开章表、提笔并等待；王献之不看章表，把注意移向干涸旧砚，以沉默控制回答的范围；家人停止小动作，给出等待空间。
- **Shift Trigger / New Tactics：** 道士问出“平生可有过失”；长停顿后，王献之不列功过、不解释原因，只说史载原句。道士从准备记录转为笔悬未落。
- **Performance Actions：** 道士展开、询问、提笔、停住；王献之转移视线、维持呼吸、选择极短回答、停止继续说；家人保持原位，不靠近、不哭喊、不接话。
- **Blocking & Spatial Power：** 病榻限定王献之身体范围，却保留他对回答的控制；道士位于章表书写处，与旧砚保持物理区分；家人在较暗的守候区域，不包围病榻。没有人物越过王献之的沉默去解释。
- **Audience Beat：** 先等待一个临终总结，随后发现他绕开功名，只留下“与郗家离婚”；惊讶之后不是哭诉，而是笔未落和无人接话造成的不可逆停顿。
- **Information Design：** 观众此时第一次知道离婚是他临终仍记之事；只能据此理解“仍有遗憾”，不能推断完整爱情史、责任归属或一生唯一评价。郗氏和新安公主保持不出现。
- **Sound / Silence / Time：** 夜间底声、病中呼吸、纸张展开和灯焰细响足够支撑场内。问题之后延长无动作等待；原句后取消所有人的语言回应，让笔尖、呼吸和灯焰承担时间。结尾旁白进入后，场内声音逐步减少，但不以骤然神秘化处理。
- **Required Assets / State Changes：** CHR-003 病重状态；CST-003；LOC-006；PRP-004；GRP-002；FX-001。
- **Must Show / Withhold / Avoid：** 必须显示同脸病体、章表与旧砚分开、道士笔悬未落、回答后的集体静止；隐藏离婚过程和女性形象；避免闪回、爱情信物、灸足传说、道教奇观、家人号哭、恐怖病容和把灯灭解释成死亡特效。
- **Turn / Exit State：** 王献之最想返回之处只剩语言，行动可能已经关闭；观众被迫重新理解前两人的及时转身。
- **Next-scene Trigger：** 无后续剧情场；叙述者把“那里还在不在”交还观众，影片结束。
