# ASSET REQUIREMENTS

## PROJECT

- **Project ID：** FPD-20260921-归去来兮
- **Visual Bible Version：** v1
- **Scope：** 60–90 秒独立短片；只列连续性所需资产，不含生成提示词、画面调度或分镜任务。

## ASSET LIST

### CHR-001｜张翰身份资产

- **Type：** CHARACTER
- **Narrative Function：** 建立“仍在仕途但能够转身归去”的成年西晋士人。
- **Required Views / States：** 中性身份参考；在职整衣状态；离任后合理减层的行旅状态；同一面貌一致性核对。
- **Locked Features：** 成年男性；身份端正而非帝王贵胄；两种状态保持同一体貌；不以散发敞衣代表自由。
- **Variable Features：** 具体年龄感、体型、面部细节、服装颜色。
- **Evidence Status：** RESEARCH-INFERRED + OPEN
- **Continuity Risk：** 与陶渊明、王献之变成同一“宽袍文人”；官服串代。
- **Priority：** P0
- **Approval Gate：** 人物轮廓与服装层级经史料来源核对；与另两人并排可辨且无夸张标签。

### CHR-002｜陶渊明身份资产

- **Type：** CHARACTER
- **Narrative Function：** 在“彭泽令”与“归家者”之间保持同一人物，并让归田保留现实代价。
- **Required Views / States：** 中性身份参考；县令状态；归家行旅状态；生活状态磨损说明。
- **Locked Features：** 约四十岁上下的成年感；同一面貌；官职状态不奢华；归家状态不蓬头垢面、不仙化。
- **Variable Features：** 体型、须发程度、日常衣色、行囊形式。
- **Evidence Status：** DOCUMENTED AGE RANGE + RESEARCH-INFERRED + OPEN
- **Continuity Risk：** 被做成固定“采菊隐士”符号；两种服装状态像不同人物。
- **Priority：** P0
- **Approval Gate：** 同脸连续性成立；县令与归家身份一眼可分；贫困表达不过度。

### CHR-003｜王献之身份与年龄连续性资产

- **Type：** CHARACTER
- **Narrative Function：** 支撑“盛名显位”到“病重临终”的观众认知转折。
- **Required Views / States：** 盛年中性身份参考；书写状态；任官外层状态；病重末期状态；盛年/末期骨相对照。
- **Locked Features：** 眉眼、鼻口、骨相、惯用手在年龄变化中一致；不使用发光墨迹或夸张天才姿态；病重不改变身份识别。
- **Variable Features：** 盛年年龄感、病体程度、须发变化、服装层数。
- **Evidence Status：** DOCUMENTED IDENTITY + CREATIVE APPEARANCE
- **Continuity Risk：** 年龄变化导致换脸；误把后世王献之画像当可靠写生。
- **Priority：** P0
- **Approval Gate：** 先批准基础面貌，再批准衰老/病体；任何图像史料须标注时代与可信度。

### GRP-001｜官署与县衙功能人物组

- **Type：** GROUP
- **Narrative Function：** 显示张翰与陶渊明身处制度空间，并支持交还、送达、等待等功能。
- **Required Views / States：** 属吏/县吏类别参考；站立、持文书或冠带的功能状态。
- **Locked Features：** 不抢主角辨识；不使用同一显眼面孔跨地点复用；身份层级低于核心人物。
- **Variable Features：** 人数、年龄、衣色、具体职责分配。
- **Evidence Status：** RESEARCH-INFERRED + ASSUMED
- **Continuity Risk：** 辅助角色过多；服饰与核心人物层级混乱。
- **Priority：** P1
- **Approval Gate：** 先通过服饰制度范围，再决定最小人数。

### GRP-002｜王献之段功能人物组

- **Type：** GROUP
- **Narrative Function：** 门生和侍者建立其公开位置；家人与道士支持临终仪式。
- **Required Views / States：** 门生/侍者类别；家人暗处状态；道士书写章表状态。
- **Locked Features：** 克制、功能性；不替王献之表演情绪；家人与道士不做奇观化造型。
- **Variable Features：** 人数、年龄、位置关系、服装次级色。
- **Evidence Status：** DOCUMENTED FUNCTION + RESEARCH-INFERRED APPEARANCE
- **Continuity Risk：** 道教仪式被幻想化；群体反应喧宾夺主。
- **Priority：** P1
- **Approval Gate：** 仪式行为与服饰分别核验；删去无叙事功能成员。

### CST-001｜西晋官署服饰范围

- **Type：** COSTUME
- **Narrative Function：** 区分张翰在职身份与离任状态。
- **Required Views / States：** 在职完整层级；合理减层的行旅层级；冠帽、腰间物件和鞋履证据页。
- **Locked Features：** 不用后世影视通用袍服直接替代；不以敞胸散发表现名士。
- **Variable Features：** 颜色、织物、纹样、冠帽具体形式。
- **Evidence Status：** OPEN / RESEARCH-INFERRED
- **Continuity Risk：** 东晋、西晋或唐宋样式混用。
- **Priority：** P0
- **Approval Gate：** 至少两类可靠来源交叉支持；无法确定部分明确标为创作。

### CST-002｜东晋末县令与日常服饰范围

- **Type：** COSTUME
- **Narrative Function：** 支撑陶渊明由任职到归家的身份变化。
- **Required Views / States：** 县令工作层级；离任行旅层级；归家日常层级；磨损位置说明。
- **Locked Features：** 状态差异来自层级和使用痕迹，不来自人物突然“野化”。
- **Variable Features：** 冠帽、色彩、织物、行囊与鞋履。
- **Evidence Status：** OPEN / RESEARCH-INFERRED
- **Continuity Risk：** 把后世文人像当陶渊明写真；贫困符号化。
- **Priority：** P0
- **Approval Gate：** 服制研究通过，且三种状态可连续转换。

### CST-003｜东晋高门士人、公职与病中服饰范围

- **Type：** COSTUME
- **Narrative Function：** 建立王献之公开地位，并让末期服装变化服从病体而非身份消失。
- **Required Views / States：** 书写内层；任官外层；病中轻简层；三状态转换表。
- **Locked Features：** 盛年不堆砌皇室奢华；病中不穿现代化白色寝衣；同一身份材料关系延续。
- **Variable Features：** 冠帽、纹样、衣色、外层数量。
- **Evidence Status：** OPEN / RESEARCH-INFERRED
- **Continuity Risk：** 明清文人书斋造型；公主婚姻被直接转译成帝王服饰。
- **Priority：** P0
- **Approval Gate：** 身份等级与时代范围分别核验；未证实纹样不得锁定。

### LOC-001｜洛阳官署工作空间

- **Type：** LOCATION
- **Narrative Function：** 让张翰处于有序、可继续升迁也可主动退出的制度环境。
- **Required Views / States：** 可用空间结构参考；工作案、文书区、出入口关系；人物离开前后状态。
- **Locked Features：** 空间尺度克制；行动路径清楚；不建宏大宫殿；不声称齐王府精确复原。
- **Variable Features：** 梁柱、墙面、门窗、陈设数量。
- **Evidence Status：** UNKNOWN + CREATIVE
- **Continuity Risk：** 唐宋官署或影视宫殿化；空间无法支持交还与离开。
- **Priority：** P0
- **Approval Gate：** 先批准功能拓扑，再批准历史外观；不确定处有标注。

### LOC-002｜南归水路环境

- **Type：** LOCATION
- **Narrative Function：** 证明张翰已经进入真实归途，并打开第一段空间感。
- **Required Views / States：** 水路与岸线关系；秋季状态；船与上下船位置关系。
- **Locked Features：** 不出现可识别的错误现代地标或后世园林；方向可读。
- **Variable Features：** 天气、岸植被、船型、远方聚落密度。
- **Evidence Status：** RESEARCH-INFERRED + OPEN
- **Continuity Risk：** 船型串代；水乡被做成明清旅游画面。
- **Priority：** P0
- **Approval Gate：** 船型与区域环境另行核验后批准。

### LOC-003｜彭泽县衙工作空间

- **Narrative Function：** 承载陶渊明在生计与本性之间的现实位置。
- **Required Views / States：** 工作案与门口关系；官印、文书、家书位置；黄昏使用状态。

- **Priority：** P0

### LOC-004｜陶渊明居所与荒径

- **Required Views / States：** 家门、窄径、院落关系；荒草、松、菊位置；清晨居住状态。

- **Priority：** P0
- **Approval Gate：** 每项植物和陈设说明其文本或生活功能；删除纯装饰物。

### LOC-006｜王献之病榻空间

- **Type：** LOCATION
- **Narrative Function：** 让公开成就退去，只留下不可逆的私人陈述。
- **Required Views / States：** 病榻、灯、章表书写处、家人位置、干涸砚台的空间关系；夜间使用状态。

- **Priority：** P0

### PRP-001｜官职交还物与印信组

- **Type：** PROP
- **Narrative Function：** 让张翰和陶渊明的离任成为可见行动，而不是抽象旁白。
- **Required Views / States：** 张翰职务物件候选；陶渊明官印；在手、置案、交还/留下状态。
- **Locked Features：** 两人物物件不默认相同；功能先于装饰；不使用未经核验的现代仿古官印。
- **Variable Features：** 材质、尺寸、系带、收纳方式。
- **Evidence Status：** UNKNOWN / RESEARCH-INFERRED
- **Continuity Risk：** 造型串代；把象征物误当历史确定物。
- **Priority：** P0
- **Approval Gate：** 每件物品需有制度或考古依据；无可靠结论时简化而非细造。

### PRP-002｜陶渊明文书与旧家书组

- **Type：** PROP
- **Narrative Function：** 并置未完公务与家庭牵引。
- **Required Views / States：** 待处理文书；折旧家书；合上、置放、携带关系。
- **Locked Features：** 家书可使用明确标注为电影创作的原创书法，不冒充陶渊明真迹；折旧来自使用，不做藏宝图式污渍。
- **Variable Features：** 文字可见度与笔势、折痕、纸张/简牍最终方案。
- **Evidence Status：** CREATIVE + OPEN MATERIAL
- **Continuity Risk：** 原创文字未标注而被误解为史料原件；载体串代；生成图中的次要文字字形不稳定。
- **Priority：** P0
- **Approval Gate：** 载体和书写方式审查；可见文字另行校对。

### PRP-003｜王献之书写工具与长卷

- **Type：** PROP
- **Narrative Function：** 建立其书法家身份，并为“仍可书写”与“不能重写关系”提供物质基础。
- **Required Views / States：** 笔、墨、砚、书写承载物；新墨状态；长卷被托起状态；工具收置状态。
- **Locked Features：** 不复制《中秋帖》等传世法帖文本、装裱、收藏印章和破损；长卷为功能性重构。
- **Variable Features：** 具体材质、尺寸、文字清晰度、工具数量。
- **Evidence Status：** DOCUMENTED TRADITION + CREATIVE OBJECT
- **Continuity Risk：** 古摹本被误当原件；明清文房清供化。
- **Priority：** P0
- **Approval Gate：** 晋代书写材料研究通过；可见文字通过来源与版权/真实性审核。

### PRP-004｜临终章表、现用笔砚与干涸旧砚

- **Type：** PROP
- **Narrative Function：** 支持道士记录与王献之停顿；以“可写/已干”区分仪式当下和不可逆过去。
- **Required Views / States：** 展开章表；悬笔状态；现用墨；独立的干涸旧砚。
- **Locked Features：** 两套书写状态不可混淆；旧砚不刻入虚构爱情信物信息。
- **Variable Features：** 砚形、章表尺寸、旧砚磨损。
- **Evidence Status：** DOCUMENTED FUNCTION + CREATIVE MOTIF
- **Continuity Risk：** 道具逻辑矛盾；旧砚被误读为史实遗物。
- **Priority：** P0
- **Approval Gate：** 仪式实用性和创作隐喻分别标注并通过。

### GRF-001｜“归”主题图形系统

- **Type：** GRAPHIC
- **Narrative Function：** 统一三段并让“归”的含义发生变化。
- **Required Views / States：** 片头/段落/结尾使用层级；可靠引文、史书转述、创作旁白三类文字样式区分。
- **Locked Features：** 明确属于当代影片叙事层；不伪称张翰、陶渊明或王献之手迹；引文保留准确出处。
- **Variable Features：** 字体来源、排版、出现次数、是否只保留结尾一次。
- **Evidence Status：** CREATIVE
- **Continuity Risk：** 当代图形与剧中实物混淆；使用王献之风格造成错误署名。
- **Priority：** P0
- **Approval Gate：** 来源层级一眼可辨；字体授权与历史暗示均无风险。

### FX-001｜风、水、草木与灯焰状态组

- **Type：** EFFECT STATE
- **Narrative Function：** 以可变化的自然与材料状态连接三种“归”。
- **Required Views / States：** 秋风对衣物/纸/叶的影响；水面流动；荒草、松、菊的轻微风态；灯焰自然波动。
- **Locked Features：** 所有变化服从真实环境；不作为超自然征兆；不同段落强度克制。
- **Variable Features：** 风力、波纹、植被密度、灯焰幅度。
- **Evidence Status：** CREATIVE + PHYSICALLY GROUNDED
- **Continuity Risk：** 特效抢戏；用统一慢动作制造虚假诗意。
- **Priority：** P1
- **Approval Gate：** 状态能说明环境且不替人物表达心理。

## DEFERRED / NOT REQUIRED

- 郗氏与新安公主的正面人物资产：V1 剧本不要求出场，创建会增加未经证实的关系表演风险。
- 三位人物完整生平、多年龄成长资产：短片只需当前叙事状态。
- 齐王冏、督邮、王羲之的独立人物资产：仅属背景信息，不承担可见行动。
- 吴中食物宴席资产：当前剧本不需要，避免短片转为美食展示。
- 宏大洛阳城、建康城或宫殿群：不服务当前行动，且考据成本过高。
- 具体传世法帖复刻：禁止作为剧中原件使用。
- 郗氏爱情信物、灸足、离婚现场：缺少可靠依据且越过人物系统边界。
