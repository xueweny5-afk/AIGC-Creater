# U02｜江南烟雨组画｜单元简报 v2
2026-10-20；沿用FPD-20261018-晴天未完。[原简报](project-brief-u02.md)保留历史。
USER_FACT：多组镜头体现，二楼上、小道漫步、河畔，每个3秒，组成古代江南烟雨风景如画的感觉。
推荐暂名《行入烟雨》，为标题提案，不因改名另建项目。
继承LOCKED：诗情画意优先，古代江南春雨，中式美学；仅文字交付到视频生成前。
本轮ASSUMED：五镜×3秒＝15秒，16:9；前三种观看位置来自用户，增加廊下望亭与石桥远景收束为创作提案。
情感：从楼上望见江南，到身在雨巷与河畔，最后将自己留在画里。
Form：诗性观察蒙太奇；每镜为独立观看位置，不暗示摄影机连续飞行或证明空间相邻。
人物：保留主观体验，无出镜主角、手脚或近景路人；不加入人物剧情。
Execution：Seedream逐镜首帧，Seedance 2.5逐镜单首帧；3秒是最终剪辑长度，生成入口按实际可选时长适配，必要时取较长镜头中稳定的3秒。不承诺平台支持直接生成3秒。
交接：[五镜内容包](delivery/jiangnan-rain-montage-handoff.md)。资产/画面/动态/顺序节奏待媒体，不以文字标生产Gate通过。
