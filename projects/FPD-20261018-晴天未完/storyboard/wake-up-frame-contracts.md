# 草地初醒首尾Frame合同补充｜v3.0

来源：[方向回执](../direction/wake-up-revision.md)、[Visual](../visual-development/wake-up-look-state.md)；PLANNED / CONTENT_ONLY。

F01 START：刚睁开后第一眼看近草，身体侧躺的低视点；中间几片草清楚，左缘树干作空间锚点，天空未成主体，不入画人物/杯。
F02 END：同一位置头部已转向上方，大部分蓝天白云、同一树冠边缘、局部树隙光。摄影机朝向确实不同，不能再要求两帧裁切/投影位置相同。
始终保持同树种、草地、光源方向、色彩与身体落点；角度变化需要资产/构图确认，首尾静态不证明树干→树冠→天空的中间连续性。
两帧所需Composition Guide均PLANNED；实际图与获准用途NONE。首帧选“刚睁开后的可见草地”，不以纯黑图当空间依据；初醒感由短暂柔焦恢复表达，不必生成字面眼球/睫毛。
尾帧编辑需改变观看朝向而保持场景身份，超出普通局部光效修改；若入口难以派生正确上方空间，应先核验场景结构，不让模型编造陌生地点。
