# U03｜镜头串联提案与剧本登记 v1

来源：[单元定义与精简Treatment](../project-brief-u03.md)、[剧本主稿](../screenplay/heartbeat-montage-v1.fountain)。2026-10-25。SHOT EXPLORATION，全部为未获用户批准的文字提案。

## 观看顺序

| 段落与估时 | 镜头探索 | 触发—回应与结尾保留 |
|---|---|---|
| S001 / 0—4秒 | 双人中景起，冰棒轻碰时靠动作切近；吃第一口仍能看出两人 | 拆开包装→发现他在等→女生主动轻碰→同时吃；不能只拍食物 |
| S002 / 4—9秒 | 已取叶子的手与头发进入画面，再到双人近景 | 取下叶子→女生转头→接叶→笑；不增加叶子落下的铺垫镜头 |
| S003 / 9—15秒 | 保留床单侧边与两人所在区域的双人中景，连续观察 | 风掀开→相对停顿→落下→男生挪向侧边，发现女生已经在等；留侧边空间，不能穿布或瞬移 |
| S004 / 15—19秒 | 女生将要系完时进入，双人侧面中景 | 男生停步→回头→女生起身跟上→并肩；不完整演一遍系鞋带 |
| S005 / 19—24秒 | 群体中景随朋友散开，保留两人；回头回应后再收尾 | 男生看→女生回头→停住→他走近→她留位置；结束在回应发生后 |

时间为ESTIMATED分配，按进入时已有动作、部分动作可重叠推估；未做Animatic或实际播放，不保证24秒完成。若节奏拥挤，优先删一个片段，不把所有反应加速。每段可包含一至两个镜头，不把“一场”等同“一镜”。

## 串联与声音

跨场采用清楚的场景切换，承接人物关注与回应，不声称空间相连。不必五次机械卡音乐重拍。用便利店门铃、叶子轻响、布料风声、自行车轮声、合照后人声区分环境；音乐为可选后续提案，不承担解释关系的任务。

人物身份与关系连续；服装允许随不同日子变化，后续视觉阶段再定。环境可由日光过渡到日落前，但只是编排，不锁同一天的时间线。S005增加少量成年朋友，待资产与群体生成验证。

## 剧本登记与自检

- Identity / Coverage：U03独立探索单元，S001—S005正文COMPLETE；五段内容均ASSUMED，尚无批准Treatment，不作正式下游放行。
- Continuity：同一对成年人；不同日子无需跨场携带冰棒、叶子或衣物；男生推车仅S004；天台布料上沿固定，下摆受风，人物绕侧边而非穿过布料。
- Scene Function：S001女生主动回应等待；S002关注细节获得回应；S003环境促成偶遇后双方主动寻找；S004察觉落后而停步；S005女生回头与男生走近构成双向行动。
- Dialogue / Voice：无对白、无旁白；只保留自然环境声，不用字幕说明“他喜欢她”。
- Grounding：原创虚构提案，无现实人物与历史重建；参考仅作软性情绪与视觉参考。
- Production Load：两名主要成年人物，五处空间，末段少量朋友。难点为床单遮挡连续性、取叶手部接触、跨场身份稳定及24秒内反应可读性，尚未实测。
- SELF-AUDIT：五段均有触发与回应，结尾从被看见发展到主动回应；两次等待分别落在共享第一口与并肩行走，仍有重复风险，用户若觉松散可优先删S004。未做独立冷读、成片节奏与模型可行性验证。
- Decision / Next：等待用户评价故事组合及感受；方法只作候选假设，不修改公共流程或创建固定技能。后续继续时先回写用户决定，再按流程补齐正式上游与视觉等阶段。
