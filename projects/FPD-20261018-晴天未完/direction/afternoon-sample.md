## 创作主稿

**情感命题：** 独处时不用赶往任何地方，可以被窗外的一阵风暂时吸引。这次只验证舒展、惬意、略带梦感的观看体验。

**故事：** 晴朗夏日下午，一位成年女性坐在开着的窗边看书。风将白纱帘轻轻吹向室内，窗外的绿地露得更完整。她注意到纱帘的变化，停下阅读，慢慢抬眼望向窗外。风变小，纱帘落回窗侧；她仍安静看着外面。

**人物：** C01，约25—30岁，黑色及肩发、米白棉质短袖、浅灰长裤，神情放松。人物外观为提案，不沿用参考视频人物、校服或身份。道具P01：浅米色无可读文字封面的书，全程摊开放在腿上，双手轻扶，不翻页、不合书。

**场景：** LOC01，普通住宅的简洁房间，浅奶白墙、浅木地板、木椅、一扇侧开的窗。摄影机从室内斜看窗边，人物在画面左侧中景；右侧前景是一幅白色纱帘，下摆接近地面；窗外是邻近绿地和蓝天，不指定真实地点。窗扇不变化，窗外不增加人物或车辆。

**开始与结尾：** 开始人物低头看书，纱帘垂在窗侧；结尾人物保持坐姿望向窗外，书仍在腿上，帘子已回落。没有反转、告白或额外象征物。

## 视觉与光线

- LOOK01 v0.1：PHYSICAL，摄影写实基础，轻微理想化的柔和呈现；无非物理变化。蓝天、自然绿、奶白和浅木色共存，肤色保留正常暖意。
- LIGHT01 v0.1：夏日下午侧向日光由窗外进入，室内白墙提供柔和反射填充；窗边地板有一小片偏暖日光，人物脸部受光柔和。窗外和室内均需保留可读细节，不能通过整体过曝制造梦感。
- AIR01 v0.1：空气清透，无可见雾、烟、漂浮尘粒。开窗来风是纱帘运动的来源，主要推动帘子下半部向室内摆动。
- 质地：纱帘可见织纹和透光层次，棉衣、木地板可辨；亮边轻柔，人物不失焦。
- 本样例从原视频迁移的是明亮环境、色块关系与轻动作；换用新的室内空间和事件。原视频不作为身份、场景或精确构图输入。

## 镜头与运动探索 SH01 v0.1

建议横版16:9，目标约12秒，为创作目标，不是已核实的平台参数。单镜头，室内斜向环境中景，人物与窗外环境同时可读，不追求极浅景深。

| 目标时间 | 发生的事情 | 注意与保持 |
|---|---|---|
| 0—3秒 | 人物低头看书，帘子只有很轻的摆动 | 先看清房间与窗外；不翻页，手与书保持接触 |
| 3—6秒 | 来风使帘子下半部向室内缓慢鼓起，窗外绿地显露更多 | MAIN：纱帘；摄影机开始沿原视线缓慢靠近，不绕行、不变焦 |
| 6—9秒 | 人物先停下阅读，随后缓慢抬眼望向窗外，头部只有小幅转动 | MAIN：视线回应；SUPPORT：帘子缓慢回落；不强制微笑 |
| 9—12秒 | 摄影机停下；帘子落回窗侧，人物继续望着窗外 | 最后约3秒保留安静停留，不突然切黑或出现片尾字 |

- 摄影机：只做一次短距离缓慢前移，因帘子露出窗外而靠近；维持斜向关系，不越过纱帘或改变主体左右位置。
- MAIN / SUPPORT / HOLD：注意力由纱帘转交人物视线；环境和布料提供支持；人物坐姿、双手、书本、椅子、窗框和光照状态保持。
- 回应链：阅读 → 风吹帘、绿地显露 → 短暂停顿 → 视线抬向窗外 → 保持观看。
- 声音意图：轻风、细微布料声与很远的鸟鸣，无对白；首版建议先不加音乐。声音交后期安排，不假设目标模型能生成同步音轨。
