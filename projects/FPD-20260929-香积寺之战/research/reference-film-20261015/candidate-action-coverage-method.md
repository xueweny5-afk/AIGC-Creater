# 候选方法：按动作阶段组织覆盖镜头

- Method ID：MTH-action-phase-coverage
- 版本 / 状态：V0.1 / CANDIDATE
- 来源：[MST-20261015-xiangjisi-action-coverage](filmmaking-method-study.md)
- 验证：成片视觉采样观察；无本项目真实Pilot、生成参数或完整QC。不构成已验证专项Skill。

## 核心机制与适用范围

把复杂事件拆成观众能理解的动作阶段：准备或判断→可见触发→主要行动→接触或改变→后果。为不同阶段选择合适景别，用物件状态、动作方向、视线与角色响应把镜头连接起来。

这不是固定五镜公式。剧本已交代的准备无需重拍，持续行动可以保留更长；必要因果不能以快速切镜省略。机制适用于战争、劳动、救援等复杂行动，不绑定题材。

## 控制与保护

- 可控制：每镜唯一信息、静态时刻、主动作边界、切点、反应覆盖、近中远尺度职责、状态交接和QC要求。
- 必须保护：项目剧本、人物选择、结果、历史研究、资产身份、真实空间、时段与光向、受伤/退出的不可逆状态。
- 可变：角色、道具、地点、具体镜数、景别、节奏、影调、生成模型。
- 不得用剪辑掩盖手部、武器、人马穿模；不可把“短镜头一定成功”或“这样一定更便宜”写成保证。

## 工作方式

1. 先写事件的开始状态、改变它的触发与必须留下的结果。
2. 列出观众必须看见的信息，分配MAIN、SUPPORT、HOLD对象。
3. 每个Clip只指定一个主动作，复杂动作按有意义阶段划分；不机械增镜。
4. 静态图只表现当前阶段的一个瞬间；运动设计记录进入、改变、退出。
5. 相邻镜头记录人物、持物手、兵器、方向、接触、损伤与人数状态。必要反应镜头要看得出反应对象。
6. 从单镜真实性与顺序可读性两层验收。

## 阶段接口

| 阶段 | 方法贡献 | 不能代替 |
|---|---|---|
| Scene / Shot | 动作因果、镜头职责与反应覆盖 | 剧本调度、选择、空间证据 |
| Storyboard | 各动作阶段可读的静态瞬间 | 资产身份、连续性批准 |
| Motion | 单一主动作与可连接的起止状态 | 未定义的身体接触和空间 |
| Prompt / Generation | 紧凑表达、参考职责、分段执行意图 | 模型能力核验与生成授权 |
| QC / Post | 看得懂的因果、动作连接、不可逆状态 | 原始画面错误与Picture Lock |

## 最小Pilot假设

| 失败假设 | 测试与保持不变 | 通过证据 | 失败回退 |
|---|---|---|---|
| 复杂多人动作即使分段仍不可读 | 相同人物、衣甲、地点、光向；只比较同一事件的动作边界与覆盖方式 | 顺序观看能说清谁改变了什么，关键接触可见，没有状态跳回 | Shot / Motion |
| 切镜后兵器或身份变化 | 相同资产与状态；不同视点的相邻两段 | 人物、持物手、道具、伤势与退出人数保持 | Asset / Prompt / Generation |
| 反应镜头只有表情，没有对象 | 同一人物、事件与状态；检查视线投影和对象覆盖 | 能明确指出看见什么后作出反应，未靠字幕补因果 | Scene / Shot |

真实执行需记录确切输入、模型版本/入口、Prompt、参数、Take、切点与完整播放QC。不以本参考成片直接代替测试结果。

## 原创性与归档

不包含原片人物造型、台词、音乐、专属字幕或独特完整镜头组合。Raw Media Included：NO。保持为项目内候选；只有用户明确采用并建立范围回执后才影响制作字段。
