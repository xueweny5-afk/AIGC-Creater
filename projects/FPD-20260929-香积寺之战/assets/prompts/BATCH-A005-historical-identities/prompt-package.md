# BATCH-A005 HISTORICAL IDENTITIES PROMPT PACKAGE

## Rule

郭子仪与仆固怀恩均为真实历史人物，但具体面貌未知。本批为制作需要的非肖像式重构，只锁定个体身份和体态，不宣称复原真实长相。

## CHAR-GUOZIYI-001

成熟至年长的东亚男性职业将领，精瘦耐久、沉着观察、自然不对称和真实年龄纹理，灰黑头发实用收束，短而克制的灰黑胡须。正面平视、中性表情、灰色无缝背景、均匀校准光、低饱和历史写实。只穿深灰褐交领内层。

Negative：帝王、金冠、龙纹、金甲、白发神仙、飘逸长须、高台演说、明星脸、影视角色、盔甲、兵器、旗号、战场和戏剧光。

## CHAR-PUGU-001

成熟边地骑将，个体化面貌、紧凑耐久体态、警觉但克制的目光，实用收束发式和短胡茬。正面平视、中性身份摄影、灰色无缝背景、均匀校准光、低饱和历史写实。只穿灰褐骑乘内层。

Negative：族群脸谱、野蛮化、夸张皮草羽饰、兽牙、纹面、现代民族服装拼贴、孤骑英雄、幻想骑装、明星脸、马匹、盔甲、武器、战场和戏剧光。

## Body Identity Derivation

- Preserve：批准正脸的五官、发际、耳形、年龄、肤色和胡须。
- Guo：稳定、精瘦耐久、自然年龄与重量分布。
- Pugu：紧凑耐久、髋腿适合长期骑乘但不健美化。
- Common negative：正式甲胄、武器、马匹、英雄姿态、多人、文字、拼贴、手脚错误。
