# 03｜军队群体资产

群体图均为静态组织参考，不要求一次图里完成连续动作。每个状态独立出图；先锁人数、站位、标志物，再只改变该状态允许的动作与损耗。文件存入 `assets/groups/<Asset ID>/`。

## GROUP-TANG-FRONT-001｜唐前军与三名同列

输入：`lineup-six-soldiers-v002.png` 只供身份索引；A/B/C 各自正侧面优先；主角脸 V2；前军衣甲；B 型刀中间候选。主提示词：`同一支唐军前军六人群体，低饱和深铁甲与灰褐布衣，真实身高和面孔差异、双手持同家族 B 型长刀。剧本阵位固定：A 在主角左侧且解剖左护耳始终缺失；B 在主角右侧且解剖右前臂灰褐旧布始终保留；C 瘦高，在主角后排，持有独特浅赭缠线与小缺口的 B 型刀。六人合照原索引不是剧情阵位。战场制作坐标右侧是东翼。无半跪固定三排阵、无克隆脸、无关刀。`

| 本次变化 | 建议文件名 |
|---|---|
| T0 完整：六人加远处少量轮廓，主角、A、B、C 的关系一眼可读，清洁空气。 | `state-t0-complete-v001.png` |
| T1 失散：同一批人因追击/反压被人流隔开，只变间距，不凭空新增人物；三标志仍在各自人身上。 | `state-t1-separated-v001.png` |
| T2 重组：从失散回身，同向长刀和肩距逐渐恢复；A、B、C 都还在。 | `state-t2-regroup-v001.png` |

| T4 战后空位：与 T0 同机位同地表锚点，主角在，A/B/C 不在；三件遗物位置分别对应先前退出方向。 | `state-t4-empty-spaces-v001.png` |
