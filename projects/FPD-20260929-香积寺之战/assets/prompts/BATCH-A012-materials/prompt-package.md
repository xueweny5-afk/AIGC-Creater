# BATCH-A012｜战场材料状态板

- 日期：2026-10-02
- 工具：内置图像生成
- 用途：`MAT-BATTLEFIELD-001` 的金属、织物、皮革与木柄状态校准；均非镜头关键帧。

## A012-01｜暗色金属

同一唐代中期暗铁甲片和刀刃局部，三栏同尺度同角度：M0 使用旧且干燥；M1 细尘仅落在向上暴露面和缝隙；M2 局部刃口擦损与余尘。灰色中性背景、散射日光、窄高光。禁止镜面黑甲、铬光、全局脏污、字样。输出：`material-dark-metal-v001.png`。

## A012-02｜军用织物

同一灰褐衣袖与少量暗红旗布，四栏同尺度：T0 干燥使用旧；T1 腋下或肘内汗湿并增加垂坠；T2 上方褶皱积细土；T3 短裂口与纤维。哑光织物、自然重力。禁止丝绸光泽、泥浆、雨、血和文字。输出：`material-military-textile-v001.png`。T1 差异不足，需修订。

## A012-03｜皮革

同一马缰/腰带皮条和暗金属扣件，三栏：L0 哑光旧皮；L1 仅扣件、手握、弯折区局部磨亮；L2 缝边积尘及握持处汗色。禁止均匀油亮、现代马鞍、无来源水珠。输出：`material-leather-v001.png`。L1 光泽扩散过宽，需修订。

## A012-04｜木柄

同一长刀木柄握持段两栏：W0 干燥粗糙、握持区自然略平滑；W1 握带及相邻木面汗尘加深、细土卡在缝里。保留几何、色和材质；灰色背景、散射日光。禁止塑胶、亮漆、均匀泥污。输出：`material-wood-grip-v001.png`。

## A012-05｜皮革局部修订

以 `material-leather-v001.png` 为编辑目标，只将中栏 L1 的大片漆状反光恢复为哑光旧皮；仅在扣件接触与握持弯折处留下小范围柔和磨亮。尽量保持三栏结构与其余状态。输出：`material-leather-v002.png`；修订也轻微改变了其他栏的纹理，因此作为新版本整图自审，不宣称像素级不变。

## A012-06｜织物汗湿修订

以 `material-military-textile-v001.png` 为编辑目标，增强第二栏 T1 肘内和腋下缝边的不规则汗湿暗区及垂坠；保持哑光、无水珠。其余三栏尽量保留。输出：`material-military-textile-v002.png`；可读性有所提高，但仍偏细微，只作为近景参考候选。
