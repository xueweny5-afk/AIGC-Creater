# ASSET CONTRACT

## IDENTITY

- **Asset ID：** PROP-HORSE-TACK-001
- **Type：** PROP / ANIMAL EQUIPMENT SYSTEM
- **Working Name：** 骑兵坐骑与马具系统
- **Version：** V1.2
- **Status：** STATIC_RIDER_CONTACT_PASS
- **Evidence Status：** PERIOD-FUNCTION RECONSTRUCTION / STRUCTURAL REVIEW REQUIRED

## LOCKED FEATURES

- 中型、耐久、适合阵地机动的战马体态；不使用现代高大纯血赛马轮廓。
- 鞍、鞍垫、镫、缰、胸带和扣件必须形成可受力系统；不悬空、不穿模。
- 仆固怀恩主坐骑保持同一花色、鬃尾、白斑、马具体系和体型。
- 群体马匹只在花色、维修和局部部件上受控变化。

## REQUIRED VIEWS / STATES

1. 主坐骑左侧结构母图、正斜、右侧和后向。
2. 马具拆分板：鞍、鞍垫、镫、缰、胸带、扣件。
3. H0 等候；H1 转向；H2 高速；H3 接敌后汗尘。
4. 手—缰、脚—镫、鞍—骑手三处接触验证。

## NEGATIVE CONSTRAINTS

- 无现代英式/西部鞍具、马术比赛装备、奇幻金属马铠和装饰性巨大鞍桥。
- 无悬空脚镫、断裂缰绳、错误关节、赛马腾空模板或过度肌肉化马体。
- 无无依据的阵营刻板装饰。

## DERIVATION RULE

- 先锁主坐骑与基础马具侧面结构，再派生角度和动态。
- 动态状态只改变重心、腿位、缰绳张力、汗尘和鬃尾运动，不改变马匹身份。
- 与 COST-PUGU-001 和 GROUP-UYGHUR-CAV-001 联合审批。
