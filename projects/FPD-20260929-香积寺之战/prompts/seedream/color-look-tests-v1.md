## 使用方法

1. 每次生成一张横向单幅图；建议在界面选择16:9，三张使用同样的尺寸和模型版本。该比例是测试选择，不锁定成片画幅。
2. 先用01生成战前基准。若已有本项目批准的人物衣甲参考，可上传并添加下方绑定句；没有参考图也可直接测试，文字生成的人物只作临时视觉载体。
3. 若入口支持图片编辑，02和03分别上传同一张01原始结果，添加下方“母图绑定句”，再接对应正文。不要用02结果继续生成03。原始01保留为共同基准。
4. 若只有文生图，三条正文均可独立使用，但人物一致性无法仅靠文字保证；此时只比较色彩、受光和材质，不判定角色连续性。
5. 不必另外上传电影截图；正文已将参考方向转成具体描述。输出不需要片名、字幕、调色板或三联图。

## 01｜战前：冷灰写实基准

```text
一张真人历史战争电影剧照，唐代战争题材的分镜前色调测试。午后，干燥开阔的黄土地。一名成年东亚男性普通军士站在阵列前，膝部以上中景，位于画面右侧，身体略侧，双手稳握长刀木柄，嘴唇闭合，警觉地看向画面左侧。左后方三名军士前后错开，两面暗红军旗位于远处。画面同时看得到人物面部、衣甲、灰褐土地和浅灰天空。

人物面部保留眼下疲态、胡茬、细纹与自然黄棕肤色。暗铁灰层叠衣甲旧但完整，甲片叠压处有阴影，边缘局部磨亮；皮带有接触折痕，粗织内衬反光柔弱，各种材料清楚区分。

自然天光从画面左上方照射，人物右侧面部自然偏暗，仍保留皮肤和甲片结构。冷中性天空、黄褐地面反射、暖肤色形成克制的色彩关系，暗红旗帜只占很小面积。中等对比，黑位厚重但不堵塞，高光柔和，主体清晰，远处逐渐柔化。空气较清洁，没有大面积扬尘。画面沉静、紧张，有真实现场摄影的材质和曝光感。单幅横向画面，无文字、字幕、水印、拼贴、夸张青橙色或磨皮效果。
```

## 02｜激战：尘土与损耗

```text
一张真人历史战争电影的色调测试图。唐代普通军士位于干燥黄土战场，膝部以上中景，站在画面右侧，身体略侧，双手稳握长刀木柄，视线朝画面左侧。左后方三名军士前后错开，远处有两面低饱和暗红军旗，保留人物、衣甲、土地与天空的对照关系。

时段为较晚午后，左上方自然光比战前略低，光源仍来自同一侧。人物额头和鼻翼有局部汗光，面颊略泛红，灰尘集中在颈部、衣领、护甲缝隙和下摆；内衬吸汗处局部变深，甲片出现少量接触擦痕，但头盔与衣甲主体完整，面部身份和装备款式稳定。

附近人马扰动的黄褐尘土主要位于背景和近地面，疏密不均，背景军士与旗帜降低对比，前景面部、双手和衣甲仍然清楚。天空保持冷中性，土尘呈暖灰褐，肤色保留自然血色，铁甲有克制的窄亮边。整体低饱和，中等主体对比，深暗处仍有结构，高光柔和。沉重、紧绷，有消耗感。单幅横向画面，无文字、字幕、水印、全局白雾、火焰、额外光束、浓重滤镜或血浆喷溅。
```

## 03｜战后：冷中性黄昏余光

```text
一张真人历史战争电影的黄昏色调测试图。唐代普通军士站在干燥黄土战场，膝部以上中景，位于画面右侧，身体略侧，双手握着长刀木柄，嘴唇闭合，视线落向画面左侧。左后方仍有三名军士和两面暗红旗帜，位置与战前测试画面一致，用于比较同一空间的光线与材料变化。

自然日光减弱，冷中性天空余光成为主要照明，原来来自左上方的方向性光只剩很弱的痕迹，没有新增火光或人物补光。地面暖反射减弱，黄褐土呈较冷的灰褐色；人物肤色仍有微弱棕暖色，眼下疲态、干燥嘴唇和局部尘污可辨。衣甲缝隙残留灰尘，内衬保留汗湿后的深浅变化，金属高光显著减少，皮革和织物更哑，但甲片与头盔结构清楚。

战斗停止后的少量余尘停留在近地面，远景可见度回升。整体低至中等对比，深色衣甲和背景仍有分离，天空保留渐变，面部不被额外提亮。安静、疲惫、苍凉，没有金色凯旋光、橙红落日或英雄海报式轮廓光。单幅横向画面，无文字、字幕、水印、拼贴、黑白化或均匀浓雾。
```

## 单变量对照：想更冷硬时

使用同一张01母图，只加下段做一个额外对照；不同时改人物、动作、天气或构图。

```text
保持参考图中的人物、衣甲、构图、天空亮度和光源方向不变。仅调整调色：环境色彩再收敛少量，暗铁灰与土褐色更加凝练，适度增加甲片和面部的局部明暗对比，保留肤色中的棕暖和微弱血色，深色甲片内部仍可辨认。整体呈轻度银保留胶片观感，冷硬而克制，不压死黑位，不漂白皮肤，不增加雾、颗粒或光晕。
```

## 验收与回执

- 核心假设：低饱和冷环境仍能保留自然肤色和分材质反光；时段/尘土变化不会导致人物与装备重画。
- 01→02→03是叙事状态测试，包含多个变化，不构成单变量滤镜比较。上面的额外对照才仅改变调色。
- 检查：肤色是否发青；铁、皮、布是否分得开；暗部是否保留结构；背景尘是否有来源；母图编辑是否改变脸、甲型和长刀。
- 模型输出未经验证；如身份/装备变化明显，该图仍可用于色调讨论，不能作为连续性通过证据。
