## 分工

关键帧负责当前姿态、构图、光线、材料；图生视频负责从输入状态继续的主动作、摄影机行为、环境响应与可剪辑结束状态。不能从最终画面证明作者就是这样工作。

## 1. 侧面骑兵冲锋

参考机制：原片00:57.5—01:00的低视点、逆光暗面与马蹄尘。主动作为持续疾驰，摄影机为平行侧跟。

### 关键帧

```text
真人历史战争电影的骑兵侧面中景。摄影机接近马腹高度，一匹深棕战马位于画面中央，身体朝画面右侧，处于疾驰步态的一瞬，骑手上身略向前，双手控制缰绳。后方少量骑兵错开排列，右侧运动前方留出空间。低角度日光来自左后方，天空明亮，马身和骑手正面保留明显暗部，鬃毛与甲片边缘有细窄亮光。马蹄附近有刚被踢起的灰褐尘土，后方较浓、前方较清。暗铁甲片、旧皮革马具和马匹短毛具有不同反光，远处军阵随距离减淡。低饱和灰蓝天空与土褐地面，高光柔和，暗部保留体积。单幅横向，无文字、水印或现代物件。
```

### 图生视频

```text
从输入画面当前疾驰步态继续，骑兵持续向画面右侧奔行。摄影机与领骑平行侧跟，保持距离、机位高度和主体占比。马匹整体向前运动，四肢连续交替落地，骑手髋部和躯干随马背小幅承重起伏，双手始终控制缰绳。鬃毛与衣摆随前进气流向后摆，尘土由马蹄落地踢起，集中在近地面并留在骑队后方。后排骑兵保持错开位置。光源方向和曝光连续，结束时领骑仍向右疾驰。保持人物、马匹、衣甲、马具与兵器结构，不新增骑手，不突然转向，不环绕、变焦或切镜。
```

## 2. 骑将回望

参考机制：原片02:58—03:00的背面转头。追兵与正面反应在原片另有镜头，不拼进本Clip。主动作一次回头，摄影机固定。

### 关键帧

```text
真人历史战争电影的骑将肩背中近景。摄影机位于人物后侧，一名骑将坐在深棕马上，躯干朝前，头部刚开始向左肩方向偏转，只露出少量侧脸，双手保留控制缰绳的姿势。肩甲和后背占画面主要部分，下方露出部分马颈，背景是灰褐平原与低地平线。自然侧光照到头盔边缘和近侧肩甲，面部未受光区域保持暗部。甲片叠压厚度、局部磨损和旧皮革连接清楚，露出的皮肤保留自然棕暖色。低饱和灰蓝与土褐，主体明确、背景柔和。单幅横向，无文字、水印或夸张轮廓光。
```

### 图生视频

```text
从首帧已经开始偏转的头部姿态继续，骑将把头转向左肩后方，视线先侧移再落定，眉头略收紧，嘴唇闭合。躯干仍朝前，肩部只作必要的小幅跟随，双手不离开缰绳。转头结束后停留片刻，保持看向画外后方的姿态。摄影机固定在原肩背位置，不绕到正面，不推拉。马匹只保持输入状态所需的轻微承重起伏，背景不争夺注意。保持面孔、头盔、衣甲和受光，不反复回头，不大幅扭转身体，不张嘴喊叫，不切入追兵画面。
```

## 3. 弓手放箭

参考机制：原片01:42—01:47的瞄准、可见命令字幕与箭群。本例只处理一名弓手的一次释放。

### 关键帧

```text
真人历史战争电影的步弓手中近景，摄影机位于弓手侧前方。一名成年东亚弓手满弓瞄准画面右侧，左手握弓把，左臂向右前方伸出，右手将弦拉至面颊附近。一支箭已搭在弦上，箭杆朝右，手、弓把、弓弦、箭尾与面部的连接关系清楚。后方少量弓手错开排列作为队列背景。人物嘴唇紧闭，目光集中，皮肤有自然细纹与局部汗光。暗色衣甲、粗织袖口和旧皮护臂反光不同。自然天光从侧上方照射，阴影保留肤色和衣甲层次，灰蓝天空、灰褐地面与小面积暗红旗低饱和。焦点在前景眼睛和持弓手。单幅横向，无文字、水印、额外箭杆或融合手指。
```

### 图生视频

```text
从输入画面的满弓姿态开始，弓手短暂保持瞄准，随后右手手指释放弓弦一次，箭沿既定瞄准方向向画面右侧射出。弓弦回弹后轻微振动，右手沿面颊旁自然向后收少量距离，左手稳定握弓，身体只有轻微受力响应。射出后保留持弓姿态，视线继续沿箭的方向。摄影机固定，背景队列只作轻微从属响应，光线与衣甲保持一致。只射出一支箭，不重新装箭，不反复拉弓，不让箭改变方向，不切到天空箭雨或受击者，不改变人物脸与左右手关系。
```

天空箭群与目标受击分别写镜头、使用对应图像，按方向、空间与后果剪接。军令、音效和字幕仍按项目后期分工，不假定未知视频模型能精确控制声音或口型。

## 验收

图片结构：主体当前状态→构图→有来源的光线→材料→必要排除。

视频结构：首帧后继续→一个主动作→一个摄影机行为→环境响应→结束状态→连续性约束。

先检查关键帧的手、弓、缰绳与身体连接；不能指望运动修复错误。视频检查动作是否只发生一次、人物/装备是否漂移、尘尾是否与运动相容、切出状态能否接下一镜。以上例子未实际生成或验证。
