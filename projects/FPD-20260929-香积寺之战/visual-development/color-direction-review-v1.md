## 1. 推荐方向

**冷灰天光、黄褐土地、暗铁衣甲、保留血色的人，以及不断失去温度的战场。**

本片要让观众看见队伍如何以人的损耗维持秩序。色调的作用是让人物、兵器、军阵和空位可读，支持从紧张到惨胜的情绪。整体沿用已批准的冷灰体系；肤色、土色和旗帜不一并抽成灰色。

先确定色彩与受光关系，再选择胶片模拟或LUT。Kodak 2383、银保留等只保留为后续试验选项，不指定为当前全片硬标准。尤其不能在激战开始时突然切换强滤镜，造成连续空间的天气和材质跳变。

## 3. 三种可审看方向

| 方向 | 色彩关系 | 观看感受 | 本项目适配 |
|---|---|---|---|
| A 冷灰写实（推荐） | 冷中性天空、黄褐土、暗铁、自然暖肤色、少量暗红 | 沉重而清楚，能看到人的疲惫和材料差异 | 作为整片基准，与现有合同一致 |
| B 更强去色与对比 | 土色与肤色进一步收敛，局部深暗、金属亮边突出 | 冷硬、压迫 | 仅作为对照，容易损失人脸与军阵层次；未采用 |
| C 暖灰史诗 | 暖灰土地与侧后光更明显，阴影保持中性偏冷 | 苍茫、悲壮 | 可研究黄昏前的局部受光，不作为结尾金色凯旋方案；未采用 |

推荐A。变化主要通过时间、尘土、材质损耗和人物缺席发生；不把不同段落处理成三部电影。

## 4. A方案的可执行色彩规则

- 天空：浅灰冷白到低饱和灰蓝；保留云层或天空渐变，不一律染成青色。
- 土地：黄褐到灰褐，是全片面积最大的暖色来源；扬尘继承地表颜色。
- 衣甲：暗铁灰，受光边缘略亮；叠压、铆钉和接缝可辨，不能整片压死成黑。
- 皮肤：自然黄棕、棕红与局部血色；允许疲劳、汗湿和尘污，避免统一青灰脸。
- 旗帜：低饱和暗红作为有限识别锚点；不因高潮增加红色面积或饱和度。
- 对比：人物与附近动作维持可读，远景随扬尘降低对比；不能统一加对比抵消空气透视。
- 高光：金属窄亮边与宽柔反光由角度决定；天空柔和过渡，避免HDR光边。
- 颗粒、光晕、暗角：保持 OPEN，后续按真实画面决定；不作为真实感的必需条件。

不新建一套并行状态ID，下游沿用Visual Bible V1中的现有NLA与LLS。

| 剧本范围 / 状态 | 色调与光线 | 物理触发 / 情绪功能 |
|---|---|---|
| S001 / NLA-01 / LLS-FRONT-AFTERNOON-ORDER-V1 | 冷中性天光；黄褐地表与自然肤色明确，衣甲层次清楚 | 战前少扰动、空气较清；先让观众记住完整的人与阵列 |
| S002—S004 / NLA-02 / 现有ROUT、HOLD、REGROUP状态 | 主光与S001连续；人流扬尘使局部背景变暖灰、降低对比，近处脸和手仍可读 | 溃退、冲撞与重组造成尘土脉冲；不靠天空突然变暗表示危机 |
| S005 / NLA-03 / LLS-FRONT-LATEAFTERNOON-ADVANCE-V1 | 天光随时间降低；暖色更多来自肤色、地面反射与尘，暗甲保持结构 | 推进与补位持续消耗人数；汗湿、积尘和擦损增加，不恢复洁净 |
| S006—S007 / NLA-04 / 现有CAVALRY、TURN状态 | 较低角度自然光可勾亮尘尾和部分甲片；总体仍冷中性，不全场镀金 | 马蹄产生方向性尘尾；敌军撤离后扬尘开始减弱，具体光源方位沿用OPEN项 |
| S008 / NLA-05 / LLS-FRONT-DUSK-AFTERMATH-V1 | 冷中性天空余光，地面暖反射减弱；不做金色胜利光，遗物和空位保持可辨 | 运动停止、余光下降、尘土沉降；让观众感到赢下战场却失去同列 |

上述为现有合同的解释与审看提案，天气、主光世界方位仍按原OPEN/UNKNOWN边界处理，不宣称757年当天实际如此。

## 6. 分镜前的最小验收与交接

色调文字确认后，最低限度用同一人物与衣甲、同一地表，审看“战前、激战、战后”三个状态。每个状态都检查面部、金属、织物、天空、土色和暗红旗是否保持同一体系；这些是后续色调验证需求，不是本次已生成或已验收的媒体。

验收重点：

1. 三种状态能看出时间与情绪变化，同时能认出是同一天、同一战场。
2. 肤色有生命感，铁、皮、布的反光有区别。
3. 暗甲内部仍有结构，战后遗物和空位不会被黑位吞没。
4. 尘土有物理来源，既不平均铺满，也不在切镜后无故清空。
5. 方向性日光不能随镜头反打任意反转。

后续Shot List与Storyboard继承对应LLS/ATM状态，仅记录有叙事依据的变化。色调决定影响场景、材质及受光呈现，不改变角色身份、历史兵器形制和战场拓扑。
