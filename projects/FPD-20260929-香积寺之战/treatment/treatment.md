## COMPLETE TREATMENT

[LOCKED + RESEARCHED] 唐军已经在长安西南、香积寺附近展开。前军、中军与后军仍保持完整结构，远处敌阵带来的压力尚未转化为全面交锋。无名安西军士站在前列军士之间。他不知道整场作战部署，只知道自己的位置由左右两名同列、身后不断延伸的人群和前方一致朝向的长刀共同确定。郭子仪处于中军的信息节点，能够接收比前线更多的战况，却也只能等待前方真正发生变化。故事在一个完整但紧绷的共同体状态中开始：每个人尚在原位，完整本身就是后来衡量损失的基准。

[RESEARCHED] 燕军挑战后，唐军向前追击。短暂的前进让压力似乎得到释放，但追击使原有队列被拉开。燕军随即齐进反压，前军开始退却，局部后退迅速传染成相互冲撞的惊乱，并波及中军和辎重方向。无名军士最初仍想寻找自己的同列，但视野、声音和人流都失去秩序。他被后退的人群带离原位，最终也顺着人流求生。这个选择不被定义为怯懦：对只看得见周围数步的人而言，继续后退是当下最直接的生存反应。与此同时，郭子仪所处的中军感受到前军崩散正在向后传递；全军仍有指挥结构，但留给前线恢复秩序的时间已经很少。

[RESEARCHED + ASSUMED] 李嗣业进入溃退方向，以史载的临阵奋击中止退势。Treatment 不替史书补写长篇演说，也不把他表现为凭个人杀敌扭转全局。他首先成为一个逆着人流站住的明确方向，使身边军士不得不重新判断自己是在逃离危险，还是正在把危险引向尚未崩溃的军阵。退势并非同时停止，而是从靠近李嗣业的局部开始出现迟疑：有人继续退，有人回望残存旗号，有人试图找回兵器和间距。

[ASSUMED] 无名军士也停下。他并不知道中军的压力，更不知道东侧还存在敌骑威胁。他只认出残存的阵列标志，也发现先前站在身边的一部分同列仍在尝试聚拢。继续后退仍可能让他暂时远离锋线，转身则意味着主动回到刚刚把所有人冲散的地方。他没有获得英雄式顿悟，只是从被人流带走的状态中重新做出一个很小的、不可撤回的选择：回到缺口里。身边其他人的零散选择与他相互支撑，原本互相推挤的人重新形成有共同朝向的局部队列。李嗣业的行动提供了方向，普通军士各自停步和补位，才使“稍定”成为可持续的阵线状态。

[RESEARCHED + ASSUMED] 前军开始持长刀向前推进。“如墙而进”不是完美、无损的仪仗式齐步，而是重建后的队列在阻力中维持同一方向。无名军士重新进入群体动作后，不再拥有独立寻找安全路线的空间。他只能跟随前后左右的节奏完成推进。正面碰撞不断削去队列：有人失去行动能力，有人从他身边消失，后方的人补入前方留下的位置。他每补一次位，就离最初的位置更远，也离危险更近。阵线在宏观上趋于完整，构成阵线的人却持续减少。

[LOCKED + ASSUMED] 伤亡的代价在这一过程中由抽象变为可感知。战前与无名军士共同构成方位参照的数名同列，不再全部出现；某个刚被填上的空位很快又需要第二个人填补；装备和体力的损耗不会因阵线恢复而复原。无名军士没有时间为任何一个倒下者停留，他能做的只有保持方向，不让下一个缺口从自己这里扩大。李嗣业仍承担前军推进的可见方向，但战果不被归因于他的个人武力，而是由一整列不断减少的人共同完成。

[RESEARCHED] 当前军勉强站稳时，东侧敌骑仍企图攻击唐军侧后。这个威胁不在无名军士的认知范围内，但它决定了正面推进能否继续。侦察使唐军一方意识到东侧危险，仆固怀恩率回纥骑兵迎击。Treatment 不虚构郭子仪亲自发现一切或逐字下达完整部署，只呈现中军仍能接收信息、东翼仍能作出行动这一事实。仆固怀恩的骑兵不是最后一刻凭空出现的援军，而是此前已属于唐军作战结构、此刻在另一方向完成其不可替代的任务。

[RESEARCHED + ASSUMED] 东侧威胁受到反击后，正面燕军承受的压力发生变化。无名军士看不到另一处战斗的全貌，只能先听见马蹄与喊声的方向改变，再发现眼前敌军不再持续向前，局部退势逐渐扩大。他不理解全部战术，但可以确认自己所在的队列不再只是勉强抵挡。李嗣业所率前军与东翼行动在结果上形成夹击，唐军从顶住转入反攻，燕军最终溃退。这个转折属于相互配合的多支军队，不属于某个名将的孤立奇功。

[LOCKED + RESEARCHED] 战斗结束时已接近黄昏。唐军在战役层面取得了通往收复长安的胜利，但故事不跟随胜军入城，也不进入庆功。无名军士仍处在战场上。他重新面对战前曾经完整的同列位置：队列在意义上还站着，实际的人数已经严重减少。那些曾帮助他判断左右、前后与间距的人没有全部回来，遗下的兵器、破损装备和无人补上的空位成为一张没有姓名的损失清单。

[LOCKED] 无名军士没有欢呼，也不需要被郭子仪、李嗣业或仆固怀恩看见。他只确认自己仍站在这里，然后把视线投向长安所在的方向。远处方向意味着战役目标正在接近，却不能消除身边的缺席。故事以这一不可逆状态结束：军阵重新获得了形状，最初组成它的人却不可能重新完整；“胜利”与“失去”在同一个幸存者身上同时成立。

## NARRATIVE SEQUENCE MAP

### Sequence 1｜完整是损失的基准

- **Start State｜起始状态：** 唐军前、中、后三军已经展开，无名军士与同列保持完整位置；郭子仪处于中军节点。
- **Process / Action｜过程或行动：** 军队等待交锋，个体通过相邻者、旗号和兵器方向确认自身位置。
- **Choice / Response｜选择或反应：** 无名军士维持阵位，不寻求额外行动。
- **Consequence｜后果：** 共同体的完整状态被建立，后来每个缺席都将有明确参照。
- **Information Change｜信息变化：** 观众知道无名军士只能看见局部，同时知道中军结构仍在。
- **Emotional Movement｜情绪运动：** 压抑 → 紧张。
- **Provenance｜来源：** [RESEARCHED] CLM-001、CLM-002；[ASSUMED] 无名军士与具体同列关系。

### Sequence 2｜追击使阵线失去形状

- **Start State｜起始状态：** 前军保持方向，等待中的压力尚可控制。
- **Process / Action｜过程或行动：** 挑战引发追击，队列被拉开；燕军齐进反压，局部退却扩散为惊乱。
- **Choice / Response｜选择或反应：** 无名军士先寻找同列，随后顺着退潮求生；郭子仪所在中军承受前军失序传来的压力。
- **Consequence｜后果：** 主角离开原位，军阵从共同体变成方向冲突的人群；中后军暴露于更大风险。
- **Information Change｜信息变化：** 观众理解溃败不是单次冲击，而是追击、拉开、反压和传染造成的连续结果。
- **Emotional Movement｜情绪运动：** 紧张 → 短暂释放 → 失控。
- **Provenance｜来源：** [RESEARCHED] CLM-003；[ASSUMED] 主角被人流带离原位的局部经历。

### Sequence 3｜停下是第一次反向选择

- **Start State｜起始状态：** 前军退势仍在扩大，无名军士已被带离阵位。
- **Process / Action｜过程或行动：** 李嗣业进入危机区域并使退势出现停顿；零散军士重新辨认旗号、同列和共同方向。
- **Choice / Response｜选择或反应：** 无名军士停止继续后退，转身补入一个正在形成的缺口；其他人的局部选择与之互相支撑。
- **Consequence｜后果：** 前军从“停止崩溃”转为“可以重新行动”；主角重新获得阵位，也主动接受更高风险。
- **Information Change｜信息变化：** 观众看到名将行动只有被普通士兵执行，才能变成真正的阵线变化。
- **Emotional Movement｜情绪运动：** 失控 → 窒息般停顿 → 顶住。
- **Provenance｜来源：** [RESEARCHED] CLM-003、CLM-012；[ASSUMED] 主角回身与群体逐步重组。

### Sequence 4｜墙由不断减少的人维持

- **Start State｜起始状态：** 重建的前军具备共同方向，但仍不稳固，正面压力未消失。
- **Process / Action｜过程或行动：** 李嗣业率前军持长刀推进；碰撞造成持续减员，后方不断补入空缺。
- **Choice / Response｜选择或反应：** 无名军士不离开阵线，连续接替更靠前的位置；群体用一次次补位保持推进。
- **Consequence｜后果：** 阵线在战术上变得坚固，群体在人员上变得残缺；主角越接近胜势，身边熟悉的人越少。
- **Information Change｜信息变化：** “如墙”从壮观形象转化为有生命代价的共同体动作。
- **Emotional Movement｜情绪运动：** 顶住 → 重压下推进 → 代价显现。
- **Provenance｜来源：** [RESEARCHED] CLM-003、CLM-006、CLM-007；[ASSUMED] 补位机制和具体减员连续性；[DO NOT ASSERT] CLM-016 所列固定阵法。

### Sequence 5｜胜利留下不能补回的空位

- **Start State｜起始状态：** 正面前军已经恢复推进，但东侧敌骑仍威胁唐军侧后。
- **Process / Action｜过程或行动：** 仆固怀恩率回纥骑兵反击东侧伏骑；东翼与正面行动形成合力，燕军转入溃退；战斗接近黄昏后结束。
- **Choice / Response｜选择或反应：** 无名军士继续执行局部推进，直到从敌军退势中理解战局已经改变；战后他选择停留并面对空位，而非参与欢呼。
- **Consequence｜后果：** 唐军取得战役胜利，完整队列却无法恢复；“收复长安”的宏观结果与无名者的缺席同时成立。
- **Information Change｜信息变化：** 主角和观众晚于中军理解东翼行动的意义；结尾才完全理解伤亡规模。
- **Emotional Movement｜情绪运动：** 压力 → 反攻释放 → 沉默的余痛。
- **Provenance｜来源：** [RESEARCHED] CLM-004、CLM-005；[ASSUMED] 主角通过声音方向和敌军退势感知变化；[LOCKED] 以空位完成惨胜。

因果链：因为追击拉开阵线，所以燕军反压能够把退却放大为惊乱；因为李嗣业逆向止退并提供明确方向，所以普通军士有条件重新选择阵位；因为普通军士真正停步和补位，所以前军能够“如墙”推进；因为东侧伏骑仍威胁侧后，所以仅靠正面站稳还不能赢；因为仆固怀恩率回纥骑兵反击东侧，所以正面与侧后力量能够共同迫使燕军溃退；因为胜利由持续补位换来，所以战后完整阵形留下无法补回的空位。

## WORLD / RULE USE

- **军阵依赖：** 单个军士的安全与队列是否完整直接相关。军阵不是背景，而是改变角色可选行动和生存概率的规则。
- **有限视野：** 前军士兵、中军指挥者和东翼骑兵拥有不同信息。信息差决定谁能判断全局、谁只能响应局部。
- **命令效力：** 命令本身不能自动改变战场，必须经过军士停步、重组和执行才产生后果。
- **空间因果：** 前军、中军、后军与东翼属于同一战场结构；前军失序会向后扩散，东翼受袭会破坏正面推进。
- **不可逆损耗：** 倒下或失去行动能力的人不会在后续状态中复原；装备、疲劳、尘土和人数变化必须累积。
- **历史边界：** 不使用精确唐军阵亡数字，不把争议阵法和陌刀形制当作确定规则，不虚构真实人物内心。

## PRODUCTION FEASIBILITY

- **Character Load｜角色负担：** 4 个可识别人物、1 个群体角色。CHR-001 贯穿全片；郭子仪、李嗣业、仆固怀恩各只完成一个明确叙事功能。
- **Location Load｜地点负担：** 一个连续战场，内部只需维持前军、中军、东翼与战后原阵位的空间关系；不进入寺内、长安城内或营帐。
- **Time Span｜时间跨度：** 史实从午至酉，成片压缩为约 150—180 秒的连续战役体验；不表现次日入城。
- **Complex Action｜复杂行动：** 追击转溃退、局部止退、长刀集体推进、连续补位、东翼骑兵迎击、敌军退势。后续应把每项复杂动作拆成单一可验证动作单元，但本阶段不规定镜头。
- **Continuity Risks｜连续性风险：** 前军人数必须单向递减；已消失的同列不得随机复现；CHR-001 的位置、装备破损和疲劳持续累积；李嗣业衣甲状态需符合结构；仆固怀恩与东翼骑队的空间方向必须稳定；天光只作时间推进，不断言具体天气。
- **Reusable Asset Candidates｜潜在复用资产：** CHR-001 五阶段状态；CHR-002 危机前/止退/推进状态；CHR-003 中军状态；CHR-004 骑乘状态；4—6 个可辨认群体轮廓；唐军前军基础阵列、燕军压力阵列、东翼两类骑兵、战场基础空间、损伤与空位状态。

建议的叙事时长配比仅用于下阶段校验，不构成镜头表：完整阵列约 20—25 秒；追击与溃乱约 30—35 秒；止退与重新入列约 30—35 秒；如墙推进与持续补位约 45—55 秒；东翼反击、溃退与战后空位约 35—45 秒。总长控制在 160—175 秒较稳妥。

## DECISION REGISTER

### LOCKED

- Treatment Scope 为 Standalone Film，时长 2 分 30 秒至 3 分钟，16 镜以内。
- 五段因果为：完整阵列 → 追击与溃乱 → 止退与回身 → 如墙推进与减员 → 东翼反击与战后空位。
- 无名军士先求生后回身，其选择只改变局部阵位，不改变整场战役。
- 郭子仪、李嗣业、仆固怀恩分别承担中军连续性、前军止退、东翼反击。
- 历史人物无私人内心补写；郭子仪不被塑造成全知军师；李嗣业不以个人武力击败全军；仆固怀恩与回纥骑兵不是凭空到达的援军。
- 惨烈通过同列消失、重复补位、损伤累积和战后空位表达，不使用存疑数字。
- 结尾不入长安、不庆功、不欢呼。

### OPEN

- 最终片名、平台、画幅与精确成片时长。
- 是否使用片头/片尾史料字幕及其措辞。
- 历史人物功能性军令的具体文字。
- 李嗣业衣甲变化、长刀/陌刀候选形制及人物具体视觉身份锚点。
- 主角是否需要极短非语言发声；默认为无需完整台词。

### ASSUMED

- 无解释性旁白，主要依靠行动、声音和状态变化传递因果。
- 故事允许把午至酉的数小时压缩为连续体验，不改变关键事件顺序。
- 观众通过中军和东翼短暂离开主角视角获得必要全局信息，但情绪仍回到 CHR-001。
- 战后主角位于与战前可比对的阵位附近，以确保“空位”具有明确记忆来源。
- 推荐成片目标约 160—175 秒，为后续节奏调整保留余量。
