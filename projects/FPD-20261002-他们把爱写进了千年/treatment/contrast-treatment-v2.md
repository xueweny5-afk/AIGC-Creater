# 《他们把爱，写进了千年》前后反差版 Treatment

**形式：** 四个六秒微段落。每段先建立真实可感的二人关系，再让同一物件引出突然的时间切换。下述具体动作是影像化重构，不声称史料记载了这一瞬间。

## 1. 李清照与赵明诚｜共同做一件事

灯下，两人俯身看同一张碑拓。她沿纸面轻移指尖，他低头同看；两人的注意力落在同一处。**切点：** 手势还在继续时，画面突然切到同一书案与碑拓。纸仍铺开，身旁却空了。她托腮看向空位。只留下极轻的纸响与室内静默。

## 2. 苏轼与王弗｜有人记得你遗忘的事

两人并坐读书。王弗沿书页轻移指尖，苏轼托腮侧目看她。**切点：** 指书动作还未结束，硬切到同一书页和空椅。现在苏轼仍托腮朝那个方向看，却无人回应。文本从王弗能记书的线索转到苏轼的记梦词。

## 3. 陆游与唐氏｜同一条路只余一人

春园里，两人沿石径慢行，相视轻笑，桃花掠过画面前景。**切点：** 步伐未停时突然切到同一条石径的后来时刻；唐氏的位置空了，园中春色也变得清冷。陆游低头看手中折信。这里拍的是诗词情绪，不把这次同行和信件描述成已证实史实。

## 4. 沈复与陈芸｜最普通的一餐

桌上两只碗，两人对坐，相视轻笑，普通饭菜因为对方在场而显得温暖。**切点：** 碗筷轻响之后，硬切到同一桌面：碗还在，对面无人。沈复托腮望向空碗。最后停在这只碗，不加解释性结尾字幕。

## 节奏与声音

- 每组前 3 秒让观众看见一个明确关系动作；第 3 秒以同地同物硬切；后 3 秒给缺席和反应留出时间。现有静帧不承诺严格同机位或动作接点。
- 四次切点不使用闪白、故障转场或夸张泪水。音乐在切点压低约四分之一秒，随后低音进入；正式动态版再加入纸、脚步、碗的局部声音。
- 反差的主角始终是**同一物件旁少了一个人**，不是人物突然变老或画面突然变灰。
