# CH01 / CH02 正脸画幅修复提示词 v1

用途：以各自已生成的正脸候选作为**编辑输入图**，分别运行一次图像编辑或局部扩图。不得只用文字重新生成人脸。两人互不作为彼此的参考图。

## CH01 李清照

输入图：`../characters/CH01/canon-face-front-v1-candidate.png`

```text
CHANGE：仅向上扩展画布，补全原图顶部被截断的深色发髻和自然发丝。让完整发髻轮廓与画框上边之间留出可见的浅灰色背景空间；延续原图已有的发量、盘发结构、发色与光照。

PRESERVE：锁定原图现有像素中的整张脸、五官比例、肤色、眼神、眉形、嘴唇、双耳、脖颈、衣领、人物正面姿态、表情、背景灰度和柔和均匀光线。已有头发部分不改动。

CONSTRAINTS：这是扩图修复，不重新生成演员，不改变发际线或年龄，不加发饰、首饰、戏服、道具、文字或水印；不改变图像下方和左右两侧内容。保持单人、正面、平视、中性身份照。
```

输出：`../characters/CH01/canon-face-front-v2.png`。验收：完整发髻不碰上边框，脸部与 v1 候选可逐点识别为同一人，没有新发饰或新的头发结构。

## CH02 赵明诚

输入图：`../characters/CH02/canon-face-front-v1-candidate.png`

```text
CHANGE：仅向上扩展画布，补全原图顶部被截断的深色束发与发髻。让完整发髻轮廓与画框上边之间留出可见的浅灰色背景空间；延续原图已有发量、发流、发色与光照。

PRESERVE：锁定原图现有像素中的整张脸、五官比例、肤色、眼神、眉形、胡须形状与密度、双耳、脖颈、衣领、人物正面姿态、表情、背景灰度和柔和均匀光线。已有头发部分不改动。

CONSTRAINTS：这是扩图修复，不重新生成演员，不改变发际线、年龄或胡须，不加冠帽、发饰、戏服、道具、文字或水印；不改变图像下方和左右两侧内容。保持单人、正面、平视、中性身份照。
```

输出：`../characters/CH02/canon-face-front-v2.png`。验收：完整发髻不碰上边框，脸和胡须与 v1 候选可逐点识别为同一人，没有新冠帽或新的头发结构。

## 执行顺序

先分别修复两张正脸并回传审核。通过后，才以各自修复版作为唯一身份母图派生左右 45°、左右侧面、全身正面及其他全身视图。若编辑工具会重绘整张脸，请改用只覆盖画布新增区域的扩图模式。
