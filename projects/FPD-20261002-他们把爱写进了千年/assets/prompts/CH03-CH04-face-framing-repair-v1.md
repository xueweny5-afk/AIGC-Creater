# CH03 / CH04 正脸画幅修复提示词 v1

用途：分别上传各自的正脸候选，使用**扩图/画布外延**模式。只编辑画布新增的上方区域；不要仅凭文字重新生成人脸。两人的图片不可互作身份参考。

## CH03 苏轼

输入图：`../characters/CH03/canon-face-front-v1-candidate.png`

```text
CHANGE：只向上扩展画布约 8%–10%，延续原图浅灰背景，让完整束发发髻与画框上边之间留下稳定的背景空间。若新增区域包含少量发丝，只自然延续原图现有的深色发流与发髻外轮廓。

PRESERVE：原图已有的脸、眼鼻口比例、眉形、肤色、年龄感、长须形状与密度、发际线、现有发髻、耳朵、衣领、正面姿态、中性表情、柔和均匀光线全部保持。原图已有像素不重绘。

CONSTRAINTS：不改变演员身份，不缩短或加长胡须，不改变发型结构，不加冠帽、发簪、正式戏服、道具、文字或水印。不扩展左右或下方；保持单人正面身份照。
```

输出：`../characters/CH03/canon-face-front-v2.png`。验收：上方留白明显；与候选是同一张脸、同一胡须、同一发髻。

## CH04 王弗

输入图：`../characters/CH04/canon-face-front-v1-candidate.png`

```text
CHANGE：只向上扩展画布约 8%–10%，延续原图浅灰背景，让目前几乎贴上边框的完整盘发发髻与画框上边之间留下稳定的背景空间。新增区域只补自然发丝和背景，不重新设计发髻。

PRESERVE：原图已有的脸、眼鼻口比例、眉形、肤色、年龄感、发际线、盘发结构、耳朵、衣领、正面姿态、中性表情、柔和均匀光线全部保持。原图已有像素不重绘。

CONSTRAINTS：不改变演员身份，不改成李清照的脸或发髻，不加发饰、首饰、正式戏服、道具、文字或水印。不扩展左右或下方；保持单人正面身份照。
```

输出：`../characters/CH04/canon-face-front-v2.png`。验收：上方留白明显；与候选是同一张脸、同一盘发，没有新增发饰。

两张修复版回传审核后，分别作为 CH03、CH04 的唯一身份母图，再逐张派生左右 45° 和侧面。若编辑工具会重绘全脸，改用只覆盖画布新增区域的扩图模式。
