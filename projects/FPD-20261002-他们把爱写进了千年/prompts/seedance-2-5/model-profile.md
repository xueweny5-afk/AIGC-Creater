# Seedance 2.5 模型档案｜2026-10-12

**项目用途：** 八镜分别以已批准静帧制作独立图生视频；用户自行操作。本档案只记录官方可核实能力，不代表已做技术样片。

| 项目 | 已核实规则 | 本片采用 |
|---|---|---|
| 模型 | 火山方舟 `doubao-seedance-2-5-260628`；其他产品界面可能使用 Seedance 2.5 名称 | 用户指定 Seedance 2.5，具体入口由用户使用的平台界面决定 |
| 任务 | 支持一张 `first_frame` 或首尾两张帧图 | SH01–05/07–08 用单首帧；SH06 需补起始帧后用首尾帧 |
| 时长 | 首帧/首尾帧任务 `duration` 为 4–30 秒或自动 | 每镜 4 秒；后期从稳定画面中选约 3 秒，24 秒总长仍是目标而非模型直接输出 |
| 画幅 | 首帧/首尾帧任务 `ratio` 必须 `adaptive`，沿用首帧比例 | 首帧均为 1080×1920、9:16；不在接口中强填 `9:16` |
| 声音 | 模型可生成音频 | 本片对白、诗句、硬切声音由后期独立制作；如界面可关闭原生声音则关闭，不能关闭则只取画面，不把合成口型当成定稿 |
| 提示词引用 | 官方文档提供图片引用和首尾帧角色 | 手动界面按槽位上传；不臆造该界面的 `@图` 索引，提示词正文只描述已上传画面 |

**官方依据：** [Seedance 2.5 教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)、[模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=en)、[提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)。2026-10-12 查阅。界面若与 API 有差异，以当前界面为准并记录实际选择。

**尚未验证：** 人物脸/手连续性、画面上下留白稳定度、3 秒有效内容和对白口型；这些需要后续每组试镜。当前用户边界止于生成前，不提交视频生成。
