# 八镜图生视频执行卡｜Seedance 2.5｜v1

**状态：** `STAGE13 COMPILED / USER GENERATE / SH06 WAITING FRAME`。依据 `../../screenplay/screenplay.fountain`、`../../direction/shot-list.md` v4、`../../storyboard/frame-manifest.md` v4、`../../motion/motion-spec.md` v4 与八张已批准 `key-v2.png`。不提交生成任务。此包是当前版；旧 MiniMax 包和 `../pre-video-prompt-package.md` 已过期。

## 执行顺序与平台设置

1. 可先各组做一镜技术样片：SH01、SH03、SH05、SH07；核对人物、手和上下留白后再做对应后镜。SH02/04/08 可与其他组并行；SH06 等 `sh06-start-frame-handoff.md` 的 `S06-start-v3.png` 经确认后执行。
2. 选择 **Seedance 2.5 首帧生视频**入口。逐卡把指定 PNG 放入**首帧槽**；SH06 另把 `S06-key-v2.png` 放入**尾帧槽**。不要把同组前镜图当作后镜首帧，以免生成人物镜内消失。
3. 每镜设 **4 秒**，画幅设**自适应**（自动继承首帧 9:16）。如可选，关闭原生声音；画质选界面支持的最高稳定选项，记录实际值。每镜只复制下方对应主提示词。平台无独立负向栏时，提示词中的“保持/不要”已覆盖关键限制。
4. 原始结果按卡号保存到 `../../generation/raw/SHxx-seedance25-take01.mp4`（相对本文件）。不要自行裁切或把 8 镜合成一条。记录实际模型入口、4 秒设置和文件名；回传逐镜结果，用户可直接说明哪些镜头“审核通过”。后续 QC 从 4 秒中选约 3 秒可用段，并复核 24 秒总节奏。

**统一边界：** 每张已批准帧是该镜的第一幅画面，动作只能从画中当前状态继续；固定机位，维持人物脸、服装、左右关系、道具、光源位置、画面中部叙事区与上下深色留白。不生成字幕、诗句、可读书信文字、第三人、鬼影、分屏、额外动作或镜内消失。四次“温馨→落寞”在 **SH01→02、03→04、05→06、07→08** 的剪辑点硬切，Seedance 逐镜只生成镜内动作。前后帧景别在前三组有用户已认可差异，不承诺像素级匹配。

## 切点与返回规则

| 成片切点 | 剪辑处理 | 失败时回到 |
|---|---|---|
| SH01→02，约 3 秒 | 赵刚按住 → 硬切年长李独处；纸声由有回应到停 | SH01/02 对应视频卡；若纸角静帧不可读返 Stage 11 |
| SH03→04，约 9 秒 | 对视刚成立 → 硬切年长苏与空椅；人声骤停 | SH03/04 视频卡 |
| SH05→06，约 15 秒 | 将触未触 → 硬切唐已缺席；双人脚步变单人 | 先查 SH06 补起始帧与尾帧，再返视频卡 |
| SH07→08，约 21 秒 | 菜入右碗、陈回应 → 硬切年长沈面对空碗 | SH07/08 视频卡 |

四句对白、两句诗文和声音断点由后期处理；模型视频中的试生成语音及唇形不作为成片批准素材。若稳定可用段不足约 3 秒，回 Stage 10/12 调镜长和动作节奏，不强行裁坏动作。下一流程是小批技术样片、实际 Take 登记与 G5 审核，仍须用户另行明确进入视频生成。
