## Director Thesis / Continuity Contract

观众先听到一股正在接近的力量，再看见都城为它开门、日常人群为它让路，最终一张无人拾起的诏书与关闭的宫门把公开行动变成无法旁观的宫廷权力变化。悬念来自被遮住的来者和逐步压缩的通行空间，不新增主角表情或大规模厮杀。

进入 S001：门留窄缝、骑兵在外且不可辨、百姓尚未进入视野。离开 S001：门已开放到可容领骑通过，骑兵正在进城。进入 S002：队伍已在街内，路边人占原有生活空间。离开 S002：一次马蹄踏水已发生，百姓贴墙让出通道。进入 S003：诏已落在宫阶并被雨淋，非镜内投递；离开 S003：诏仍在石阶，宫门闭合、门外余响尚在。S001→S002 是队伍行进的空间续接；S002→S003 是权力行动的语义/声音续接，不声称街道直通特定宫门。

## Scene Designs

### S001｜洛阳城门·清晨

- **因与功能**：291 年权力动员进入都城；从不可辨的接近声转为可通过的入口，显出城市边界被打开。
- **进入→转折→退出**：门窄缝、军队尚在雾外 → 门轴承重、门体开放造成冷光和低雾进入门洞 → 领骑获得通行空间并进入；不在开门前清楚展示其身份或阵容。
- **目标/阻力/策略**：军队的可观察目标是通过城门；门狭窄且未开启时保持慢行间距，开放后维持队列通过。没有具名士兵的个人心理线。门口其他守卫行为不在剧本中，不新增。
- **表演连续性**：领骑与后骑重心随马步小幅承重，视线沿通道，不看观众；手持兵器随坐姿稳定，仅马步造成微小摆动。没有宣言、呐喊或集体回头。退出时队列方向不反转。
- **空间与信息**：只依据门洞同侧可见结构；雾先遮远人形，门开后才让观众辨识骑兵。军队确切数量、受谁指挥均 withheld。
- **Look/Air**：LA01；`LLS-S01-DAWN-R1`、`ATM-S01-FOG-R1`。低位户外晨雾由微风/开门通风缓入，门内不凭空有烟；门打开仅改变入光区域，其他受光 HOLD。
- **声音与节奏**：远马蹄先于可辨身形；门轴摩擦随实际开启出现，马蹄由远到近。必须留给观众辨认“声音来自门外”的间隔；可通行时释放悬念，但不以配乐代替门和马的物理声。声音把进城状态带入 S002。
- **Must show / withhold / avoid**：必须出现门的窄→开与领骑通过；暂藏来者具体阵容；避免门还闭着马已在门内、雾变烟或火盆亮度突然大变。
- **资产依赖**：S01 窄缝/开门同一可见结构已经有图，晨雾与门扇连续动作尚未实证；骑兵/马具仅远距可读，不使用 REWORK 的马具图作近景事实。

### S002｜洛阳街道·清晨

- **因与功能**：军队进入后街道原有生活被迫让位；权力变化第一次落在普通人身体动作上。
- **进入→转折→退出**：队伍已占道路通行线，百姓仍临墙留出最小身位 → 前蹄一次接触积水，近马声与水花触发老人低头、邻人稍后收袖贴墙 → 路中央通道让出，人留在墙边。不得全体同步后撤。
- **目标/阻力/策略**：路人即时目标是避免与马队接触并守住手中衣物；受街道宽度/军队逼近限制，先就地收袖再贴墙，不跨入马行线。军士继续通过，不对百姓作剧本外威吓。
- **表演连续性**：百姓重心从路边自然站立移向墙侧，视线先落向近蹄/地面而非正对骑兵脸，呼吸压低；布袖由手臂收束造成位移，水花不应让全身湿透。退出时仍在墙边，为后续街道空出的道路留下物理结果。
- **空间与信息**：S02 图只支持单向墙/路/水面；不宣称路人的个体身份或全城规模。马具争议部位可留在叙事可读范围之外，但不能造出不合时代理由的近距特写。
- **Look/Air**：LA01；`LLS-S02-WETDAY-R1`、`ATM-S02-SPLASH-R1`。阴天湿地，无新雾。水花仅一次蹄触触发，沿动量飞起并落回；其他环境 HOLD。
- **声音与节奏**：近马蹄压过远声，一次低短踏水和衣料摩擦；反应落在接触声之后。此处不追加人群惨叫；声压留给 S003 雨声/宫门的权力空间。
- **Must show / withhold / avoid**：必须看见一次触水和至少两种先后避让反应；避免同步人群、巨浪、第二次踏水、老百姓跪拜。
- **资产依赖**：S02 单向湿街/水材质与 C04 群体姿态限域可用；马蹄/袖部接触的前后状态和手部皮肤特写仍未通过。

### S003｜宫阶与宫门·日雨

- **因与功能**：政变通过留在门外的文书和随后的关门声，被转译为不可逆的制度空间变化。
- **进入→转折→退出**：诏已经落在宫阶且受雨，朱印边缘微渗 → 宫门在其后方合拢 → 纸留原处、门外余响维持一瞬，通行/知情边界关闭。
- **目标/阻力/策略**：本场不出现持诏者或关门者；纸与门的状态承担叙事，不能给不可见人物发明个人目标。门体运动由门轴与重力解释，不表现神秘自闭。
- **表演连续性**：无可见具名人物。纸边因吸水缓慢贴石，不能像布料跳动；门闭合后纸的位置不变。
- **空间与信息**：观众看见权力结果却不知道门内具体发生什么；宫门内人物与完整宫城拓扑 withheld。纸图与门图只证明各自同向局部，需另核石阶能否作为同一空间。
- **Look/Air**：LA01；`LLS-PALACE-RAIN-R1`、`ATM-PALACE-RAIN-R1`。阴天雨落在开放石阶，门内雨减弱；宫门关闭使窄缝冷光收细，纸吸水、朱印局部微渗。不得把雨变血色流体或突然暴雨。
- **声音与节奏**：雨声持续并成为两动作的共同空间底；门的沉重碰合声打断纸的静观，余响将观众送入 S004 的清洁昏暗殿内。此声音桥不证明同一门直接通到帝座。
- **Must show / withhold / avoid**：必须看出纸已落在湿石、印边轻渗、门终态闭合；避免编造具体诏文和特定发布者、纸晶化、门后华丽宫室。
- **资产依赖**：P02 旧雨中图仅限原状态；R2 湿石纸印失败，不得用作近景。S03 宫门结构通过单向局部，关闭状态与诏书固定位置尚缺一致性审核。

### S004｜大殿·日

- **因/功能/信息**：宫门余响转入权力中心；观众看到晋惠帝坐在帝位却不主导行动。群臣只有影子，不赋予具名身份、台词或可见阴谋。
- **进入→触发→退出**：帝已独坐、殿内清洁昏暗 → 帘影、柱影与经过的人影依次分割其身形；他仍留原位，最多用目光追随声/影 → 帝座位置不变，观众转去识别争权诸王。
- **目标/策略/表演**：惠帝的即时可见任务是守住坐姿、观察经过之人；障碍是人影不断遮蔽视线。重心留在座上，手部不新增权杖操作，不张嘴呆望；冠服只随细小坐姿调整自然垂落。沉默并非失去意识。
- **空间/Look/Air**：仅 S03 清洁殿内的同向柱列、帝座、帘和阶梯可证；反向殿路 UNKNOWN。LA02／`LLS-S03-291-DAY-R1`／`ATM-INTERIOR-CLEAN-R1`，帘/人改变遮挡而非新烟尘或换光源，其他 HOLD。
- **声/节奏/出口**：宫门余响衰减，殿内脚步/织物声很轻；必须留住独坐与影子掠过的时间，不用大乐替代静默。LA02 的空间压迫转为 S005 的抽象“八王”识别。依赖 C01 身份和 K01/殿内组合核对；远景可限域避免未批正脸特写。

### S005｜抽象八王形势空间

- **因/功能/信息**：回答“争夺朝廷的是谁”，而非演出一场同时发生的会战。观众看见八枚棋子与洛阳红点，八个姓名按信息需要显露；诸王并非同时参战。
- **进入→触发→退出**：八棋已围点且位置固定 → 姓名逐步作为后期图文出现 → 空间关系仍不变，把注意从人数交给 301 年具体篡位。
- **行动/空间/Look**：没有可见下棋人，不让棋子自行行军；八枚黑木棋、中央红标和概念底图为可见锚点，真实方位/疆界 UNKNOWN。LA02 过渡 LA03；`LLS-S04-MAP-R1`／`ATM-ABSTRACT-CLEAN-R1`，无烟、单一工作光 HOLD。
- **声/节奏/出口**：旁白报“八王”并给八名姓名可读时间；木质撞击仅在有实际接触动作时可用，不以连续落子声暗示棋子移动。图文结束后切 S006 的一位具名行动者。依赖 P06 清洁八棋/底图的限域状态和后期准确字稿。

### S006｜大殿·301 年日

- **因/功能/信息**：抽象争权落在司马伦托玺与走向帝座的具体行动。与 S004 可复用大殿可见拓扑，但不是同一天；不表现帝位交接的未记载细节。
- **进入→触发→退出**：司马伦在帝座前一段距离，玉玺尚待其托稳 → 手掌承住**同一枚**玉玺，再朝帝座前进并停住 → 玉玺仍由他持有，事件转向诸王讨逆。
- **目标/策略/表演**：即时目标是以持玺行动取得可见皇权位置；障碍是必须让玺不滑落并穿过阶前空间。身体重心随步移，眼睛朝帝座方向；双手承重、袖口随手臂抬起；不奸笑、不临时增加诏读或跪拜。
- **空间/Look/Air**：殿内同向结构 VISIBLE，门至座完整路线 INFERRED、反向 UNKNOWN。LA03／`LLS-S03-301-DAY-R1`／`ATM-INTERIOR-CLEAN-R1`；弱暖实用火源和入口天光保持，不加“皇权金光”。玉质有重量、绶带垂落。
- **声/节奏/出口**：袖料/脚步轻声与持物停顿让篡位事实可读，旁白标注 301 年；托稳之后才允许前进，不在后续画面重复取玺。依赖 C02 正脸、K03、P01 掌中尺度与 S03 同向路径。

### S007｜抽象诸军形势空间

- **因/功能/信息**：司马伦篡位引出讨逆联盟/不同势力方向；只解释压力趋向洛阳，不给出现代行政边界或精确行军路线。
- **进入→触发→退出**：无字底图稳定 → 齐王、成都王、河间王等标识及趋向洛阳的概念路线在后期显露 → 视线从图转向 S008 的实际五骑。
- **行动/Look/声**：没有实体棋子自行移动；LA03／`LLS-S04-MAP-R1`／`ATM-ABSTRACT-CLEAN-R1`。人名、箭头均后期叠加，不在生成图里伪造字。信息密度上升后立刻给 S008 实体尺度和马蹄声；路线音效不冒充真实战役现场。依赖 P06 无字底图。

### S008｜北方荒野·日

- **因/功能/信息**：地图上的“起兵”变成穿越地形的可见军事运动；只拍五骑，不声称此五骑就是某位王的实录部队。
- **进入→触发→退出**：五骑已在荒野通行线 → 保持方向与略有差异的间距穿过 → 马蹄、衣甲声带到 S009 的权力交接隐喻。
- **目标/表演/空间**：队伍即时目标是继续赶路；骑者随马步承重、看行进前方，不频繁挥戟或勒马。S05 旷野地形与道路方向 VISIBLE，同侧路径可用；准确地理与反向地形 UNKNOWN。
- **Look/Air/节奏**：LA03／`LLS-S05-OVERCAST-R1`／`ATM-OUTDOOR-CLEAN-R1`；阴天、贴地微扰可以由蹄触发，新增浓尘不准。马步和甲片声持续，离开前不突然变万人战场。依赖 S05 地形、C03 服装和远距马体；马具近景仍受 REWORK 门槛。

### S009｜抽象玉玺交接空间

- **因/功能/信息**：司马伦败亡后权力继续被争夺，用**一次**匿名交接表达循环，不把画面指定为某次可考现场。
- **进入→触发→退出**：给予者持同一 P01 玉玺，接收者空手在下方等待 → 接收者先托住重量，给予者确认承重后松手 → 玉玺只在接收者双手中，原手退出。不能有复制玉玺或三次蒙太奇交接。
- **目标/表演/空间**：两人唯一动作任务分别为稳妥交付/接住；焦点是手与物的所有权，不赋予脸、姓名或心理。抽象暗背景可独立设计，但手掌、绶带、玺体尺度必须通过接触检验。
- **Look/Air/声**：LA03／`LLS-P01-TRANSFER-R1`／`ATM-ABSTRACT-CLEAN-R1`；单侧可解释光、无发光玉石。承重带来的微小接触声和释放前短停顿决定节奏；完成后切向被争夺者本人 S010。此场为全片最高优先级状态变化资产缺口。

### S010｜行进封闭车驾内·日

- **因/功能/信息**：权力象征交接后，真正被移动的是晋惠帝；观众见他在车内而非主动驾车。
- **进入→触发→退出**：车已行进，惠帝坐稳 → 木厢轻响与帘缝天光变化，他望向帘外而不掀帘 → 人仍坐车内，车继续向城外走，为 S011 外景揭示方向。
- **目标/表演/空间**：他的即时任务是透过帘缝辨认外界；阻力是封闭车厢与被动移动。上身重心跟车轮轻微晃动，视线转向帘外，手可以压住座缘但不新增抛物或挣扎。车内后帘、窗/门与外车体的物理连接 UNKNOWN，不先固定反拍。
- **Look/Air/声**：LA04／`LLS-P05-TRAVEL-R1`／`ATM-INTERIOR-CLEAN-R1`；帘外天光只因帘摆/行进变化，不无源闪烁。木响、轮声是接 S011 的声音桥。依赖 C01 同脸跨年龄、K02、P05 车内外尺寸/帘结构。

### S011｜洛阳城外道路·日

- **因/功能/信息**：车内被动移动在外景变为明确的**离开洛阳**；城门必须留在队伍身后而非目的地前方。
- **进入→触发→退出**：同一封闭车驾从城门所在方向驶出，少量军士护送 → 车沿出城路继续远离，城门相对距离增大 → 车仍朝前，故事转到由战争耗损的农田。
- **目标/调度/空间**：护送者保持车旁/车后可解释位置，牛在车前牵引，车辙随轮产生；不新设追兵或劫车。车与城门必须在同一世界方向关系内；P05 侧形可见、S01 城门只提供同侧局部，城外道路与车体比例 UNKNOWN，旧帧单凭画面左右不放行。
- **Look/Air/声**：LA04／`LLS-S06-DEPARTURE-R1`／`ATM-OUTDOOR-CLEAN-R1`；阴天、若地面湿干未证则不新增明显扬尘。牛步/车轮/低声甲片连续 S010 木响，直到车队远去。依赖 P05 机械/车身一致、出城方向状态帧。

### S012｜荒废农田·黄昏

- **因/功能/信息**：宫廷对皇帝/玉玺的争夺转为无人耕作的可见后果；没有烧村或尸体奇观。
