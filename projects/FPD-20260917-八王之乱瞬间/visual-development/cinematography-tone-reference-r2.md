# 《洛阳无赢家》电影摄影与物理质感基准 R2

Project ID：`FPD-20260917-八王之乱瞬间`；日期：2026-10-09。继承 [R1](cinematography-tone-reference-r1.md) 的五段色彩弧线和历史边界；本版把“电影质感”落实为可检查的光、空气、材质与摄影决策。片名只供人沟通，不作为模型必须模仿的对象。

## 核心气质

这是一段被镜头亲历的西晋政治动荡，不是英雄海报。画面应有生活和历史材料的重量：人物允许被建筑压小、被门框或帘缘遮住；不强求每张都正面、居中、清晰地展示主角。颜色克制但不灰死；皮肤保有自然血色、年龄纹理及不完全均匀的受光。阴影有层次，亮部不泛白，局部黑暗允许存在，但手与道具接触、衣冠和叙事信息仍可读。

**全片风格定名：克制的历史政治悬疑现实主义。**摄影机像站在事发现场的目击者，先观察权力如何进入、转手和离开，再看普通人承受的后果。片头让观众先听到和看到威胁的迹象，最后仍让威胁留在远方；中段不拍成英雄武侠、宫斗华服秀或灾难奇观。电影感主要来自可辨认的空间关系、真实承重、来源明确的光，以及镜头敢于停留，不靠高饱和、烟、光束和频繁推拉。

可直接放入图生视频提示词的**全片成像母句**：西晋历史纪录片式剧情重演，摄影机处于真实空间中的观察位置；人物、道具与建筑保持首帧身份及尺度。低饱和但保留自然肤色和泥土、旧木、粗布、铁、玉的本色；阴天或既有实用光源塑造柔和亮部与有层次的深暗部。局部磨损、雨水、泥痕和衣料重力可见，空气只按本镜已批准状态变化。一个连续镜头，只完成本镜规定的动作；不做古装海报、游戏CG、青橙滤镜、HDR、体积光、无来源烟尘或自动转场。实际每镜还须加自己的时间、机位、动作及光源，不能只复制这段母句。

摄影参考保持原批准关系：雨城与危险感借《绣春刀Ⅱ：修罗战场》，大殿尺度借《荆轲刺秦王》与《末代皇帝》，荒野材料重量借《投名状》，流亡段的远距离观察与留白借《刺客聂隐娘》。只取可观察的光线、色彩、尺度和表演强度；不复制这些影片的具体镜头、朝代服饰、兵器或建筑。

## 开场连续性锁：SH01 → SH02

SH01 的窄缝底图没有人物且透出暖色低太阳，SH02 静帧则是冷灰阴天、门全开、领骑已靠近门槛。两张图不能仅靠“保持一致”四字当作已对位的首尾帧。正式投视频前，以 SH02 的冷阴天、城门结构和摄影轴线为准，补核或补做一张 **SH01 末态构图帧**：同一机位、同一城门已开到可通行，雾里仅有很远、不可辨脸与人数的骑影。SH01 从无人窄缝发展到这个末态；SH02 从这些远影向门槛行进，不允许在剪点瞬间凭空出现近景骑兵。若补帧前先试片，SH01/02 仅视为技术测试，不视为可直接拼接的成片段落。两镜同用冷阴天晨光，不能一镜金色夕阳、一镜蓝色阴天。

## 光与材料的执行规则

| 场景 | 有来源的光 | 可见的材料反应 | 空气状态／禁止项 |
|---|---|---|---|
| S001 城门清晨 | 门外冷晨光经门洞进入，门内较暗；开门只扩大入光范围 | 受潮门木只有边缘局部低反光，石泥路不均匀湿亮 | 门外低位晨雾，门洞稍稀；不变成白色烟墙 |
| S002 雨后街巷 | 阴天散射光；水面只有天空的破碎反射 | 蹄边泥水、路边粗布和墙脚各有不同湿度 | 只在一次蹄水接触点有低小水花；无全街烟尘 |
| S003 宫阶雨中 | 阴天光照开放石阶，门内较暗；火盆只影响局部 | 青纸吸水、朱印边缘轻渗、石阶积水不均 | 雨在开放处可见，门内减弱；不叠烟和光柱 |
| S004／S006 大殿 | 既定门窗冷天光与少量油灯；人物、柱、帘受同一光向 | 旧木哑光，手常触处略亮；石阶磨损局部而非全局纹理 | 清洁空气。不得为“电影感”加浮尘、浓雾或体积光束 |
| S008 北方荒野 | 阴天自然光，云层让地表有缓慢明度差，不出金色边光 | 干草、土、旧铁和马具各有自身粗糙度 | 五骑蹄下允许极少贴地微尘，只在干土接触处；不形成尾随尘墙，远地形仍清楚 |
| S011 牛车离城 | 阴天天光；车、路、城门靠自然明度分层 | 现有 S06 底图有湿泥和水洼；轮下可有压痕和局部湿泥，不改成干沙路 | 不扬尘；无炊烟、战争烟和滤镜雾 |
| S013 流民路 | 既定暮光从云层均匀落下，不逆光镶金边 | 泥路有水洼，粗布吸光，母子仍能读出衣褶 | 不扬尘、不加烧村烟；距离感来自人物大小和地形层次 |
| S016 夜城 | 月夜弱环境光与近处火盆；远火只在远处显现 | 旧甲与城垛近火侧只有窄而弱的暖反光 | 高空云可见，城外地面仍黑；远火不照亮守军脸 |

## 成像限制

- 景深服务距离关系：近景可有自然背景虚化，远景仍保留城门、道路或帝座的可读性；不使用全画面糊化掩盖结构。
- 允许局部曝光不均、自然遮挡、轻微粗糙与非完美排列；不改已锁定的中轴镜位或主体数量。
- “胶片颗粒”若作为后期选择，应细弱、全片统一地评估；它不是空气中的灰尘，也不能替代皮肤和织物细节。
- 禁止统一青橙、蓝灰滤镜、强黑柔泛光、HDR、假漏光、强暗角、全局浮尘、无来源光束与每件物体同样脏旧。

## 使用顺序

先确认场景底图与单一时刻的构图，再固定人物／道具参考，最后写本镜真正可见的光和物理响应。每镜最多强调一两个有辨识度的质感细节；其余由批准资产承担。若模型输出“棚拍感”，优先检查人物位置、光源、材质接触和参考图冲突，不靠追加“电影感、8K、大师级”等形容词补救。
