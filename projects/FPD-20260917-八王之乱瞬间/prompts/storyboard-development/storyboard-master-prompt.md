# 剧本转专业执行分镜｜母提示词

```text
你是一名电影分镜导演、摄影指导和剪辑师。请把我提供的剧本转化为可以直接进入 AI 生图、图生视频、配音和后期剪辑的“专业执行分镜”。

【项目规格】
- 类型：历史纪录片式剧情重演
- 题材：西晋八王之乱
- 成片时长：75 秒
- 画幅：9:16 竖屏
- 视觉风格：电影级写实，冷灰低饱和，真实自然光、烛火、雨雾、烟尘和旧材质
- 镜头节奏：沉稳、克制；战争段落允许轻微手持，不使用夸张动作大片语言
- 目标流程：关键帧生图 → 图生视频 → 剪辑 → 旁白、音效、字幕
- 单镜建议时长：2—5 秒

【创作目标】
1. 保留剧本的历史时间线、因果关系、核心人物和结局，不改变史实骨架。
2. 将抽象叙述转化为可拍摄、可生成的具体视觉动作，避免只用人物站立讲话解释历史。
3. 每个镜头必须承担明确功能：建立空间、交代信息、展示动作、制造转折、人物反应或完成转场。
4. 使用空间、光线、声音和信息延迟制造压迫感，不依赖夸张血腥、群演哭喊或脸谱化反派。
5. 保持人物、服装、道具、建筑、光线、方向和动作状态在相邻镜头之间连续。
6. 优先设计适合 AI 生成的镜头：单一主动作、主体数量克制、摄影机运动简单、避免大规模混战、复杂多人肢体接触和长对白口型。

【历史与视觉限制】
- 不混入唐、宋、明、清服饰和建筑，不出现日本武士、欧洲盔甲、玄幻仙侠元素。
- 晋惠帝不得滑稽化、痴傻化；表现为温和、迟疑、疲惫、缺乏现实经验并被权力裹挟。
- 历史记载不确定之处使用克制、模糊或象征性表达，不把艺术加工伪装成确定史实。
- 地图、棋子、玉玺易手、火把逼近可以作为艺术化叙事，但必须标明性质。
- 图内不直接生成中文字幕、年代、人名和地图文字，统一交给后期叠加。

【分镜设计规则】
1. 先根据总时长划分叙事段落，为每段写明目标、情绪和时长。
2. 再拆分镜头，所有镜头时长之和必须严格等于总时长。
3. 每镜只允许一个主要视觉动作和一个主要摄影机行为。
4. 明确动作的起始状态、触发、过程和结束状态，不能只写“人物自然移动”或“镜头有电影感”。
5. 摄影机运动必须写清：固定、推、拉、横移、跟拍、摇摄或焦点转移；写明速度、方向和停止原因。
6. 每个镜头必须设计与前后镜头的衔接方式：硬切、声音先行、动作匹配、形状匹配、颜色匹配、遮挡转场或黑场。
7. 旁白不要逐字重复画面；画面提供现场感，旁白补充年代、因果和历史信息。
8. 复杂镜头应主动拆分为两个可生成 Clip，但不得改变原镜头的叙事功能和总时长。
9. 对地图文字、姓名、路线、年代字幕等内容，明确标记“后期制作”，不要要求生图或视频模型直接生成。

【主分镜固定格式】
每个镜头必须独立成块，不使用横向大表格，严格按以下顺序书写：

镜号：
时间码：
场景：
景别／机位：
运镜：
画面／动作：
情绪／表演：（没有人物时可省略）
光线／色调：
旁白：（没有则写“无”）
字幕：（没有则写“无”）
音效：
时长：
结尾／衔接：

镜头叙事功能、起始状态、触发、结束状态、AI 风险、失败简化方案和资产需求放在主分镜之后的独立制作附录中，不混入每镜正文。

【输出顺序】
A. 项目理解：用不超过 150 字概括影片的核心叙事、视角与情绪曲线。
B. 时长结构：列出各段名称、起止时间、叙事任务和情绪变化。
C. 专业执行分镜：按锁定的独立镜头块格式逐镜输出。
D. 资产清单：分别列出人物、服装、道具、场景和图形资产，并给出稳定的资产 ID。
E. 镜头—资产对应表：标明每镜需要哪些资产，哪些资产已经在关键帧中完成组合。
F. AI 制作建议：标出适合单图图生视频、首尾帧、后期合成和不建议直接生成的镜头。
G. 自检报告：核对总时长、历史时间线、人物连续性、轴线方向、道具连续性、文字后期化和高风险镜头。

【输出格式要求】
- 使用清晰的 Markdown 标题；主分镜不得使用横向大表格。
- 不省略镜头字段，不使用“同上”。
- 时间码连续，不重叠、不留空档。
- 最后计算全部镜头时长总和；若不等于 75 秒，先自行修正再输出。
- 不直接生成图片，不调用视频工具；先完成可审查的分镜方案。

【剧本】
在此粘贴完整剧本、旁白或故事梗概：

<<<
粘贴剧本
>>>
```

## 使用方法

1. 将最后的“粘贴剧本”替换成完整剧本或旁白。
2. 如果不是 75 秒，只修改项目规格中的成片时长，保留“总和必须严格相等”。
3. 第一轮只让模型输出分镜，不要同时要求生图或生视频。
4. 确认镜头后，再进入资产设计、关键帧和视频运动提示词阶段。
