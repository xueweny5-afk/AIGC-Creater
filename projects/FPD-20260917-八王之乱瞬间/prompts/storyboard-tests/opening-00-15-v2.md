## 为什么拆成 5 个生成单元

剪辑上仍是“城门开启—骑兵入城—马蹄与百姓—雨中诏书—宫门闭合”五个视觉节拍。SH04A 与 SH04B 共同承担剧本中最后五秒，但诏书微距与宫门全景在主体、尺度和运动上差异过大，拆开生成后硬切，稳定性和电影感都更好。

## 全局视觉合同

- 历史纪录片式剧情重演，西晋洛阳，电影级写实，冷峻克制。
- 冷灰、铅蓝、湿土褐为主色，只允许旧军旗、朱印和少量火盆出现暗红或暗橙。
- 阴天晨光来自城门外侧；雾、雨、湿泥和纸纤维只对既有光线作物理响应，不自发发光。
- 真实夯土、旧木、铁铆钉、泥水、粗织物和磨损甲片；表面以哑光、吸水和使用痕迹为主。
- 摄影保持低运动：一次镜头只保留一个主体动作和一个摄影机行为。
- 字幕、年代、人名和可读诏书文字全部后期添加；生成画面中不写字。
- 西晋物质文化边界：不得出现唐宋明清服饰、明清城楼、清宫金饰、日本武士、欧洲盔甲、玄幻特效或现代物品。

## `@` 引用规则

- 本文件中的 `@START_* / @END_* / @SCENE_* / @WARDROBE_* / @GROUP_* / @STATE_* / @PROP_*` 是稳定的逻辑别名，不假装任何平台天然认识。
- 实际生成前必须按每镜“上传与 `@` 绑定表”依次上传，再把逻辑别名替换成当前入口显示的 `@图1 / @图2` 或实际媒体槽。
- `START` 控制视频 0 秒的完整画面；动作从该画面之后继续。
- `END` 只控制结束状态；不得把尾帧已有动作复制到 0 秒或重复执行。
- 人物、服装、场景、道具参考只控制各自字段，不能相互覆盖；STYLE 或构图参考不能改写硬锚点。
- 标记为 `PLANNED` 的文件尚不存在，只能先用于生成计划；实际文件生成并审核前，不得上传或把对应 Unit 标为 READY。

## SH01｜00:00—00:03｜晨雾城门开启

### 任务

- 方式：`CREATE START KEYFRAME` → `START/END I2V`
- 新起始帧目标：`storyboard/frames/SH01-城门晨雾/SH01-城门晨雾-start-v2.png`
- 结束锚点：`assets/locations/S01-洛阳城门/S01-洛阳城门-晨雾-v1.png`
- 代表瞬间：城门尚只开启窄缝，雾后骑兵仍不可辨认。

### 起始关键帧生成／编辑提示词

> 以参考图中的西晋洛阳城门为完全锁定的建筑与材质基准，保持同一夯土墙、木构城楼、包铁旧木门、铁铆钉、兵器架、湿泥地面、晨雾、冷灰晨光和 9:16 中轴构图。把当前大开的两扇城门改为刚刚启动的状态：沉重门扇只向内开启约一成人宽的窄缝，缝外是浓雾和极弱冷白天光，远处只有三至五个无法辨认面孔与甲胄细节的骑兵暗影。前景泥水静止，木门因长期受潮呈深色哑光，门轴附近有真实磨损，不出现人物近景，不出现字幕或可读文字。电影级写实历史纪录片重演，35mm 自然透视，深景深，冷灰低饱和，细微胶片颗粒，克制、压抑、没有英雄入场感。

### 视频提示词

> 从窄缝城门的起始帧继续。0.0—0.6 秒，摄影机和城门短暂停住，晨雾先从门缝中缓慢涌入，远处低沉马蹄声逐渐接近。0.6—2.6 秒，两扇沉重湿木门以相同速度向内缓慢开启，门轴运动有真实重量和轻微阻滞；摄影机只做极慢、笔直的前推。门外骑兵始终只是雾中暗影，轮廓略微清楚但看不见脸。2.6—3.0 秒，门开启到结束参考图的宽度后停止，雾继续流动，切入下一镜。保持城墙、门楼、铁件、兵器架和地面完全不变；门扇不能弯曲、融化或穿插。

### 排除项

> 不突然全开，不高速推镜，不把雾变成烟火，不新增军队，不出现太阳圣光或英雄剪影，不改变门楼结构，不让旗帜剧烈摆动，不生成文字、水印、标志，不出现明清城门或奇幻巨城。

### 验收点

- 起始与结束必须是同一座城门、同一机位、同一晨光。
- 开门是唯一主要动作；雾是从属环境反应。
- 骑兵在本镜不得提前清晰亮相。

### 排除项

> 不冲锋、不扬蹄嘶鸣、不挥舞长戟、不整齐齐步、不新增骑兵和旗帜；不改变领骑面孔、头盔、甲胄、马匹毛色、门楼或队形；不出现外露马镫特写，不出现夸张镜头震动、速度拉丝、强逆光、尘暴、字幕或水印。

### 验收点

- 运动方向和 SH01 一致，始终由城外进入城内。
- 马匹是有重量的步行，不是冲锋或漂移。
- 画面注意力只落在“军队进入”，不要同时制造打斗。
