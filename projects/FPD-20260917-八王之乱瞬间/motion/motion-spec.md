# 《洛阳无赢家》Motion Spec

- Project ID：`FPD-20260917-八王之乱瞬间`
- 状态：`READY FOR PROMPT ADAPTATION`
- 画幅：9:16
- 成片时长：75 秒
- 运动原则：每镜只保留一个主要动作和一个摄影机行为；人物身份、建筑、甲胄、道具形制与首帧构图锁定。
- 生成策略：平台统一生成 5 秒母片，剪辑时按计划时长取有效区间；SH04、SH12 在镜内拆成两个生成 Clip。

## 逐镜运动合同

### SH01｜3 秒｜洛阳城门晨雾

- 输入角色：START。
- 0.0—1.2 秒：城门与摄影机 HOLD，雾气横向缓慢流动，远处只有模糊骑兵轮廓。
- 1.2—2.5 秒：摄影机极慢直线推近；轮廓略清晰但不显露面孔。
- 2.5—3.0 秒：沉重城门刚开始向内移动即停止。
- 物理／声音触发：远处马蹄渐近；门轴受力缓慢启动。
- 结束状态：门内出现窄黑缝，供 SH02 切入。
- 风险简化：门体若变形，取消开门，只保留雾与推近。

### SH02｜3 秒｜骑兵入城

- 输入角色：MID，骑兵已经进入门洞。
- 0.0—2.4 秒：战马稳步前行；摄影机以相同速度缓慢后退；长戟与旧旗仅随步态轻摆。
- 2.4—3.0 秒：前马接近画面下缘，前蹄准备落地。
- HOLD：士兵不看镜头、不挥兵器；建筑形体不变。
- 结束状态：以下一镜马蹄落水方向收尾。
- 风险简化：优先保住马体结构和军装，删除旗帜运动。

### SH03｜4 秒｜马蹄与百姓避让

- 输入角色：MID，马蹄正接近积水。
- 0.0—1.0 秒：前蹄落入积水，形成一次小范围泥水飞溅。
- 1.0—3.2 秒：战马继续稳步通过；相机贴地轻微后退，百姓只做低头和收袖。
- 3.2—4.0 秒：泥水涟漪衰减，后方骑兵略靠近。
- HOLD：不得展示骑手脚部和马镫；百姓不齐刷刷跪拜。
- 结束状态：水面涟漪可硬切诏书雨滴。
- 风险简化：若马腿畸变，改为固定机位，仅动画水滴与背景雾。

### SH04A｜3 秒｜雨中青纸诏

- 输入角色：START。
- 0.0—2.5 秒：摄影机极慢推近；雨滴落下，墨迹和朱印向纸纤维轻微扩散，纸角被风抬起后落回。
- 2.5—3.0 秒：雨势与推近 HOLD，为硬切蓄力。
- HOLD：纸面不得出现新增或可读文字。
- 结束状态：朱印占据注意中心，硬切 SH04B。

### SH04B｜2 秒｜宫门闭合

- 输入角色：MID，门扇已经接近闭合。
- 0.0—1.6 秒：两扇门依靠自身重量缓慢合拢；门缝冷光连续缩窄；雨水沿阶面流下。
- 1.6—2.0 秒：门体撞合并停止，光缝只剩极细一线；火焰轻晃。
- 摄影机：固定。
- 结束状态：一线冷光匹配 SH05 殿门视角。

### SH05｜3 秒｜晋惠帝独坐空殿

- 输入角色：START。
- 0.0—2.5 秒：摄影机沿门缝极慢推进；晋惠帝保持坐姿，只在 1.5 秒后轻微抬眼。
- 2.5—3.0 秒：摄影机停止，人物 HOLD。
- HOLD：嘴部、双手、帝座、冠服不动；不增加群臣。
- 结束状态：前景帘影轻动，引向 SH06。

### SH06｜4 秒｜群臣影子切割人物

- 输入角色：MID。
- 0.0—3.4 秒：摄影机从殿侧缓慢横移；珠帘、木柱和两三名群臣剪影依次掠过前景；晋惠帝只以视线跟随。
- 3.4—4.0 秒：一根柱影完全遮黑画面。
- HOLD：晋惠帝身体不转、不说话；群臣无清晰面孔和大动作。
- 结束状态：黑场匹配地图暗背景。

### SH07｜4 秒｜八枚棋子趋近洛阳

- 输入角色：REFERENCE；棋子运动为抽象动画。
- 0.0—3.3 秒：八枚黑棋分三批短距离滑向中央红点，每枚落定后立即停止；摄影机固定并做极轻数字推近。
- 3.3—4.0 秒：八棋保留小空隙，全部 HOLD。
- 物理：棋子贴着沙盘表面平移，不漂浮、不跳动。
- 结束状态：尚未完全合围，接 SH08。
- 风险简化：生成模型若无法保持八枚数量，则只动画光影，棋子移动在后期完成。

### SH08｜4 秒｜八王完成合围

- 输入角色：END，八枚棋子已就位。
- 0.0—3.2 秒：摄影机缓慢推近中央红点；周围环境光逐渐降低。
- 3.2—4.0 秒：最后一次木质落子声后全画面 HOLD。
- HOLD：必须保持恰好八枚；不生成姓名和地图文字。
- 结束状态：中央红点充满注意区域，匹配玉玺色彩。

### SH09｜3 秒｜司马伦取玺

- 输入角色：MID，手已覆盖玉玺。
- 0.0—1.8 秒：右手施力，将玉玺从木案抬起约一个掌高；绶带受重力延迟垂落。
- 1.8—2.7 秒：光学焦点从玉玺转到司马伦面部；人物神情不变。
- 2.7—3.0 秒：动作停止。
- HOLD：不奸笑、不改变玉玺形制和手指数量。
- 结束状态：玉玺停在画面中部。

### SH10｜3 秒｜司马伦登阶

- 输入角色：MID，人物正在最后两级台阶。
- 0.0—2.4 秒：司马伦完成两步登阶；玉玺垂在身侧，绶带随步态小幅摆动；摄影机极慢前推。
- 2.4—3.0 秒：人物在帝座前停下；群臣只做幅度不同的俯首。
- HOLD：不转身、不坐下、不形成庆典。
- 结束状态：人物占据帝座中轴。

### SH11｜4 秒｜诸军汇向洛阳

- 输入角色：REFERENCE。
- 0.0—1.2 秒：摄影机较快推近沙盘中央后减速。
- 1.2—3.5 秒：三至四条行军路线由画面边缘依次向洛阳绘入，三枚小旗轻微立起。
- 3.5—4.0 秒：最后一路抵达中央，画面 HOLD。
- 说明：路线与标签优先在后期绘制，视频模型只负责沙盘光影和轻推。
- 结束状态：一条路线越过画面边缘，匹配荒野骑兵方向。

### SH12A｜2 秒｜荒野五骑

- 输入角色：MID。
- 0.0—2.0 秒：五骑保持松散间距从左向右横穿；相机侧向跟随，前景枯草产生运动模糊；旧旗只做一次风摆。
- HOLD：骑兵数量固定为五；不接近镜头，不显示马具细节。
- 结束状态：骑兵离开画面右侧，马蹄声转为心跳。

### SH12B｜3 秒｜玉玺易手蒙太奇

- 输入角色：MID，双方已接触玉玺。
- 0.0—1.6 秒：右侧双手承接重量，左侧手松开绶带；玉玺仅移动短距离。
- 1.6—2.3 秒：交出者退入黑暗，第三只手稍靠近但不完成第二次交接。
- 2.3—3.0 秒：玉玺与承接者 HOLD。
- 说明：三次易手由同一条成功视频在剪辑中重复、翻转节奏和遮黑完成，不要求模型一次完成三次。
- 结束状态：暗色袖口或绶带遮满画面，接车帘。

### SH13｜3 秒｜晋惠帝车内

- 输入角色：START。
- 0.0—2.4 秒：车体产生低频小幅摇晃；窗帘被气流掀开一次，冷光扫过眼睛；晋惠帝目光转向帘外。
- 2.4—3.0 秒：帘幕回落，人物保持沉默。
- HOLD：嘴部、冠服、面部身份稳定；不做惊恐转头。
- 结束状态：视线停在窗外，切主观远景。

### SH14｜4 秒｜车驾离开洛阳

- 输入角色：MID。
- 0.0—3.5 秒：牛车和护卫沿右前方道路缓慢离城；木轮连续滚动并扬起少量灰尘；摄影机缓慢拉远。
- 3.5—4.0 秒：旧旗扫过画面局部，洛阳仍位于左后方。
- HOLD：方向不可反转；车不得驶向城门；护卫规模不增加。
- 结束状态：暗红旗布可匹配荒田破旗。

### SH15｜4 秒｜荒废农田

- 输入角色：START。
- 0.0—3.4 秒：摄影机水平缓慢横移，依次经过破旗、废弃农具和空粮袋；远处薄烟缓慢上升。
- 3.4—4.0 秒：一个小型人物背影从前景边缘进入，但不显脸。
- HOLD：不扩大为壮观火灾，不新增战斗和尸体。
- 结束状态：背影运动方向接 SH16。

### SH16｜4 秒｜母子加入队伍

- 输入角色：MID，母子已经牵手行走。
- 0.0—3.2 秒：母亲与孩子沿泥路稳步向远处前行；衣摆受步态和微风轻动；前方旅人保持松散间距。
- 3.2—4.0 秒：相机极慢推近牵手位置后停止。
- HOLD：二人不回头、不奔跑、不哭喊；背景村庄不燃烧。
- 结束状态：暗橙暮光点占据远处小区域，匹配地图红点。

### SH17｜3 秒｜八王棋子暗下

- 输入角色：END，多数棋子已经倾倒。
- 0.0—2.4 秒：照亮棋子的局部光按由外到内顺序逐个熄灭；最后一枚直立棋子的高光消失。
- 2.4—3.0 秒：只保留中央暗红点和极弱环境光。
- HOLD：八枚棋子数量、位置、倒伏状态不变。
- 结束状态：中央红点匹配空殿玉玺。

### SH18｜3 秒｜空殿玉玺

- 输入角色：START。
- 0.0—2.2 秒：摄影机从玉玺极慢拉远；绶带末端被穿堂风抬起一次后落下；远处宫灯依次熄灭。
- 2.2—3.0 秒：最后灯火熄灭，空间进入冷黑。
- HOLD：玉玺不移动、不旋转；不增加人物。
- 结束状态：最后一点火光可匹配城外远点。

### SH19｜3 秒｜城外纯黑至单火点

- 输入模式：START_END；SH19 为 START，SH20A 为 END。
- 0.0—1.8 秒：摄影机、守军、城垛 HOLD；云层极慢移动，荒野保持纯黑。
- 1.8—2.5 秒：地平线偏右出现唯一一个微弱火点。
- 2.5—3.0 秒：火点稳定，守军仅轻微前倾。
- 结束状态：与 SH20A 完全一致。

### SH20｜3 秒｜单火点扩展为火线

- 输入模式：START_END；SH20A 为 START，SH20B 为 END。
- 0.0—0.6 秒：唯一火点 HOLD，保留识别停顿。
- 0.6—2.5 秒：火点两侧不规则出现更多微小火把，逐渐连成断续火线；薄雾轻移。
- 2.5—3.0 秒：火线密度到达尾帧状态但不快速逼近。
- HOLD：相机、月亮、城垛和守军位置锁定；不出现军队身份。
- 结束状态：远方火光开始映亮城垛边缘。

### SH21｜3 秒｜守军握戟与黑场

- 输入角色：MID。
- 0.0—1.8 秒：守军呼吸略加重，双手逐步握紧长戟；面部只做压住恐惧的细微反应；火光在半张脸上跳动。
- 1.8—2.2 秒：镜头从握戟手快速上移至眼睛后停止。
- 2.2—3.0 秒：剪辑阶段加入城门撞击声并硬切纯黑；不要求生成模型表现撞门。
- HOLD：不喊叫、不挥戟、不出现敌军。
- 结束状态：纯黑，后期叠加 311 与 316 年字幕。

## 连续性与失败简化顺序

1. 先保人物身份、建筑和道具形制。
2. 再保主动作和结束状态。
3. 再保摄影机方向与相邻镜头匹配。
4. 次级雾、衣摆、火焰和群体微动可以删除。
5. 不以新增人物、放大战争或复杂运镜弥补失败。
