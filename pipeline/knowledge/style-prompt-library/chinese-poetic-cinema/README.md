## 适用范围

古典庭院、江南雨巷、荷塘水境、山水行旅等以安静观察、空间留白和叙事停顿为核心的画面。可用作单帧、关键帧和图生视频的风格参考。原文中的 Midjourney、Image 2.5 和视频适配建议是来源文件的写法，实际使用时应核对当前模型能力和参数。

## 可复用的风格要素

| 维度 | 提炼结果 |
|---|---|
| 人物与叙事 | 人物融于环境，以克制动作、视线和停顿暗示故事前后；抽象情绪要落实为可见现象。 |
| 观察方式 | 从门、窗、帘、檐、花枝或水对岸观察，让遮挡和距离承担含蓄感。 |
| 构图与空间 | 非对称平衡、框景和留白；明确前景、中景、远景，人物与环境比例由叙事决定。 |
| 光线 | 写清光源、经过的介质和受光位置；让花影、窗影、水影等有实际来源。 |
| 色彩 | 以克制的主色和少量视觉锚点组织画面；具体色彩随场景变化。 |
| 材质 | 老木、纸、布、瓦、石、水与草木等应呈现可观察的物理状态。 |
| 时间与运动 | 用檐水、帘、枝叶、水纹等小变化表现时间；镜头运动应服务当前场景。 |

来源文件的组织顺序是“人 → 境 → 观 → 构 → 层 → 光 → 色 → 质 → 动 → 情”。这是一种检查顺序，成品提示词不必机械填满十项。

| `cf153561` 雨夜街巷 | 高位远望，屋檐和树叶围住街巷；暖灯、湿瓦和檐水共同组织空间 | 夜雨写成“灯具发光 → 雨/湿瓦反射 → 行人经过”的关系，不用无来源的泛金光 |
| `d80aad17` 桥上 | 花枝、石栏和水道层层遮挡，人物只露出局部；水和花瓣提示时间 | 允许人物被遮住一部分，但要保留姿态或视线线索，并指定一项可持续的环境变化 |

据此，镜头设计增加四个检查点：

1. **密度与可读性同时检查。** 留白可以是水面、暗部或人物周围的轮廓通道，不等于背景必须空。密集枝叶、屋檐和建筑可以形成层次，但不要吞掉叙事动作。
2. **光写成局部事件。** 确定一个主要光源、入射方向、被照亮的材质和可见反射。冷暖关系由时段和场景物件支撑；暗部保留木、瓦、石、布的层次。
3. **每镜只挑一个视觉锚点。** 可以是红衣、白衣、书页或灯；不要让花、雾、雨、灯和发光粒子同时争夺注意力。
4. **让动态有因果。** 风吹芦苇与衣摆，雨形成檐水与地面反光，水流带动花瓣；人物动作与这些变化处在同一时刻。图生视频时先保持机位和空间结构稳定，再选择一项主要环境动态。

这些截图集中在古装人物、江南水境与雨雪光影，适合作为这一支风格的参考，不能代表全部中式美学。它们也不能单凭单帧证明运动方式、历史服制或场景拓扑准确。

## 复用时的最小写法

```text
在{具体地点与时刻}，{人物}正{可见动作}。摄影机从{有叙事理由的观察位置}看向人物；{有空间来源的前景}形成{遮挡/框景}，{中景}承载动作，{远景}交代环境。即使环境密集，也让{人物轮廓或关键动作}清楚可读。{实际光源}从{方向}经过{介质}，只照亮{受光材质与局部反射}；{主色}中以{来自具体物件的单一色彩锚点}引导视线。{风/雨/水等原因}带动{一项主要微动态}，画面停在{叙事变化或悬念}。
```

按具体场景删去无作用的字段，不默认加入雾、颗粒、柔焦或古风道具。项目已批准的人物身份、时代、建筑和服装优先于风格条目；模型专用写法交由现有 `film-prompt-adapter` 处理。
