## 收录方式

当用户说“这是 XX 风格的提示词，你整理收集下”时：

1. 保存用户提供的原始提示词，保留版本和来源说明，不擅自改写原文。
2. 提炼光线、色彩、人物、空间、材质、镜头等可观察的风格特征；只填写原文能支持的内容。
3. 另写一份便于复用的整理版，区分通用风格要素和原提示词中的特定题材、人物、场景。
4. 标明适用任务、已知限制及验证状态；未经过实际生成测试的内容不标为“已验证”。
5. 同一风格的新增提示词归入同一条目或其子目录，并更新本索引；不同风格分别建条目。

以作品或创作者命名的风格，名称只作为检索标签。整理版应描述可观察的视觉机制，不将作品名称直接当作生成指令，也不复制可识别的角色或画面。
