## 可迁移的提示词机制

### 1. 环境不是“风格词”，而是可观察的生活系统

视频中的室内环境提示同时处理实际光源、室内外冷暖关系、旧电视反射、木材磨损、墙面局部污迹、厨房水汽、灰尘和人物活动，并排除影楼年画感、过量红色、豪华现代内装、塑料皮肤和过锐化。

应迁移为：`空间结构 → 表面材料 → 使用痕迹 → 陈设行为 → 空气介质 → 光线响应 → 排除项`。不复制具体北方农村客厅和春节陈设。

### 2. 角色参考需要可分离的身份视图

视频展示正面、侧面、背面、全身和人脸特写资产卡，说明单张定妆图不足以支撑多镜连续性。公共流程进一步增强为：先批准正面人脸身份锚点，再派生头部角度和全身六视图；人物、服装、妆发分开，最后形成组合定妆。

### 3. 视频 Prompt 的有效核心是触发后的表演链

示例镜头使用“画外问题 → 短暂停顿 → 视线轻微变化 → 克制微笑 → 不立即回答”，并同时锁定固定镜头、人物年龄/身份、环境状态和不夸张表演。可迁移的是：`进入状态 → 具体触发 → 可观察变化 → 保持/停止 → 退出状态`，而不是复制对白和人物。

### 4. 负向词承担连续性保护

视频示例的排除项不是通用质量词，而是针对当前风险：不变老、不转成侧背面、不看错方向、不夸张紧张或大笑、不立即回答、镜头不漂浮、皮肤不塑料化。公共方法因此按身份、状态、空间、权利、材质和表演风险选择少量限制。

### 5. 空气介质必须有物理原因

视频提出用灰尘、蒸汽、烟雾或湿润空气增强空间厚度。公共流程只吸收其物理机制：记录介质来源、分布、密度、运动驱动、受光方式和跨镜连续性；拒绝把全局薄雾、漂浮颗粒和胶片颗粒变成统一“去 AI 感”配方。

### 6. 十三项是覆盖检查，不是固定长 Prompt

参考锚点、概念、动态、摄影意图、镜头、场景、色彩、光、构图、表演、时间线、声音和排除项适合用于查漏。最终执行文本仍按任务和模型压缩；不适用或不支持的能力显式登记，不用自然语言伪装。

### 7. 先纠正语义类别，再增加视觉细节

环境示例有一次很有价值的修正：不接受泛泛的“夜晚旧屋”，而是明确为除夕夜的老家客厅，核心是家人真实团圆、各自忙碌的生活状态。随后才补实际灯源、电视反射、陈设、材质和空气。

可迁移顺序是：

```text
宽泛类别
→ 具体地点与事件
→ 人物关系和当前活动
→ 观众必须读到的生活状态
→ 光、材料、空气与声音证据
```

如果第一层语义错误，继续增加纹理、焦距和颗粒只会让错误方向更精致。

### 8. 把镜头时长留给唯一表演事件

菜地人物示例在镜头开始时让人物已经停下劳动、仍扶着工具并保留轻微呼吸，然后由画外提问触发停顿、眼神变化和克制微笑；人物不在本镜立刻回答。这个安排同时降低了动作复杂度，并留下可供下一镜继承的未完成状态。

可迁移为：

```text
previous action already settled
→ preserved bodily residue
→ specific external trigger
→ delayed reaction
→ one small visible change
→ withheld completion
→ observable handoff state
```

### 9. 正向目标与负向限制互相镜像

示例先规定年轻、固定正面机位、克制微笑和不立即回答，再排除老年化、侧背面、镜头漂浮、夸张大笑和马上说话。负向词因此保护当前镜头合同，而不是通用质量词。

### 10. 用注意力预算组织提示词

人物反应是主任务时，摄影机固定，背景只证明农村菜地空间，环境声音和轻风保持低强度；背景不能喧宾夺主。提示词并非元素越多越好，而是一个主注意层、少量支撑层和明确 HOLD 层。

## 两条提示词的功能拆解

### 环境提示词（约 03:21）

| 功能层 | 示例采用的方法 | 可迁移规则 |
|---|---|---|
| 语义校准 | 从泛化旧屋修正为具体节日、老家与家庭活动 | 先确定“这是什么生活时刻” |
| 实际光源 | 室内暖色实用灯、室外冷夜、电视节目反射 | 光必须有来源、方向与材料落点 |
| 陈设与行动 | 物件自然分布，家人各做不同事情 | 场景不是布景清单，人物不为镜头排队 |
| 材料真实 | 木、墙、皮肤、织物有局部使用痕迹 | 缺陷需要位置、尺度和原因 |
| 空气 | 食物热气、厨房水汽和细微尘埃 | 只保留有来源的介质 |
| 成像 | 轻微扩散、自然观察距离、克制锐度 | 黑柔与空气分层，不把成像效果当雾 |
| 声音 | 碗筷、包食物、交谈、儿童活动和远处节庆声 | 声音证明活动和空间，不只是气氛 |
| 排除 | 摆拍、红色过载、现代豪装、塑料皮肤等 | 排除当前最可能的错误默认值 |

### 视频提示词（约 05:20）

| 功能层 | 示例采用的方法 | 可迁移规则 |
|---|---|---|
| 故事坐标 | 章节、过去时期、北方乡村、夏末菜地 | 在动作前声明当前叙事状态 |
| 主体锁定 | 只有一名年轻人物，年龄和生活痕迹受控 | 正向身份状态先于负向限制 |
| 起始状态 | 劳动已经暂停，手仍扶工具，身体保留余势 | 不让镜头从复杂动作最前端开始 |
| 声音触发 | 画外提问引发表演 | 声音可以是动作触发器 |
| 表演链 | 停顿、视线轻变、轻微微笑、不立即回答 | 抽象怀念变成可观察时间链 |
| 摄影机 | 固定、正面、眼平，不发生漂移 | 表演镜头减少摄影机竞争 |
| 背景角色 | 只承担空间证据，不主导注意 | 背景密度和运动从属于主体 |
| 色彩/材质 | 自然日光、低饱和中低反差、肤质与劳动痕迹 | 视觉状态服务时间和人物生活 |
| 声音层 | 菜地底噪、远处昆虫、风、呼吸和衣料 | 区分触发声、环境声和表演声 |
| 终点 | 微笑已经出现，回答尚未开始 | End State 可以是有意未完成 |
| 排除 | 年龄、站位、表演、现代物件、镜头和皮肤风险 | 负向项与正向合同一一对应 |

## 应保留与应压缩的内容

### 适合保留在完整执行合同

- 故事时期和场景语义；
- 参考图职责和身份状态；
- 起始状态、触发、表演顺序与终点；
- 实际灯源、材料反应和有来源空气；
- 声音触发和必要环境声；
- 当前镜头的针对性排除。

### 编译给模型时需要按 Profile 压缩

- 已由参考图稳定承载的长篇外貌描述；
- 同义反复的“真实、生活、自然、克制”；
- 不可直接观察的诗性总结；
- 未核实模型是否理解的成对焦距数字；
- 平台不支持的声音、负向词或精确摄影控制；
- 可以进入外部参数的模型、时长、画幅和分辨率。

## 最终判断

教程最值得吸收的不是某个模型的长提示词，而是把环境细节、参考图职责、动作触发、微表演、固定镜头和针对性排除组织成一个可验证的执行合同。公共 Skill 在此基础上增加资产版本、六视图、服装/妆发分离、场景状态、模型能力回执、连续性和局部返工机制。
