## SCENE DESIGNS

### S001｜相邻摊位通道·清晨

- **Source Range：** S001 全场。
- **Direct Cause：** 故事起点。
- **Scene Function：** 建立无需说明的互助惯例和未被讨论的边界。
- **Entry State：** 两摊尚未完全开市；老摊主先到；通道被空筐占用。
- **Character Objectives：** 老摊主恢复熟悉秩序；邻摊经营者尽快进入多任务营业。
- **Obstacle / Pressure：** 时间和到访者同时开始挤入准备工作。
- **Initial Tactics：** 老摊主直接挪筐并代为回应；邻摊用轻松询问确认默契。
- **Shift Trigger / New Tactics：** 使用者把纸条夹在共享位置；双方从偶然补位进入默认托付。
- **Performance Actions：** 老摊主不停止手中工作便指出夹子；邻摊把备用夹子留在两摊之间；双方都不正式道谢。
- **Blocking & Spatial Power：** 老摊主先掌握通道秩序；邻摊进入后，两人各守工作面，共享物位于分界而非任何一方深处。
- **Audience Beat：** 先感到熟悉顺畅，再意识到这种顺畅依赖一方主动补位。
- **Information Design：** 观众知道惯例存在；人物把它视为无需说明；互助上限保持未知。
- **Sound / Silence / Time：** 卷帘门、摆放和零散询问建立开市节律；对话夹在劳动中，不形成专门谈心时刻。
- **Required Assets / State Changes：** LOC-E01 基础拓扑；夹子全量共享；空筐位置变化。
- **Must Show / Withhold / Avoid：** 必须看见物件跨到共享区；不展示人物家庭背景；避免亲密化表演。
- **Turn / Exit State：** 默认互助成为可重复机制。
- **Next-scene Trigger：** 零散请求增加，使默认机制开始挤压个人工作。

### S002｜相邻摊位通道·上午

- **Source Range：** S002 全场。
- **Direct Cause：** S001 建立的默认托付被更频繁使用。
- **Scene Function：** 让善意互助显露未经协商的成本。
- **Entry State：** 夹子共享；老摊主可代为回应；双方仍认为惯例有效。
- **Character Objectives：** 邻摊希望减少混乱；老摊主希望保住自己的工作顺序和决定权。
- **Obstacle / Pressure：** 同时发生的询问、托付和未完成工作让补位出错。
- **Initial Tactics：** 邻摊提出集中处理；老摊主用反问阻止对方替自己安排。
- **Shift Trigger / New Tactics：** 邻摊解释善意仍未消除被安排感；老摊主把托付物推回边界另一侧。
- **Performance Actions：** 找错一包后立即放回；说话时继续处理自己的货；邻摊接回物品并收回夹子，不追着解释。
- **Blocking & Spatial Power：** 托付物从老摊主工作面退回邻摊；共享位置被撤销，空间边界重新变清楚。
- **Audience Beat：** 从轻微忙乱转为克制的不适；没有谁被判为恶意。
- **Information Design：** 双方知道问题存在，但各自以效率或自主理解它。
- **Sound / Silence / Time：** 订单提示与询问形成中断；夹子被收回后，短暂缺少原有交接声。
- **Required Assets / State Changes：** 夹子从共享区收回；托付物归还；老摊主未完成工作可见。
- **Must Show / Withhold / Avoid：** 必须看见撤回托付；不升级成争吵或围观。
- **Turn / Exit State：** 默认互助暂停。
- **Next-scene Trigger：** 双方必须亲自承担暂停后的实际后果。

### S003｜相邻摊位通道·另一日上午

- **Source Range：** S003 全场。
- **Direct Cause：** S002 的拒绝使两摊各自处理工作。
- **Scene Function：** 展示暂停互助的差异化后果，并让双方重新认识旧习惯的功能。
- **Entry State：** 夹子不共享；邻摊使用暂停牌；老摊主不代为接单。
- **Character Objectives：** 两人都守住刚建立的边界，同时维持各自营业。
- **Obstacle / Pressure：** 使用者并不作统一反应；等待、离开和继续购买同时发生。
- **Initial Tactics：** 老摊主只回答自己负责的事项；邻摊回来后自行承担等待。
- **Shift Trigger / New Tactics：** 老摊主重复擦拭已经干净的托盘时停下；无效重复第一次被本人中止。
- **Performance Actions：** 老摊主不给暂停状态找借口；邻摊处理完等待者后不追问；双方通过继续工作观察结果。
- **Blocking & Spatial Power：** 各自停留在自己的工作面；使用者的等待与离开使通道承担反馈，而非成为围观区。
- **Audience Beat：** 不适转为清醒；观众发现旧节律既有负担也有关系功能。
- **Information Design：** 人物没有共享总结；观众通过不同使用者和停止擦拭获得更完整信息。
- **Sound / Silence / Time：** 暂停牌减少交接声；擦拭停止后的空拍节律由环境继续填充，不加情绪性对白。
- **Required Assets / State Changes：** 暂停牌；夹子收回；托盘仍在但重复步骤中止。
- **Must Show / Withhold / Avoid：** 必须保留三种使用者反应；避免把离开者写成惩罚或把等待者写成忠诚。
- **Turn / Exit State：** 两人都获得重新协商所需的信息，但尚未提出方案。
- **Next-scene Trigger：** 老摊主可以主动决定保留什么、停止什么。

### S004｜相邻摊位通道·次日清晨

- **Source Range：** S004 全场。
- **Direct Cause：** S003 让双方看到暂停互助的实际功能与成本。
- **Scene Function：** 由当事人建立有限、对等、可执行的新约定。
- **Entry State：** 默认互助仍未恢复；托盘是否继续使用尚未明确。
- **Character Objectives：** 老摊主主动限定愿意承担的范围；邻摊确认规则是否对等且可操作。
- **Obstacle / Pressure：** 任何模糊措辞都可能让旧的无限托付返回。
- **Initial Tactics：** 老摊主给出明确时段；邻摊用边界问题测试约定。
- **Shift Trigger / New Tactics：** 邻摊接受限制并补充对等限制；老摊主主动宣布取消托盘步骤。
- **Performance Actions：** 每人只说执行条件；邻摊避免说“早该如此”；夹子只放回一半。
- **Blocking & Spatial Power：** 约定发生在各自工作面未被侵入的状态；共享物重新进入分界，但数量受限。
- **Audience Beat：** 获得小幅松动，而非胜负和解。
- **Information Design：** 双方首次公开各自能承担和不能承担的范围。
- **Sound / Silence / Time：** 开市动作继续，不为决定暂停整个市场；条件说完便回到劳动节奏。
- **Required Assets / State Changes：** 托盘收起；夹子半量共享；暂停牌仍可使用。
- **Must Show / Withhold / Avoid：** 必须看见双方都设限；避免握手、拥抱或总结主题。
- **Turn / Exit State：** 新约定成立，旧步骤被主动结束。
- **Next-scene Trigger：** 收摊时出现第一次需要按新边界作出即时确认的行动。

### S005｜相邻摊位通道·傍晚

- **Source Range：** S005 全场。
- **Direct Cause：** S004 建立有限共享与明确许可。
- **Scene Function：** 用一次普通跨界行动验证新关系规则。
- **Entry State：** 半量夹子共享；托盘不再出现；两摊准备收摊。
- **Character Objectives：** 邻摊完成共享区域清理但不默认接管；老摊主保持自主同时决定是否允许协助。
- **Obstacle / Pressure：** 旧默契会诱使行动直接越界，新规则要求停下并等待。
- **Initial Tactics：** 邻摊扫到分界处停止；老摊主先处理自己脚边物件。
- **Shift Trigger / New Tactics：** 老摊主明确允许后，邻摊才继续扫过共享通道。
- **Performance Actions：** 停住、看见、提走小筐、简短允许、继续完成；不以感谢或情绪表白收尾。
- **Blocking & Spatial Power：** 扫帚停在两摊分界；许可后只跨入共享通道，不深入接管对方工作面。
- **Audience Beat：** 看见相同的帮助因请求方式不同而具有新的意义。
- **Information Design：** 观众知道新约定已能被执行；市场未来仍未知且不重要。
- **Sound / Silence / Time：** 清扫、收纳和卷帘门形成收束；最后沉默是工作完成后的共同确认，不是告别。
- **Required Assets / State Changes：** 扫帚、半量夹子、小筐、托盘缺席、收摊状态。
- **Must Show / Withhold / Avoid：** 必须看见分界停顿和明确许可；不展示市场关闭、最后一天或外部危机。
- **Turn / Exit State：** 日常继续，互助从默认义务变成可协商行为。
- **Next-scene Trigger：** None；Standalone Film 闭合。
