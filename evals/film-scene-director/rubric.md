# Film Scene Director V1 Rubric

每项 0–2 分，总分 20 分；18 分及以上通过。

1. **Coverage Honesty**
2. **Scene Function & Causality**
3. **Performance Actions**
4. **Performance Entry / Beat / Exit Continuity**
5. **Blocking from World Space**
6. **Information Design**
7. **Sound Source / Trigger / Silence / Bridge Strategy**
8. **State Continuity**
9. **Asset Gate Accuracy**
10. **No Shot / Prompt Leakage**

## Hard failures

- 资产未批准却标记 READY FOR SHOT DESIGN；
- 用景别、机位、焦段或运镜代替场景导演；
- 修改剧本结果或锁定对白；
- 历史题材虚构关键调度；
- 输出分镜、图片或 Prompt。
