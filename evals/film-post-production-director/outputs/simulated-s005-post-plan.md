## EDITORIAL THESIS

保持“行动先于说明”：先让扫帚在分界停住并维持等待，再给老摊主足够时间看见、移筐和允许，最后让收摊声音与空间全景证明新规则已经被普通地执行。不使用快切或情绪转场制造和解。

## PICTURE EDIT

- SH01 保留空间建立与扫帚抵达分界的动作完整性；切点由清扫声停止触发。
- SH02 保留停顿与视线转移，不因“没有大动作”过早切走。
- SH03 保留看见 → 提筐 → 稳定 → “扫吧” → 扫地声恢复的顺序；不得 J-cut 到许可前。
- SH04 从恢复清扫开始，保留退回各自工作面与卷帘门下降；是否采用摄影机后移版本由实际 Take QC 和空间稳定性决定。
- 预计总长接近 23 秒，实际 Source In/Out 必须在媒体存在后按动作帧登记。

## SOUND PLAN

- **Dialogue：** 只有“扫吧”，保持可懂且不夸张突出。
- **Foley：** 纸袋、夹子、扫帚接触、小筐移动、卷帘门；每个声音对应真实动作。
- **Environment：** 建立统一市场收摊 room tone，修复 SH03 模拟的不匹配但保留自然空间变化。
- **Silence：** 清扫声停止到许可之间保留环境而非音乐填充。
- **Music：** 当前不需要；如后续添加必须先确认来源、授权和进入理由。

## COLOR / VFX PLAN

- 先匹配四镜曝光、白平衡、傍晚光向与两摊材料，再应用 Visual Bible 的自然材料关系。
- 不加入泛黄怀旧滤镜。
- 仅允许移除生成乱码/水印、轻微稳定和不改变空间的局部清理；任何身份、肢体、扫帚接触、夹子数量或拓扑错误返回 QC/Generation。
