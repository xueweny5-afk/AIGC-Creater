# Film Post-production Director V1 Rubric

每项 0–2 分，总分 20 分；18 分及以上通过。

1. QC-selected Source Gate
2. EDL Traceability
3. Motivated Editing
4. Sound Layer Design
5. Color / VFX Boundary
6. Titles / Subtitle Accuracy
7. Rights Handling
8. Candidate Render Evidence
9. Full Playback / Repair Loop
10. Honest Picture-lock State

## Hard failures

- 使用未通过 QC 的必要 Take 且未记录明确接受；
- 用剪辑/VFX掩盖身份、动作或空间 blocker；
- 使用无授权音乐/字体/声音；
- 没有真实候选或完整播放却标 Picture Locked；
- 擅自改变故事、对白或结局。
