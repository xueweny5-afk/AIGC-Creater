# ASSET REQUIREMENTS

## PROJECT

- **Project ID：** TEST-EMOTION-OLD-MARKET
- **Visual Bible Version：** V0.1 Evaluation
- **Scope：** Standalone Film, S001–S005

## ASSET LIST

### LOC-E01｜相邻摊位与通道

- **Type：** LOCATION
- **Narrative Function：** 承载默认互助、边界暂停和重新协商。
- **Required Views / States：** P0 同一拓扑的正向与反向空间参考；开市、营业、收摊三种状态。不是 Shot List。
- **Locked Features：** 两个相邻工作面、清楚分界、共享通道、卷帘门、托盘架与夹子固定位置。
- **Variable Features：** 人流密度、开闭状态、物品摆放量。
- **Evidence Status：** CREATIVE / ASSUMED
- **Continuity Risk：** 左右关系、通道尺度和固定锚点漂移。
- **Priority：** P0
- **Approval Gate：** 空间正反关系一致且可支持剧本全部动作后，方可锁定。

### CH-E01｜长期经营者

- **Type：** CHARACTER
- **Narrative Function：** 通过熟练动作和自主边界体现长期使用者。
- **Required Views / States：** 中性全身正面、侧面、背面仅因跨角度复用而需要；双手自然可见；一套基础劳动服装。表情表暂不需要。
- **Locked Features：** 体态比例、面部身份、发型、基础服装层和常用收纳方式；具体选择待用户审批。
- **Variable Features：** 袖口、轻微劳动痕迹、手中道具。
- **Evidence Status：** OPEN → CREATIVE after approval
- **Continuity Risk：** 被自动老化、贫困化或地域刻板化。
- **Priority：** P0
- **Approval Gate：** 年龄范围、性别呈现和经营品类仍 OPEN，生成前需要一个视觉决定 Gate。

### CH-E02｜邻摊经营者

- **Type：** CHARACTER
- **Narrative Function：** 以多任务劳动和边界协商形成另一种节律。
- **Required Views / States：** 与 CH-E01 相同的必要三向身份视图；一套基础劳动服装。
- **Locked Features：** 体态比例、面部身份、发型、服装层和操作物件方式；具体选择待审批。
- **Variable Features：** 手中订单物、袖口和劳动状态。
- **Evidence Status：** OPEN → CREATIVE after approval
- **Continuity Risk：** 被造型成夸张时髦、冷漠或技术代表。
- **Priority：** P0
- **Approval Gate：** 与 CH-E01 同轮确定，检查两人不形成脸谱化新旧对立。

### PROP-E01｜夹子状态组

- **Type：** PROP
- **Narrative Function：** 表示共享程度的变化。
- **Required Views / States：** 全量共享、收回、半量共享三个状态。
- **Locked Features：** 同一规格、材料与辨识颜色。
- **Variable Features：** 数量与位置。
- **Evidence Status：** CREATIVE / ASSUMED
- **Continuity Risk：** 状态与场次不匹配。
- **Priority：** P1
- **Approval Gate：** 三个状态在同一场景拓扑上可辨认。

### PROP-E02｜托盘、暂停牌与扫帚

- **Type：** PROP
- **Narrative Function：** 分别承担旧步骤取消、边界暂停和经同意跨界。
- **Required Views / States：** 单一身份参考＋剧本要求的出现/收起状态。
- **Locked Features：** 尺度、材料、抓握与收纳关系。
- **Variable Features：** 位置、使用状态和轻微劳动痕迹。
- **Evidence Status：** CREATIVE / ASSUMED
- **Continuity Risk：** 生成成象征化古董或出现不可控文字。
- **Priority：** P1
- **Approval Gate：** 功能清楚、材料可信、不抢夺人物注意力。

## DEFERRED / NOT REQUIRED

- 市场全景、城市外观、复杂招牌系统、节庆状态和额外服装均非当前剧本必需。
- 表情九宫格不是默认资产；场景行动足以定义当前表演需求。
- 任何图片 Prompt 留到 Asset Design 的实际执行环节。
