## GLOBAL MOTION RULES

- CH-E01 始终在西侧工作面，CH-E02 始终在东侧；只有扫帚在许可后进入南侧共享通道。
- 主要动作按“扫至分界并停住 → 等待 → 看见并移筐 → 允许 → 完成共享通道清扫”推进。
- 面部只承担视线与回应，不增加表演性微笑、落泪或告别凝视。
- 半量夹子保持静止且位置连续；托盘全程缺席。
- 除 SH04 的条件式后移外，摄影机保持 HOLD；后移不与最复杂的扫地接触同时发生。

## CLIP SPECIFICATIONS

### S005-SH01-CL01｜S005-SH01

- **Duration：** 6s
- **Start Frame / End Frame：** 镜头从两人各自收摊开始，结束于扫帚在分界稳定停止。
- **Start State：** CH-E01 扎纸袋；CH-E02 取下夹单；扫帚在东侧；卷帘门尚未明显下降。
- **Trigger：** CH-E02 完成夹单整理并拿起扫帚。
- **Primary Motion：** CH-E02 把清扫路径从自己摊前推进到分界并停住。
- **Character Motion：** 0–2s 两人各自小范围收纳；2–5s CH-E02 两次连续清扫接近分界；5–6s 身体重心停止前移。CH-E01 保持自己的工作节律。
- **Face / Gaze：** 0–5s 各自看手中工作；扫帚停住后 CH-E02 尚未转头。
- **Hand / Prop Contact：** CH-E02 双手稳定控制扫帚；扫帚头始终接触地面，抵达分界后停止。CH-E01 的纸袋不换手。
- **Camera Motion：** HOLD。
- **Environment / Secondary Motion：** 远处使用者缓慢离开，不穿过主要动作；夹子、托盘状态 HOLD。
- **Dialogue / Lip-sync / Sound Timing：** 全程无对白；纸袋、夹子、清扫声依动作出现；5s 处清扫声停止。
- **Speed / Acceleration / Holds：** 清扫速度均匀，接近分界前自然减速；最后保持约 1s。
- **Occlusion / Physics / Contact：** 扫帚与地面接触连续；不得穿过分界或 CH-E01 物件。
- **End State：** 扫帚停在分界；两人仍在各自区域。
- **Transition：** 切至 CH-E02 等待状态，保持扫帚角度和身体朝向。
- **Failure Risks / Simplification：** 双人手部并行风险高时，保持 CH-E01 动作更小；不可删除扫帚停止。

### S005-SH02-CL01｜S005-SH02

- **Duration：** 5s
- **Start Frame / End Frame：** 从扫帚已停止开始，结束于 CH-E01 已察觉等待。
- **Start State：** CH-E02 身体未跨界，扫帚静止；CH-E01 离画但继续收纳。
- **Trigger：** 清扫声停止后，CH-E02 确认没有自动许可。
- **Primary Motion：** CH-E02 的注意从地面转向 CH-E01。
- **Character Motion：** 0–1s 身体和扫帚 HOLD；1–2.5s 仅头部和视线转向西侧；2.5–5s 保持等待，不前进。
- **Face / Gaze：** 中性确认，不道歉、不请求式微笑；视线最终稳定在 CH-E01 方向。
- **Hand / Prop Contact：** 双手保持扫帚，握法和高度不变。
- **Camera Motion：** HOLD。
- **Environment / Secondary Motion：** 背景收摊动作低优先且不穿越主体；无风动、粒子或额外随机动作。
- **Dialogue / Lip-sync / Sound Timing：** 无对白；1s 前保留扫地停止后的空隙，其后环境收摊声持续。
- **Speed / Acceleration / Holds：** 视线转移约 1.5s，随后 HOLD 2.5s。
- **Occlusion / Physics / Contact：** 扫帚头不得滑动；身体重心仍在东侧。
- **End State：** CH-E02 等待，CH-E01 已看到但尚未行动。
- **Transition：** 切到 CH-E01 时保持视线配对方向。
- **Failure Risks / Simplification：** 如面部细节不稳，优先保留头部朝向和扫帚静止，不添加表情变化。

### S005-SH03-CL01｜S005-SH03

- **Duration：** 5s
- **Start Frame / End Frame：** 从 CH-E01 看向分界开始，结束于许可说完、扫帚开始重新运动。
- **Start State：** 小筐在 CH-E01 脚边；扫帚右缘静止；共享通道被小筐局部占用。
- **Trigger：** CH-E01 看到 CH-E02 保持等待。
- **Primary Motion：** CH-E01 提走小筐，为共享通道腾出空间。
- **Character Motion：** 0–0.8s 视线确认；0.8–3s 弯身抓住小筐并提到自己工作面内；3–4.2s 稳定站姿后说“扫吧”；4.2–5s 保持，扫帚在右缘开始移动。
- **Face / Gaze：** 视线先到扫帚/分界，再到 CH-E02；说话时不做告别性微笑。
- **Hand / Prop Contact：** 手在 1s 左右建立对小筐的抓握；小筐重量使身体重心短暂下移；放到西侧后解除接触或稳定持有，不能瞬移。
- **Camera Motion：** HOLD。
- **Environment / Secondary Motion：** 背景 HOLD 在低注意层；纸袋和夹子不移动。
- **Dialogue / Lip-sync / Sound Timing：** 3.2–4.0s CH-E01 说“扫吧”；4.3s 后扫地声重新出现。
- **Speed / Acceleration / Holds：** 提筐动作平稳，不拖长；对白前保留约 0.2s 确认停顿。
- **Occlusion / Physics / Contact：** 小筐不能穿过腿或工作面；扫帚在对白完成前不得越界。
- **End State：** 小筐移开、共享通道开放、许可完成、扫帚刚开始越界。
- **Transition：** 下一 Clip 从相同扫帚方向与位置继续。
- **Failure Risks / Simplification：** 手部接触失败时优先缩短抓握可见时长，但必须保留“提走小筐”结果。

### S005-SH04-CL01｜S005-SH04

- **Duration：** 7s
- **Start Frame / End Frame：** S005-SH04-F01 → S005-SH04-F02
- **Start State：** 扫帚刚进入共享通道；小筐已移开；两摊仍开放；半量夹子可见。
- **Trigger：** 上一镜许可和扫地声重启。
- **Primary Motion：** CH-E02 完成共享通道清扫，随后两人各自结束收纳。
- **Character Motion：** 0–2.5s CH-E02 完成两次清扫，只覆盖共享通道；CH-E01 同时完成单一收纳动作但保持次要。2.5–4s CH-E02 停止清扫并退回东侧工作面；CH-E01 回到西侧。4–6s 两人各自检查摊位，卷帘门下降。6–7s 两人视线短暂落到半量夹子，随后 HOLD。
- **Face / Gaze：** 不互相凝视；最后视线落点是共享物，不是对方脸部。
- **Hand / Prop Contact：** 扫帚始终与地面接触，完成后回到 CH-E02 一侧；夹子不被触碰；托盘不出现。
- **Camera Motion：** 0–4s HOLD。若批准后移版本，4s 卷帘门开始下降时触发缓慢直线后移，4–6.5s 完成，以两摊、通道和夹子同时进入稳定关系为终点，6.5–7s HOLD；若空间/生成能力不足，全程 HOLD。
- **Environment / Secondary Motion：** 卷帘门只在 4s 后下降；背景人员已基本离开；无额外风、粒子或灯光闪变。
- **Dialogue / Lip-sync / Sound Timing：** 无对白；0–2.5s 清扫声，2.5s 停止；4–6s 卷帘门依次落下；最后保留约 1s 环境尾声。
- **Speed / Acceleration / Holds：** 清扫均匀；人物退回各自区域后停稳；摄影机如后移则柔和起停，不与扫地主动作重叠。
- **Occlusion / Physics / Contact：** 扫帚不得进入 CH-E01 工作面；卷帘门下降不穿过人物；后移不改变两摊左右投影。
- **End State：** 通道清理完成；两人各自在摊内；卷帘门大部分落下；半量夹子保留；托盘缺席。
- **Transition：** Standalone Film 结束；声音自然收尾。
- **Failure Risks / Simplification：** 优先删减后移和背景动作，保留清扫、退回、卷帘门与夹子状态。
