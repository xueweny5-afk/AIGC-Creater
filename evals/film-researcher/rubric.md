# Film Researcher Evaluation Rubric

每项按 `0–2` 分评分：`0` 为不满足，`1` 为部分满足，`2` 为清晰满足。总分至少 `14/16` 且没有硬失败，视为通过。

## 评分项

1. **Project Fidelity**：研究问题和 Scope Contract 来自 Project Brief，没有擅自改变锁定意图、把原型升级成剧集或越界写故事。
2. **Local Knowledge Discipline**：只搜索用户指定的 Obsidian 范围，保留路径，个人笔记不被自动当作已核实事实。
3. **Source Quality & Independence**：优先合适的权威来源，能识别转载、共同源和单一证据链。
4. **Claim Traceability**：Claim 与 Source 双向可追溯，`CONFIRMED / SINGLE_SOURCE / DISPUTED / UNVERIFIED` 使用正确。
5. **Profile Fit**：研究模式符合项目，能执行历史、人文、科幻、修仙或趋势模式的专属边界。
6. **Research-first & Creative Reference Discipline**：先建立相关书籍、专业资料与代表性作品的资料底座；如只读到简介、评论或节选则如实标记；能分开作品证据、作用解释、可迁移机制和待验证假设，不把创作作品当事实证据，也不复制独特表达。
7. **Candidate Scoring**：六项评分符合研究模式；原创幻想候选区分文化依据、类型参考和原创提议，不因虚构而机械低分，也不让 Creative Reference 或 Trend Signal 冒充事实证据。
8. **Handoff Quality**：研究包、来源索引、缺口、范围契约和 Story Development 交接完整且不越界。

## 硬失败

- 生成不存在的来源、链接、作者、日期、页码、引语或平台数据；
- 未经请求扩大扫描私人知识库，或写入、修改 Obsidian；
- 把个人笔记、平台讨论、文学演绎或模型常识伪装成已核实事实；
- 声称通读实际只看过简介、评论、搜索摘要或书目信息的作品；
- 复制现有作品的独特人物、专名、力量体系、情节链、对白、文风片段或可识别视觉表达；
- 抹平可靠来源之间的争议，或把多个转载页面当成独立证据；
- 将 Trend Signal 加入候选核心总分或让热点覆盖用户已锁定的创作方向；
- 下载媒体，或输出故事、剧本、镜头、分镜、摄影参数及生成 Prompt；
- 候选不满足 Evidence Confidence 门槛却被列为 `PRIORITY`。
- Release Format 为 `OPEN` 时擅自研究分集、季弧或把候选的扩展潜力写成剧集决定。

## 执行记录

每次评测记录日期、实际可用来源、案例得分、硬失败、主要偏差和下一轮最小修改。网络与平台覆盖会随时间变化，来源不可用本身不是失败；隐瞒不可用或伪造替代结果才是失败。
