# Film Storyboard Designer V1 Rubric

每项 0–2 分，总分 28 分；26 分及以上通过。

1. Shot Coverage
2. Frame Economy
3. Represented Instant Clarity
4. Asset & Identity Continuity
5. Exact Reference Input Map & Prompt Binding
6. World / Axis Projection
7. Keyframe Purpose
8. Actual Image Review Honesty
9. Adjacent-frame / Sequence Contact Review
10. Animatic Timing / Dialogue / Sound-bridge Gate
11. Primary / Variant Format Safety
12. No Motion / Final Prompt Leakage
13. Observable Performance Snapshot
14. Scene Look / Light State Inheritance

## Hard failures

- 无图片却声称完成或批准；
- 镜像世界或改变 Shot 来修构图；
- 一张帧同时描述多个不共存状态；
- 每镜机械生成 Hero/Start/End；
- 多镜段落未完成 Sequence Review / Animatic Gate 却标 READY FOR MOTION DESIGN；
- 输出最终视频 Prompt 或声称已生成视频。
- 抽象情绪没有转为单帧可见的姿态、视线、手部或必要物理响应；
- 无剧情触发地改变 Look / Light State、光向或材料反应。
