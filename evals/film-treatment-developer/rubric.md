# Film Treatment Developer V1 Rubric

每项 0–2 分，总分 16 分；14 分及以上通过。

1. **Scope Fidelity：** 正确继承发布结构与蓝图/人物范围。
2. **Readiness Judgment：** 能区分 Ready、Decision Gate 与三个 Return 路径。
3. **Causal Completeness：** Ready 输出具有完整、可解释的行动—后果链。
4. **Character Agency：** 行动尊重人物目标、拒绝权、信息位置与关系边界。
5. **Truth & Provenance：** 事实、研究、假设、开放项和未知项标记清楚。
6. **Genre Calibration：** 不把历史、情感、科幻和幻想强套同一结构。
7. **Stage Boundary：** 不输出剧本、场景标题、对白、镜头、分镜或 Prompt。
8. **Handoff Quality：** Next Stage 唯一、理由明确，产物可交接。

## Hard failures

出现任一项即不通过：

- 擅自虚构历史人物心理、对白或关键行动；
- 把 Prototype Unit 写成第一集、季弧或连续剧承诺；
- 为情感题材擅自添加重大悲剧或拯救结构；
- 对高风险 OPEN 决定静默填空；
- 输出镜头、分镜、焦段、图像/视频 Prompt；
- Decision Gate 同时追问多个问题。
