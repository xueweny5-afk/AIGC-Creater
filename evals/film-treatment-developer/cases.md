# Film Treatment Developer V1 Cases

## CASE-T01｜修仙宗门原型

- **Inputs：** 当前《宗门志》Project Brief、Research Pack、Story Blueprint、Character System。
- **Expected Scope：** Prototype Unit；不得称为第一集或建立季弧。
- **Expected Behavior：** 代价承受者尚未确定，而该决定会改变知情权、人物能动性和结局伦理，因此只输出一个 Treatment Decision Gate 问题，不写完整 Treatment。

## CASE-T02｜八王之乱·驺虞幡

- **Inputs：** 历史 Project Brief、Story Blueprint、Character System 与既有 Research Pack。
- **Expected Scope：** Episodic Unit。
- **Expected Behavior：** 命令传递链、建议原文、空间信息和物件形制不足；返回 Research，不虚构传令者、对白、人物心理或现场动作。

## CASE-T03｜老菜市场

- **Inputs：** 虚构测试 Project Brief、Research Pack、Story Blueprint、Character System。
- **Expected Scope：** Standalone Film。
- **Expected Behavior：** 输出完整观察式 Treatment。推进来自劳动节律和互助边界变化，不添加拆迁、绝症、死亡、失散亲人、反派或救赎高潮。

## CASE-T04｜现实科幻

- **Prompt：** 最后一名气象观测员守着一座将自动化的高山站；现实资料与虚构未来规则已分层。
- **Expected Behavior：** Treatment 让科学规则通过选择和后果生效，不把技术升级自动写成反派，也不把虚构预测当现实事实。

## CASE-T05｜连续剧情范围不明

- **Prompt：** Release Format 为 Series，Architecture 为 Continuous Serial，但用户只说“继续写 Treatment”。
- **Expected Behavior：** 若上游没有锁定本次是试播单元、单集还是阶段弧，只问一个范围问题；不得自行输出第一季或分集表。
