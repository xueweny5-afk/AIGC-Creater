## COMPLETE TREATMENT

每天开市前，长期经营者先把常用物品放回熟悉的位置，再替尚未到达的邻摊留出通道。邻摊经营者到来后，一边整理自己的货物，一边处理当天分散到不同时间的订单。两人很少专门商量互助：谁短暂离开，另一个人便照看一下；固定使用者也按各自习惯出现，有人停下来多说几句，有人只取走东西便离开。相邻并不意味着亲密无间，却让许多小事无需解释。

一段时间里，使用市场的人到达得更分散。邻摊经营者需要频繁中断手头工作，长期经营者便像往常一样替对方回应询问、暂存物品。最初这只是原有互助的延伸，随后中断逐渐挤进长期经营者自己的节律：他记得邻摊物品的位置，却开始在自己的备货和收拾之间来回切换。邻摊经营者注意到这一点，提出把零散请求集中到两个固定时段，并只请对方在其中一段短暂照看。长期经营者没有立即接受。他担心一套看似省事的办法会把自己熟悉的做法变成多余，也不愿邻摊替他安排怎样工作。

两人没有因此争吵。邻摊经营者先撤回默认的托付，只处理自己的部分。通道暂时显得不那么顺畅：有人需要多等一会儿，有人改在另一个时间来，也有人仍旧按照过去的习惯停下。长期经营者在这些差异里看见，过去稳定的节律并不是所有人共同遵守的规则，而是许多次互相配合累积出的结果；邻摊经营者也发现，自己认为可以压缩的停留和交接，承担着确认、信任和照看的作用。

下一次相似的忙碌到来前，长期经营者主动划出一个明确的短时段，表示那段时间可以替邻摊看顾，但超过时段便由对方自行调整。他同时把自己一项已经很少发挥作用的重复步骤删掉，为这段协助留出余地。邻摊经营者接受这个边界，没有扩大请求，并保留一项原本准备取消的共同整理动作，因为那是两人交换当天信息的时刻。固定使用者继续以不同频率来去；没有人宣布旧市场被保存，也没有人证明新方法更好。

营业结束时，两位经营者仍各自完成收拾。通道里的大部分东西与开头相同，但共享劳动不再依赖默契中的无限延伸，而变成一项可以提出、拒绝和调整的约定。长期经营者保留了自己的秩序，也承认某个旧步骤可以结束；邻摊经营者提高了效率，却没有把关系当作需要清除的阻力。日常继续，变化只留在他们下一次如何向对方开口。

## NARRATIVE SEQUENCE MAP

### Sequence 1｜无需说明的相邻日常

- **Start State｜起始状态：** 两位经营者各有节律，互助由长期重复形成。
- **Process / Action｜过程或行动：** 开市、整理、短暂照看和不同使用者的来去反复出现。
- **Choice / Response｜选择或反应：** 双方默认在不打断自身工作的范围内互相补位。
- **Consequence｜后果：** 稳定感成立，也埋下帮助边界未经说明的问题。
- **Information Change｜信息变化：** 观众理解关系来自劳动，不来自预设亲情。
- **Emotional Movement｜情绪运动：** 熟悉、松弛、轻微依赖。
- **Provenance｜来源：** [ASSUMED] 基于 Story Blueprint 与 Character System 的虚构连接。

### Sequence 2｜互助开始挤压各自节律

- **Start State｜起始状态：** 客流与订单时间逐渐分散。
- **Process / Action｜过程或行动：** 长期经营者替邻摊承担更多零碎回应，自身工作频繁中断。
- **Choice / Response｜选择或反应：** 邻摊提出集中处理，长期经营者暂不接受被安排。
- **Consequence｜后果：** 默认互助暂停，通道出现小范围等待和不便。
- **Information Change｜信息变化：** 双方看见效率和熟悉秩序各自遗漏的部分。
- **Emotional Movement｜情绪运动：** 从自然默契转为克制的不适。
- **Provenance｜来源：** [ASSUMED] 不添加外部危机。

### Sequence 3｜各自承担不再被遮住的部分

- **Start State｜起始状态：** 双方只处理自己的工作，原有顺畅暂时减少。
- **Process / Action｜过程或行动：** 使用者作出不同选择，两位经营者观察变化的实际后果。
- **Choice / Response｜选择或反应：** 长期经营者辨认哪些习惯仍有价值；邻摊辨认哪些停留承担关系功能。
- **Consequence｜后果：** 新约定的条件能够由双方提出，而非由一方拯救另一方。
- **Information Change｜信息变化：** 问题从“新旧谁正确”转为“帮助怎样不取消自主”。
- **Emotional Movement｜情绪运动：** 不适转为可商量的清醒。
- **Provenance｜来源：** [ASSUMED] 延续人物系统的拒绝权和独立边界。

### Sequence 4｜有限而可撤回的新约定

- **Start State｜起始状态：** 双方都知道旧默契不可无限延伸。
- **Process / Action｜过程或行动：** 长期经营者主动给出有限协助时段，并删去一个失去作用的旧步骤；邻摊保留共同整理动作。
- **Choice / Response｜选择或反应：** 两人分别改变一小部分，但都不接管对方。
- **Consequence｜后果：** 日常继续，互助获得清楚边界。
- **Information Change｜信息变化：** 变化并非保存一切或替换一切，而是重新决定什么值得继续。
- **Emotional Movement｜情绪运动：** 克制的松动与未完成感。
- **Provenance｜来源：** [ASSUMED] 兑现 Ending Principle，不预设市场结局。

## CHARACTER PROGRESSION

- **长期经营者：** 从依赖未说明的惯例，到主动决定一项旧步骤可以结束，并明确自己愿意提供的帮助范围；没有被教育成接受一切新方式。
- **邻摊经营者：** 从把问题主要视为时间分配，到承认部分共同节律具有关系功能；没有成为拯救者或放弃自己的效率边界。
- **市场使用者：** 以不同到访和等待选择显示共同体内部差异，不代表统一怀旧立场。

## INFORMATION & CAUSALITY MAP

- 分散到达增加 → 默认互助扩大 → 长期经营者的工作被挤压。
- 邻摊提出集中处理 → 长期经营者拒绝被代为决定 → 默认互助暂停。
- 使用者出现不同反应 → 两人看见效率与惯例的实际功能 → 有条件的新约定成为可能。
- 双方各自放弃一小部分控制 → 互助从无边界默契变为可协商关系。

## WORLD / RULE USE

- 唯一参与因果的环境规则是：摊位相邻使短暂照看成为可能，分散的到访使中断逐渐累积。市场制度、政策和未来命运保持 OPEN。

## PRODUCTION FEASIBILITY

- **Character Load｜角色负担：** 2 名核心经营者＋少量可复用市场使用者。
- **Location Load｜地点负担：** 一条相邻摊位通道及其收摊范围。
- **Time Span｜时间跨度：** 若干普通营业周期；具体天数 OPEN。
- **Complex Action｜复杂行动：** 日常整理、交接、等待与收摊，无大型事件。
- **Continuity Risks｜连续性风险：** 重复劳动的前后差异需要稳定；不得用突发危机替代细微积累。
- **Reusable Asset Candidates｜潜在复用资产：** 两个摊位、通道、常用经营物品与少量使用者身份；仅作资产负担提示，不确定视觉设计。
