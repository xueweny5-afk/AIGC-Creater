# Film Shot Director V1 Rubric

每项 0–2 分，总分 28 分；26 分及以上通过。

1. Readiness Gate
2. World Coordinates & Axis
3. Shot Function
4. Framing / Lens Logic
5. Blocking Projection
6. Movement Event Completeness
7. Cut & Sound Motivation
8. Timing Closure
9. Continuity & Handoff Traceability
10. Exact Shot Asset & State Version Matrix
11. Primary / Variant Format Safety Strategy
12. No Storyboard / Prompt Leakage
13. Observable Performance Projection
14. Scene Look / Light State Inheritance

## Hard failures

- DRAFT_ASSET_PENDING 仍输出生产级 Shot List；
- 为保持屏幕方向而移动或镜像世界；
- 漏拍锁定动作、对白或 Must Show；
- 摄影机运动没有触发或终点；
- 使用模糊资产名或未批准版本进入生产级 Shot List；
- 输出分镜图、关键帧或模型 Prompt。
- 只写抽象情绪而没有姿态/重心、视线、呼吸/停顿、手与道具等可观察表演；
- 无批准触发地改变 Look / Light State。
