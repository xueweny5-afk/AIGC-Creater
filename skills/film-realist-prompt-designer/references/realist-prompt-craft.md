# 现实主义电影提示词创作方法

本方法由用户提供的风格提示词样例归纳而来，定位为创作辅助，不是特定模型的实测配方。样例中的北方乡村、青年回忆、晚年孤独和海边终章是题材实例，不是默认内容。

## 一、先写关系，再写影调

现实主义风格的核心不是“脏、灰、颗粒”，而是人物与生活环境的可信关系。先完成三句话：

1. 人物此刻失去、维持或意识到了什么？
2. 环境怎样包围、抵抗或承接人物？
3. 观众应通过哪个可见变化感到这件事？

例如，“孤独”可以来自人物仍在重复两人生活的动作，而另一个位置持续空着；这比“冷色、阴天、悲伤表情”更有叙事信息。

## 二、十个设计轴

| 设计轴 | 应明确的内容 | 常见失误 |
|---|---|---|
| 叙事作用 | 此段在时间线和人物变化中的任务 | 只写情绪形容词 |
| 光线 | 真实光源、方向、强弱、反射与遮挡 | 无来源轮廓光、所有场景逆光 |
| 曝光与反差 | 哪些高光受控、暗部保留什么 | 灰雾遮细节、极端 HDR |
| 色彩关系 | 主色来自哪些物件和环境，暖冷如何形成 | 一键黄滤镜/蓝滤镜 |
| 人物状态 | 肤色、毛孔、汗水、年龄、姿态、重心、微动作 | 磨皮、摆拍、标准化 AI 表演 |
| 空间与构图 | 人与环境比例、遮挡、空位、纵深、视线关系 | 只追求海报式中心构图 |
| 镜头 | 观察距离、焦段功能、机位和运动动机 | 焦段清单、漂浮运镜、无意义环绕 |
| 材质 | 布料、木石、墙面、泥土、金属和使用痕迹 | 泛化“细节丰富”、统一做旧 |
| 空气 | 来源、分布、受光和运动驱动 | 为电影感默认加雾、灰尘 |
| 成像质感 | 光学扩散、颗粒、锐度、后期边界 | 把成像效果当场景物理事实 |

这些轴不必每条提示词逐项写满。全片基线已锁定的内容只需继承；当前场景只写会影响结果的差异。

## 三、因果句式

优先使用“条件 → 可见结果 → 叙事作用”的句式：

- 窗外阴天的散射光从人物侧后方进入，室内反差偏低但暗部仍保留旧墙和衣料纹理，使人物显得被熟悉空间包围，而不是被蓝色滤镜孤立。
- 午后真实日光经树叶和白墙二次反射，皮肤略偏暖，高光柔和但不过曝；暖色来自环境反射，不来自全局黄染。
- 海面低角度反光轻微扩散远景边缘，盐雾只在逆光区域可见，人物保持清晰，辽阔感由人与海的尺度关系完成。

避免只有结果、没有来源：

- 差：电影感逆光、空气颗粒、唯美光晕。
- 好：灶火和门外冷天光共同塑造脸部，烟气只从灶口升起并被门缝气流带向屋内高处。

## 四、基线与变体

### 基线应锁定

- 现实表演：生活习惯、身体重量、停顿和不完整动作优先。
- 真实表面：皮肤、衣物、墙体、土木和常用物件保留使用痕迹。
- 光源可信：自然光和场景内实际光源优先，不凭空补造型光。
- 成像克制：高光不过度炸白，暗部不压死，数字锐化和 HDR 受控。
- 摄影机有立场：决定是在场观察、保持距离，还是贴近人物，而不是展示运镜能力。

### 变体只改少数主轴

每段选择 2–4 个真正改变情绪的轴，其余继承基线。

#### 青年或回忆段落

- 叙事机制：生命活力来自行动与环境响应，不来自统一暖滤镜。
- 可变轴：日光方向、肤色温度、动作密度、空间通透度。
- 保留：真实皮肤、受控高光、自然绿色、生活化动作。

#### 晚年、停滞或缺席段落

- 叙事机制：情绪来自重复动作后的空白，以及环境尺度大于人物。
- 可变轴：曝光略收、冷中性色比例提高、固定或极慢机位、留白增加。
- 保留：肤色仍有温度，暗部仍可读，不以哭泣或蓝滤镜替代内在情绪。

#### 释然、告别或终章段落

- 叙事机制：环境不负责制造奇观，而是接住人物已经完成的变化。
- 可变轴：空间打开、光源简化、运动趋稳、色彩关系稍清晰。
- 保留：自然环境光、真实尺度、克制表演，不用英雄式剪影和大片金色日落强迫升华。

## 五、镜头与成像

先决定观察关系，再决定焦段：

- 环境需要包围人物：中广角或正常焦段，保留可读空间，但避免夸张透视。
- 需要安静观察人物：正常至中长焦，压低摄影机存在感。
- 近距离身体细节：焦段和机位应保持真实比例，不把皮肤纹理变成猎奇展示。

固定机位、真实轨迹上的缓慢移动通常更适合克制观察，但不是硬规则。手持只在人物或现场状态需要摄影机具备呼吸和应对感时使用；漂移、无人机式滑行、数字变焦和无动机环绕应排除。

黑柔、Pro-Mist、胶片颗粒属于成像层。使用时写清目的和强度，例如“极轻微扩散高光边缘，同时保留皮肤和织物细节”；不要把它们和烟、雾、粉尘混为一谈，也不要默认每个段落都需要。

## 六、人物与材料的真实性

有效细节必须与生活状态有关：

- 皮肤：毛孔、细纹、汗水、油脂、日晒差异、年龄和环境色反射。
- 衣物：合身程度、磨损位置、清洁状态、湿度、重力和动作形成的褶皱。
- 身体：脚下受力、弯腰幅度、起身惯性、呼吸、手部犹豫和视线延迟。
- 场景：墙面修补、门窗使用痕迹、地面压痕、炊烟或水汽的真实来源。

不要为了“去 AI”机械加入污垢。整洁的新空间、新衣物和清洁空气也可以真实；关键是状态有生活原因。

## 七、写排除项

排除项围绕本次最可能的失败：

- 人像失败：无美容磨皮、塑料皮肤、过度对称、夸张哭相。
- 光线失败：无来源轮廓光、天空和皮肤高光不过曝、暗部不涂黑。
- 色彩失败：不做全局黄染或蓝染，绿色和肤色保持自然层次。
- 镜头失败：无数字变焦、漂浮滑行、无人机式无重力运动、无动机环绕。
- 质感失败：无极端锐化、廉价复古滤镜、重 HDR、涂抹感、鱼鳞纹。
- 类型失败：无旅游宣传片、短视频摆拍、商业广告或偶像剧式精致感。

只选相关项。排除项不能修复主体、动作、空间和光线本身未写清的问题。

## 八、推荐交付模板

```markdown
# 风格任务

## 叙事意图
人物与环境的关系，以及观众通过什么可见变化感知它。

## 整体风格基线
- 现实与表演：
- 光线与曝光：
- 色彩关系：
- 空间与镜头：
- 材质与空气：
- 成像边界：

## 段落变体：<名称>
- 叙事作用：
- 相对基线的变化：
- 必须继承：
- 可复制提示词：
- 排除项：
- 肉眼验收：

## 假设与待定项
```

当用户只要一条提示词时，不输出整份模板；内部完成判断后给出一段紧凑正文和必要的排除项即可。
