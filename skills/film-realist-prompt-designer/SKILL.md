# Film Realist Prompt Designer

把抽象情绪写成有因果、有物理来源、可被画面观察的现实主义电影语言。提示词应像一份简洁的摄影与美术意图，不是质感词清单。

## Inputs

尽量从现有材料取得：

- 故事、场景或镜头内容，以及这段在叙事中的作用
- 地点、年代、季节、天气、时段和实际光源
- 人物年龄、生活状态、正在做的动作与情绪压抑方式
- 必须保持的资产、构图、连续性和禁止项
- 用户指定的影视参考，以及已完成的四轴 Soft Reference Map（若有）
- 交付层级：全片风格、段落变体、场景提示词、镜头提示词或现有提示词诊断

信息不足但不影响方向时，作最少假设并显式列出；地点、时间或人物状态的不同解释会改变风格时，先指出关键歧义。

## Load resource

创作、改写或审查提示词时读取 [realist-prompt-craft.md](references/realist-prompt-craft.md)。它包含设计轴、因果写法、段落变体方法和交付模板。

## Modes

- `BASELINE`：建立全片不随场景轻易改变的现实主义风格基线。
- `VARIATION`：为回忆、当下、孤独、释然等段落建立继承基线的差异，不另起一套滤镜。
- `SCENE / SHOT`：把已确定风格压缩为当前可见时刻的提示词。
- `REVIEW`：找出词语堆砌、物理矛盾、题材刻板化、广告感和常见 AI 痕迹，并做最小改写。

## Workflow

1. **State the narrative truth.** 先用一句话说明这段画面要让观众感到什么，以及这种感受来自人物和环境的什么关系。不要从镜头、滤镜或色彩名开始。用户提供影视参考时，先使用 `film-video-method-curator` 建立 `TEXTURE / COLOR / PHOTO / MOOD` Soft Reference Map；只有片名而没有可检查片段时，不凭印象代写作品风格。
2. **Separate constants from variables.** 把全片恒定项与本段可变项分开。皮肤与材质真实性、光源有出处、表演克制等通常是恒定项；天气、色温、空间尺度和机位距离可随叙事改变。
3. **Translate by visible cause.** 依次决定光源与曝光、色彩关系、空间比例、人物行为、材质、空气介质、镜头距离与运动。每个选择都要能回答“为什么此刻如此”和“画面中如何看见”。
4. **Preserve lived reality.** 用重心、呼吸、停顿、视线、手部小动作、汗水、皮脂、衣物褶皱、磨损、泥土和真实环境纹理建立生活密度；人物不必用夸张表情替代情绪。
5. **Use optics sparingly.** 焦段服务观察距离和空间关系；扩散滤镜、胶片颗粒、浅景深、晕光只在叙事与光学条件需要时使用。区分空气介质与镜头/后期效果。
6. **Build controlled variations.** 段落变体只改变少量主轴，并写清与基线的继承关系。例如回忆可以由真实日光形成略暖的肤色，而不是统一套黄色；晚年可以降低曝光和空间温度，但不能把肤色做成死灰蓝。
7. **Write functional exclusions.** 只列与本次风险直接相关的排除项，并尽量写成正向可检查标准。不要用冗长的通用 negative prompt 掩盖主体、动作或光线不明确。
8. **Reverse-check.** 从提示词反推：人物在做什么、光从哪里来、空间是什么、情绪由什么可见事实产生。如果只能读出“电影感”，重写。
9. **Route the result.** 交付模型中立的创作母版。需要 Seedance、Kling、Veo、MiniMax 等模型语法、输入绑定或参数时，交给 `film-prompt-adapter` 编译；本 Skill 不猜测模型能力。

## Output

按请求规模输出最小必要层级：

1. **叙事意图**：一句话，说明情绪来源而非情绪标签。
2. **整体风格基线**：光线、色彩、人物与材质、空间与镜头、运动、质感及边界。
3. **段落/场景变体**：每段只写相对基线发生的变化、变化原因和必须继承项。
4. **可复制提示词**：仅在用户需要时给出；单条只描述一个任务或一个可见时刻。
5. **排除与验收点**：列出主要失败风险和能够肉眼检查的成功标准。
6. **假设/待定项**：仅列真正影响结果的未知信息。

若输出要保存到项目，遵守 `projects/<project-id>/` 的阶段目录规则；未明确 Project ID 时不要创建项目交付文件。

## Boundaries

- 不把“真实、电影感、高级、8K、大师级”等词当成可执行描述。
- 不默认添加雾、灰尘、逆光颗粒、黑柔、胶片颗粒、浅景深或手持晃动。
- 不把低饱和等同于灰蒙，不把怀旧等同于黄滤镜，不把孤独等同于蓝滤镜或哭泣特写。
- 不让所有场景共用同一焦段、同一色温、同一空气效果或同一运镜。
- 不磨皮、美容、塑料皮肤、过度锐化、极端 HDR、数字变焦、漂浮运镜或无重力动作。
- 不复制参考影片的独特人物、构图、布景或可识别画面；只能迁移高层机制，并根据当前故事重建。
- 不把多个影视片名直接拼进生成提示词；提示词只写经四轴拆解并为当前故事重建后的可见策略。
- 不宣称提示词已经在某模型上验证；模型有效性必须由真实生成与 QC 证明。

## Completion gate

- 风格选择能追溯到叙事与物理条件；
- 基线与变体没有互相矛盾或重复堆叠；
- 人物、材质、光线和空气都有可观察依据；
- 摄影机距离与运动符合人物关系和空间；
- 排除项针对当前风险，提示词没有空泛质量词；
- 可复制文本没有混入未核实的模型参数；
- 读者能够据此判断画面是否成功，而不只知道它“应该有电影感”。
