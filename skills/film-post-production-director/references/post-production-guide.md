# Post-production Guide

## Edit from meaning

切点要回答为何离开、注意交给谁、延续何种关系/感知/余韵。下一画面可提供行动/信息，也可保持、重复或形成批准的意象关系，不强制升级。按批准观看顺序剪，不把倒叙/并置自动排成线性时间；不要按原片段长度盲拼或用转场包代替连接。

继承 Animatic 的 Rhythm Map：压力上升不自动等于更快切，可能来自同一镜头内行动加速；低声音能量不自动等于拖长，必须有观察、等待或余韵价值。修改必要停顿、反应或静默时记录原因，并在完整播放中验证观众仍能读到人物变化。

## Sound carries continuity

- 先建立对白可懂度和场景空间，再加音乐。
- 环境声跨镜应保持同一空间，除非声音变化就是场景转折。
- 声音桥或声音透视变化也可依批准艺术/时间规则刻意断开空间，写清来源、职责和进入/退出，不擅改故事含义。
- 拟音必须对应接触和重量，不能只为“丰富”。
- 静默是一种明确决定，不能被默认背景音乐填满。
- 音乐要有授权或可证许可；参考曲不等于可使用素材。

## Color and VFX

- 先核对色彩管理与实际错误，再按 Visual Bible / Presentation Mode / Artistic Rule IDs-Version 处理曝光、白平衡、黑白点和镜间关系。
- 区分意外偏差与批准风格/时期/意象变化；不把艺术性曝光、色偏、平面化统一成写实匹配。
- VFX 清理不能改变身份、道具状态、历史证据或世界拓扑。
- 稳定和裁切后重新检查画幅、边界、字幕安全区和分辨率。

## Playback passes

1. 故事、节奏、情绪、信息和注意力。
2. 连续性、画面缺陷、声音、字幕、黑帧/静帧、转场和尾帧。

每次关键修改后至少重看受影响范围；宣告锁片前必须完整重看最终候选。

两项完整审核均绑定最终文件路径/校验值、时间线版本、工具和日期；适用音频实际听取。修复生成新文件后记录 Issue、新渲染和复核范围，最终文件不能借用旧候选的全片 PASS。Post Review 写 PASS / REVISE / NOT_EVALUATED；不能播放/听取时只交计划与缺口，不伪造通过。人工批准源 Take 不需重做其画面 QC，最终成片的组合、声音与字幕仍需审。

## EDL and repair trace

EDL 记录源 Take ID/版本/路径、源帧率与时间基、Source In-Out、Timeline In-Out、独立音轨源/偏移、变速、裁切/稳定、转场及理由。未知素材只写计划需求，不虚构实际入出点；执行数据回到实际素材核对。变速不得损害对白、接触或必要反应，裁切/稳定须保护 Must Read/Withhold、留白、安全区和运镜意义。

Repair Log 用 Issue ID / Change-Reason / Source Permission / Protected Intent / Feasibility-Result / New Render / Verification Scope-Evidence / Closure，复用 QC 提出的后期修复条件；不能证明能修时标待验证或返回原责任层，不以修复计划关闭问题。

## Plan and lock boundary

缺素材可完成 POST PLAN、计划 EDL、声画与艺术规则方案，写待补依赖；不要求先回传媒体才能交文本。实际锁片须源选片与用途就绪、最终候选双项完整审核、所需声音/文字/权利和问题门通过。锁片状态统一 PICTURE_LOCKED，其他状态与合同一致；它是本阶段后期文件锁定，不代表最终交付版本已导出或发布。

## Return earliest

观众第一次失去信任的位置是症状，责任可能更早。确认是 Edit、Sound、Color/VFX 还是原始 Take/Prompt/Shot/Story 后，再修最早错误层。
