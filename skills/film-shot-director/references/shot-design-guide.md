# Shot Design Guide

## Design a sentence, not a catalog

先描述整场的镜头逻辑：观众从什么空间和关系开始，注意力因什么动作转移，何时获得关键信息，最后停在哪个新状态。然后才决定镜头数。

常见功能：

- 建立空间和人物关系
- 让关键动作可读
- 保留或揭示信息
- 看见接收者反应
- 改变权力距离
- 连接时间或声音
- 留住不可逆结果

相邻镜头若承担完全相同功能，优先合并或删除。

## Cinematic sequence grammar

先写 Viewing Stance：跟随对象/观察立场、感受距离、观众与人物的信息先后及改变立场的依据。主观不等于必须使用人物眼睛机位，疏离也不等于必须远景；机位、时长、声音与遮挡共同落实立场。

“电影感”来自有目的的观看变化，不来自术语数量。每场先定义：

- `Entry Image`：观众首先知道什么、还不知道什么；
- `Development / Hold`：注意力、距离、关系或感知如何变化或保持，不强制升级；
- `Reveal / Reaction`：关键事实出现后，谁的反应改变其意义；
- `Exit Image`：场景结束时留下什么新状态或视觉余韵；
- `Coverage Pattern`：master、关系、动作、反应和细节中哪些真正必要；
- `Transition Vocabulary`：本场允许使用的少量切换方式及其动机。

相邻镜头至少检查一个有意义的变化：信息、主体、景别、角度、视线、焦点、运动方向、深度层或视觉重量。没有变化不一定错误，但必须是有意的停留、压迫或重复。不要采用“连续两个镜头不得同景别”的机械规则。

反应镜头不是对白覆盖的填充；可服务信息含义、关系、倾听、等待或感知积累，不强制产生转折。Insert 可服务动作、状态、声音、感知或已批准意象，不为“丰富画面”而存在。

按 Scene Beat ID 核对事件/持续状态、察觉、回应、变化/保持与承接由哪些 Shot 承担；一段可跨镜，一镜可跨多个连续段落，不固定一段一镜。对白内容保留但发言者不必始终可见，前提是声音归属、信息限制与倾听反应可读。

## Camera from blocking

1. 固定人物、道具和出入口的世界坐标。
2. 定义主关系轴与允许摄影机区域。
3. 从每个摄影机位置重新计算屏幕投影。
4. 检查离画人物、视线、光源和行动路径。
5. 需要越轴时让摄影机或人物的过渡可见，或先建立新轴。

不要为了让某人始终 screen-left 而镜像场景或移动门、摊位和道具。

## Framing and lens

- 景别选择说明观众需要读空间、身体行动、关系还是细节。
- 角度选择说明权力、信息和行动可读性，不自动用低机位表示强大。
- `Lens Intent` 描述透视和距离关系，如“自然透视、保留两人空间距离”或“压缩前后关系以让等待者显得接近”。
- 只有制作格式明确时才写 24mm/50mm 等数值；数值不能代替机位和主体距离。
- 浅景深不能遮掉当前必须读到的空间或反应。

Composition Relations 记录主体占比/屏幕位置、人物间距、FG-MG-BG、负空间、遮挡与视觉重心，说明 Must Read / Must Withhold。只填对本镜有用的关系；空旷、平面化、极端留白也可成立，不强制三层或三分法。尺度可用相对描述，避免伪精确。Shot 提出构图要求，Stage 11 的 Composition Guide/Frame 验证实际可读性；不能用文字批准替代画面证据。

## Movement

完整运动事件包括：

- Start state
- Trigger
- Camera path
- Subject relation
- End state
- Stop reason

如果只写“缓慢推近”，设计尚未完成。启动依据可以是动作、声音、持续观察或批准的艺术规则；写清注意力、距离或感受如何组织及为何停止，不强制揭示新剧情。漂移仍须有路径和主体关系；静止则说明等待/观察对象、必要停留与结束条件。

## Cut motives

- 动作完成或改变方向
- 新信息出现
- 接收者的反应改变意义
- 声音引导注意
- 空间/时间状态变化
- 观众需要重新定位

不要因为对白换人就自动切，不要在动作最难连续的位置切而没有目的。

## Rhythm roles

镜头节奏可以标为 `ESTABLISH / PRESSURE / DELAY / REACTION / RELEASE / AFTERMATH`，但标签必须对应当前动作、信息或声音作用。为反应、迟疑、未回答和结果余韵保留所需停留；没有叙事触发时，不用快切制造虚假紧张，也不用长镜头冒充深度。

## Shot-to-shot handoff

每个切点同时记录：前镜最后可见状态、后镜第一可见状态、匹配锚点和允许改变项。优先使用动作接点、视线接点、声音桥、图形匹配或因果反应。若前后镜无法在人物位置、朝向、手持道具、光源或动作阶段上连接，先修 Shot，而不是留给分镜或模型猜测。

省略、倒叙、并置或艺术转换继承 Scene 的 Connection Basis，标出有意不连续、保持项和观众定位依据；不将其误写成连续动作匹配，也不为匹配擅改上游时间逻辑。

## AIGC feasibility

- 复杂动作分成物理上连续的阶段。
- 减少同镜多人交叉、频繁遮挡、长时间手部精细操作和不可控文字。
- 每镜明确主体、触发和结束状态，方便后续关键帧与视频生成。
- 如果拆分会破坏表演或关系，记录风险而不是强行简化。

艺术规则与生成风险分别判断：按批准的 Presentation Mode / Artistic Rule IDs 判断形变、平面空间或象征变化是否有意；随机身份漂移、无依据地标改变仍是错误。风险方案比较须保留 Creative Intent，说明改变镜头边界或覆盖会损失什么；不以低风险等同好镜头。

## Review and stage handoff

Shot Review 使用 PASS / REVISE / NOT_EVALUATED，注明范围、证据/发现、阻断问题/责任阶段、待媒体验证项。核对观看立场、构图、Scene Beat 覆盖、切点/声音、时长与资产用途证据。READY FOR STORYBOARD 要求文本 PASS、上游当前范围就绪且无阻断项；HIGH 风险有可审查的 Pilot 计划即可继续分镜，不能冒称模型已验证。

仅内容交付可完成 SHOT EXPLORATION 并标明待验证依赖。Start/End Frame 尚不存在时只写 Planned Frame Need / State Dependency，交由 Stage 11 创建；没有未来帧文件不是本阶段阻断项，现有上游必需资产缺失仍须明确。实际帧引用以 Stage 11 的 Frame 合同和清单为准，不在 Shot 中另建独立批准源。

## Self-audit

- 每个镜头为何存在？
- 所有 Must Show 是否真的可见？
- 相邻镜头是否重复？
- 世界坐标和屏幕投影是否混淆？
- 运动是否有触发和终点？
- 对白、动作和停顿是否放得下？
- 是否提前写了 Storyboard 或 Prompt？
