# Visual Development Guide

## Start from function

视觉开发首先问：观众需要辨认什么、空间允许人物做什么、世界规则留下什么痕迹、状态变化怎样被连续看见。不要先决定风格标签。

对每条规则检查：

1. 它服务哪个故事、人物或世界功能？
2. 它在哪些条件下出现或改变？
3. 如果删除，叙事理解或连续性是否受损？
4. 它属于事实、推断、原创还是临时假设？
5. 下游需要用什么资产证明它？

## Visual proposition and direction

Visual Proposition 用简短文字说明画面希望观众辨认什么、感受怎样的关系或世界；回指具体 Scene、人物或上游表达，不只列“写实、电影感、高级”。它是视觉表达承诺，不在此处设计镜头或重写故事。

方向尚未确定且影响整体美学时，用 Direction Comparison 比较候选的表达重点、人物/环境关系、媒介与现实规则、连续性代价；数量按实际分歧决定，不强制凑多方案。记录 Direction Decision / Basis 的选择来源与状态，已知方向直接沿用。比较是文字设计，不自动生成 moodboard 或图片，也不增加独立审批流程。

## Visual relation rules

将风格落实为可观察关系：人物与环境如何区分或融合、空间密度怎样体现关系、颜色和明暗如何组织辨识、材料与使用痕迹怎样传递时间或处境。只定义当前故事需要的规则，不强制每片都有暗部、浅景深、三层空间或磨损。

为核心规则记录稳定 Rule ID、Story / Scene Scope、关系描述、Stable / Allowed Change 与 Observable Criterion。删除规则可作作用诊断，不自动删有意感官停留；光色与空间关系可以服务体验，不必都产生情节转折。具体机位、主体占比、单镜景深与构图仍归 Shot / Storyboard。

## Character identity

在人物资产生成前定义：年龄范围、体态功能、面部和发型的最低稳定锚点、服装层级、经常操作的物件、状态变化以及不可锁定项。不要用性格直接推断五官，也不要把职业变成刻板造型。

## Location as a usable system

场景不是一张氛围图。定义出入口、相邻关系、可移动路径、固定标志、尺度参照、主要光源、材料磨损和状态变化。需要反向视图时必须能来自同一拓扑。

把环境分成结构层、表面层、陈设层和空气状态层：结构层锁定空间；表面层定义墙、地、顶和主要物件的材料、接缝与老化；陈设层定义前中后景密度和生活痕迹；空气状态层定义尘、湿度、烟、雾、风、植被及其可见运动。只锁定跨镜头必须一致或会进入近景的细节。

## Color, light and material

以下光源、重量、反射与磨损等物理细节适用于 PHYSICAL 或 MIXED 的物理层；非写实层按 Artistic Presentation Rules 定义的媒介与内部连续性呈现，不为满足写实清单伪造物理原因。

- 色彩描述关系和变化，不只列十六进制颜色。
- 光线从可识别光源、时间和空间功能推导；项目级规则不能替代场景级导演决定。
- 材质说明重量、磨损、反射、透光和使用痕迹；避免全部变成光滑塑料或无来源发光。
- 服装材料同时说明层次、织法/表面、垂坠或硬挺、光泽、缝合/扣合方式以及潮湿、脏污、破损后的变化；材料特征必须能在人物动作和光线下成立。
- 环境材料同时说明尺度、接缝、边缘、反射粗糙度、积尘/积水位置与接触磨损；同一场景的远景整体、正常观察距离和近景 Detail Plate 必须相容。
- 情感片不自动泛黄，历史片不自动降饱和，科幻片不自动霓虹，修仙片不自动云雾金光。

## Physical and artistic presentation

Presentation Mode 使用 PHYSICAL / STYLIZED / MIXED，适用范围可到 Scene State。PHYSICAL 以可识别光源、空间和材料条件为依据；STYLIZED 允许绘画、抽象、梦境或象征性变形；MIXED 分清哪些遵守物理层、哪些由艺术规则呈现。模式描述呈现方式，不改变作品的真实/虚构承诺。

非物理光线、绘画纹理、象征性漂浮或主观空间变化记录 Artistic Presentation Rules：Rule ID、Story Function、Scene / State Scope、Visible Rule & Stable Features、Entry / Exit Trigger、Allowed Change、Protected Identity / Facts。已批准艺术方法无需伪造现实光源或天气原因，但必须有明确作用与内部连续性；未批准提议保持 ASSUMED / OPEN，不能借风格改变身份、历史结果或剧本关系。

Atmospheric Medium State 继续描述物理空气。艺术呈现造成的纹理、象征性雾状形态或漂浮图形不冒充真实烟雾/颗粒，不提交给物理空气辅助 Skill 作来源核验；无真实介质写 NONE。混合画面有真实烟雾时仍需来源、分布、驱动与状态规则。艺术效果作为独立 CREATIVE 呈现合同由资产、Shot / Storyboard 或后续特效验证，不编造物理解释，也不以缺物理来源一概拒绝非写实表达。

项目要求摄影写实或降低“AI感”时，定义可观察的成像条件，而不是追加“真实、电影感、杰作”等增强词：光源及衰减、曝光与动态范围、肤质/材料的局部差异、使用痕迹、空气与天气对画面的具体影响。缺陷必须有位置和原因；不要把脏污、噪点、锐化或胶片颗粒平均铺满所有人物和场景。

## Reference translation

先记录实际看到的内容，再把参考拆成：

- `HARD_ANCHOR`：只引用已批准的本项目事实与合同字段；外部参考不能凭自身建立硬锚点；
- `SOFT_REFERENCE`：喜欢的品质、可迁移的方法和允许影响范围；
- `EXCLUSION`：水印、错误人物、文字、品牌、错误年代与其他不可转移元素；
- 本项目的原创转换；
- 禁止覆盖的身份、服装、空间、状态与事实；
- 仍需分析或取得授权的问题。

不得要求“复制某位在世艺术家的风格”。改写为媒介、色彩关系、材料、空间、节奏和年代等可描述属性。

## Scene look and light states

项目级视觉语法不能代替场景状态。为反复出现或连续性敏感的 Location/Scene State 建立稳定 ID，记录有来源的主光方向、冷暖关系、对比/曝光关系、空气与天气、主体受光和材料响应。允许变化必须同时写触发事件；下游镜头继承状态 ID，只描述偏差，不重复发明“电影感灯光”。

先建立 `Narrative Look Arc`，再建立场景状态。Look Arc 按故事时期、章节、关系阶段或不可逆事件区分，而不是每场换风格；每个节点记录叙事功能、色彩/对比倾向、光线与空气倾向、材料呈现、进入条件和退出触发。外部影片只能提供 Soft Reference 方法，不能用片名代替这些可观察属性。

变化也可由已批准的时间、记忆或感知转换触发，非写实状态引用 Artistic Rule ID；同样可以有意保持稳定。冷暖、明暗与情绪不作固定一一对应，不能把每次悲伤都编成冷色/低照度。

`Atmospheric Medium State` 属于场景状态的物理层，至少回答介质、来源、空间分布、密度、运动驱动、受光方式与连续性触发。灰尘、蒸汽、烟、雾、湿气或花粉只有在地点和事件能解释时才出现；无来源的全局颗粒、持续飘雾或每场逆光尘埃不构成电影感。

## Asset prioritization

- `P0`: 不先锁定就无法保证主角、核心空间或关键道具连续性。
- `P1`: 多场复用、状态变化明显或容易漂移。
- `P2`: 单场、背景或可在场景阶段补充。

只请求剧本动作、预计观看方向与连续性风险真正需要的视图和状态，主角也不默认全套六视图。脸部辨识需要正面人脸锚点；纯背影/剪影或抽象形象可用体态/轮廓母版，未验证面部不供露脸使用。当前机位未定时记录必要范围与待补条件，不要求跳到 Shot Design 预先锁机位。人物身份、服装、妆发分别列 Asset ID，再定义 Combined Look 依赖；必要材料另列 Detail Plate。

## Self-audit

在 Continuity Risks 的 Visual Rule Validation 中把核心关系规则与艺术规则回链到最小必要 Asset ID / Views or States、Observable Criterion、Verify At Stage 和 Validation Status。设计阶段均为 PLANNED；单资产的身份、材质或空间证据交给 Asset，跨主体关系与画面整体可读性留给 Storyboard，动态转换留给 Motion / Generation / QC，不要求资产图代替正式分镜。

Decision Register 的 Visual Review 使用 PASS / REVISE / NOT_EVALUATED，记录 Scope & Evidence、Findings & Resolution 与来源；自检注明 SELF-AUDIT。PASS 仅证明文本视觉合同足以交接，不证明画面效果、用户批准或 G3 通过。READY FOR ASSET DESIGN 仍需规则、参考、场景状态及验收映射完整，影响方向的 OPEN 决定须先解决。

- 是否每条视觉规则都有叙事来源？
- 是否把 OPEN 项悄悄锁定？
- 是否把历史推断说成事实？
- 是否把“氛围”当作空间设计？
- 是否默认使用套路化电影感？
- 是否提前写镜头或 Prompt？
- 是否列出最小必要资产和审批顺序？
- 外部参考是否完成 HARD_ANCHOR / SOFT_REFERENCE / EXCLUSION 转换？
- 核心场景是否有可继承的 Look & Light State，且变化有触发？
- Narrative Look Arc 是否来自叙事时期/关系变化，而不是任意换风格？
- Atmospheric Medium 是否有来源、分布、驱动与连续性，或明确为 NONE？
- 风格是否转成可观察关系，视觉命题与选择依据是否一致？
- 物理空气与艺术呈现是否分开，艺术规则的范围与变化是否明确？
- 核心规则是否有资产/状态、验收点和验证责任阶段，而不是只写“达到电影感”？
