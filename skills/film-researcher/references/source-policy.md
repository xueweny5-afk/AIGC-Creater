# Source and Evidence Policy

本文件定义来源、证据状态和交叉验证规则。Research Pack 中所有外部事实都必须能追溯到 `source-index.md`。

## 来源类型

- `OBSIDIAN_NOTE`：用户知识库中的笔记、摘录或个人判断。必须记录 vault 与路径。
- `PRIMARY_SOURCE`：与事件或主题直接相关的原始文献、档案、原始数据、实物记录或当事材料。
- `ACADEMIC_SOURCE`：同行评审论文、学术专著、高校或研究机构的专业研究。
- `OFFICIAL_INSTITUTION`：政府、博物馆、档案馆、科研机构、国际组织或其他权威机构发布的资料。
- `PUBLIC_REFERENCE`：可靠出版物、专业媒体、百科和公开参考材料，用于补充或导航，不能自动替代更高等级证据。
- `CREATIVE_WORK`：文学、电影、动画、游戏、绘画、摄影、音乐、舞蹈、戏剧或其他创作作品。用于研究类型方法与艺术表达，不用于证明作品之外的历史、现实或科学事实。
- `PLATFORM_SIGNAL`：公开视频、搜索结果、榜单或平台讨论，只能支持近期传播与受众信号，不能证明历史或科学事实。

来源类型不等于结论一定正确。每个来源仍需记录作者或机构、发布时间、原始性、与其他来源的关系和明显限制。

## 证据状态

- `CONFIRMED`：同一关键结论得到至少两个有独立性的可靠来源支持，历史模式优先使用“原始材料＋学术或权威解释”。
- `SINGLE_SOURCE`：目前只有一个可用来源，或多个页面实际源自同一材料。
- `DISPUTED`：可靠来源之间存在事实、解释、时间、人物或因果分歧。
- `UNVERIFIED`：仅有线索、个人笔记、平台内容或无法定位原始依据。
- `REFERENCE_ONLY`：仅作为创作参考，不参与事实结论的证据评级。

ARTISTIC_PROPOSAL 与 REFERENCE HYPOTHESIS 分别标记本项目创意和待验证的迁移方法，不新增事实证据等级。艺术提议不因无法证明现实中发生过而被排除；它包含的外部事实声明仍按上述状态核验，不以“艺术许可”隐去事实边界或改写用户锁定决定。

不得用来源数量代替独立性。转载、镜像、互相引用或共同源自同一古籍、数据库、新闻稿的页面应视为同一证据链，并在限制中说明。

`REFERENCE_ONLY` 不得支持 `CONFIRMED` Claim，也不得提高候选的 `Evidence Confidence`。作品本身的出版信息、内容覆盖和创作方法分析仍须如实记录来源与阅读范围。

## Claim 与 Source 连接

- 为研究结论分配 `CLM-###`，为来源分配 `SRC-###`。
- 每条 Claim 必须列出支持来源 ID 和状态。
- 来源索引必须反向列出它支持的 Claim。
- 直接引语只保留必要短句；优先使用忠实概括，并标记页码、章节、条目或页面位置（如可获得）。
- 不将模型常识写成来源，不生成看似真实但未访问的链接、作者、日期、页码或互动数据。

## Obsidian 规则

1. 默认先搜索用户指定的 vault 和范围。若 Skill 已记录用户明确授权的默认 vault 与默认范围，可以使用该默认值；两者都没有时才询问，不自行扫描所有私人笔记。
2. 只使用 `search`、`read`、`tags`、`backlinks` 等只读能力，不使用 `create`、`append`、`property:set` 或其他修改命令。
3. 记录 `vault`、相对路径、笔记标题和相关段落位置；不要把完整私人笔记复制进研究包。
4. 笔记包含可追溯引用时，分别登记笔记与它引用的原始来源；未核实原始来源前，笔记内容仍为 `SINGLE_SOURCE` 或 `UNVERIFIED`。
5. 私人笔记不得上传到外部服务或作为网络查询全文发送；查询词只包含完成研究所需的主题、实体和公开事实。

## 公开网络规则

- 技术、科学、历史和事实性查询优先使用原始资料、论文、官方文档、权威机构与专业出版物。
- 关键事实至少交叉核实两个独立来源；无法满足时降低证据状态，而不是降低标准。
- 记录直接支持结论的页面链接、发布日期（若有）和访问日期。
- 搜索摘要只用于发现来源；未打开并核对页面内容时不得作为正式证据。
- 对时效性信息必须记录研究日期和适用时间范围。

## 创作作品研究规则

- 用户指定或明确喜欢的作品优先；未指定时选择小而有代表性的样本，兼顾类型奠基、专业评价、影响力与方法差异，不以榜单热度代替质量判断。
- 分开记录 `Full Text / Authorized Excerpt / Direct Work / Detailed Review / Synopsis / Metadata Only`。Direct Work 指直接查看或聆听作品，须注明具体画作/照片、实际片段、音轨或演出范围；不表示看完/听完整部作品。只能分析实际覆盖到的内容，不得声称通读未读取的作品。
- 提炼可迁移方法，例如题材承诺、世界规则与代价、人物欲望、视角、节奏、成长反馈、情绪和审美原则。
- 明确记录不可复制项：独特人物、专名、力量体系、情节顺序、标志性场面、对白、文风片段和可识别视觉表达。
- 遵守版权边界，不提供大段原文、章节复述或足以替代原作的详细梗概；必要引语保持最短并标明出处。
- 多部作品出现相似惯例时，可归纳类型模式，但需区分共同惯例、单部作品创新与研究者推断。
- 由绘画、摄影或音乐迁移到影片时，说明观察到的形式关系、可能的体验和本项目发展方向；不要求题材相同，不把象征解释当作者已确认的意图，也不从参考作品自动锁定影片最终美术或声音设计。

## 视觉线索规则

- 可登记博物馆藏品、档案图像、地图、遗址、建筑、服饰、器物、自然环境与可靠复原研究。
- 每条线索记录对象、时期、来源页面、它能支持的视觉判断、授权或版权状态以及局限。
- `授权未知` 不等于可自由使用；本 Skill 不下载、不重新发布、不生成绕过授权的副本。
- 影视剧照、游戏设定和网络插画只能作为后世表达或创作参考，不能自动作为历史视觉证据。

## 平台趋势规则

- 默认时间窗口为最近 30 天，必须记录起止日期和实际成功检索的平台。
- 不虚构播放量、点赞、评论、热度、受众画像或跨平台共识。
- 缓存结果必须标记缓存状态；来源稀疏时只报告弱信号。
- `Trend Signal` 独立于核心候选评分，只能帮助判断传播语境、表达方式和竞争密度，不能覆盖史实、项目意图或长期内容价值。
