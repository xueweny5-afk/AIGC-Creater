# Scene Direction Guide

## Direct behavior, not emotion

把情绪结果改写为行动任务：

- 不写“表现出不安”，写“继续整理已经整齐的物件，避免回应对方的提议”。
- 不写“愤怒地质问”，写“截断对方解释，把托付物推回其工作区”。
- 不写“温情对视”，写“在跨越边界前停住，等待对方明确允许”。

动作动词应能被演员执行：争取、拖延、确认、回避、试探、撤回、守住、允许、打断、重新定义。

陪伴、等待、共同整理、观察和沉默同样可以构成表演。不要把每次停顿解释成算计，或为日常场景强加障碍。策略没有变化时写 HOLD 与观看作用；身体细节只保留角色习惯、行动或环境能支持的部分。

## Connected scene beats

先顺读一场戏，再按实际行动段记录 `Beat ID / Event or Sustained State / Perception / Action & Response / Effect or HOLD / Handoff`。察觉对象可以是人、声响、物件或持续状态；不知情、延迟反应也须有依据。每段明确下一段接住什么，段数由戏决定，不要求每段转折，也不拆成摄影镜号。

例如：两人共同收拾 → 一人发现另一人动作变慢 → 放下手中物件等待，对方继续整理 → 工作节奏放缓、陪伴延续 → 下一段从共同等待接起。若剧本没有这项行为，不为展示该范式而新增事件。

## Blocking from power and need

调度先固定世界坐标，再根据人物目标安排：

- 接近或撤退是否改变请求压力？
- 谁控制出入口、物件、工作面或信息来源？
- 谁可以跨越边界，谁必须等待许可？
- 人物位置变化是否造成新的选择或可见后果？

没有因果意义的走动不要添加。不要为了“丰富画面”让人物反复踱步。

因果也包括工作需要、习惯、亲近、协作和共同注意。对关键位移或保持位置说明触发、路径/停留处、关系作用与他人回应；不用强制移动证明场景有效。

## Information design

分别记录：

- Audience knows
- Character A knows
- Character B knows
- Withheld
- Reveal trigger

悬念、谜团和惊讶不是同一种信息安排。观察式项目也要清楚观众何时发现重复行为已改变。

## Sound and time

- 场内声音应来自行动与环境，并影响注意、打断或节奏。
- 沉默要说明谁停止了什么行动、谁在等待回应。
- 时间压缩要保留状态变化的关键节点，不用蒙太奇标签跳过因果。
- 配乐方向最多说明功能与进入/退出条件，不提前选曲或用音乐替代人物行动。

## Rhythm intent

节奏先来自人物需要多少时间完成行动、倾听和改变策略，再由声音能量和信息密度加强。每场记录：进入压力、行动密度、声音能量、必须保留的反应/静默、转折触发和退出压力。不要用“这一场快一点/慢一点”代替原因，也不要把剪辑速度当作掩盖缺少行动的工具。

## Scene chain audit

- 直接延续是否继承上一场 Exit State？倒叙、省略和并置是否标明时间边界及已批准的连接依据？
- 人物策略的变化是否有可见或可听触发；保持时是否有明确作用？
- 退出状态、声音、感知或意象如何交给下一场？
- 哪个道具、知识、关系或空间权限发生变化？
- 删除本场是否损失行动、关系、感知积累、节奏或意象作用？均无作用才返回剧本诊断，不只用剧情推进衡量。

## Artistic presentation

读取 Presentation Mode 和 Artistic Rule IDs 的确切版本。真实空气变化记物理来源与驱动；象征色块、绘画空间或梦境变化记 `Artistic Layer / Trigger / Preserved Features`，依批准规则发生，不伪装成真实雾气或未经证实的实体空间。规则未授权的身份、地标或故事改变返回对应上游，不靠“艺术表达”豁免。

## Asset-pending work

资产未覆盖当前用途时可以设计功能性调度，例如“角色停在分界处”；依赖未验证外貌、服装、尺度或道具形态的动作标为条件方案及 Asset Dependency，不冒充生产锁定。可交付完整文字包并保持 `DRAFT_ASSET_PENDING`；无需等待回传媒体才能交付文本。

## Scene review

Scene Review 写 PASS / REVISE / NOT_EVALUATED、覆盖场景、已检查证据、问题/责任阶段及依赖。检查行动段衔接、表演可执行性、调度依据、信息与声音、艺术规则和跨场连续性。审核对象是文字设计，不代表实际表演或画面效果。当前范围设计 PASS、无阻断项且所需 P0 用途有确切批准证据才标 READY；不从单图或资产总体状态外推未验证用途。
