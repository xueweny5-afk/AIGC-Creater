# 微表演与动作化描写方法

本方法由用户提供的“抽象表情转微动作”样例整理而来。样例的价值在于克制、延迟和细微泄露；其中“惊讶就睁眼、悲伤就嘴角下撇”等组合不能作为普遍心理规律或固定模板。

## 一、表演链语法

```text
Baseline
→ Trigger
→ Latency / HOLD
→ Attention Shift
→ First Leak
→ Regulation or Displacement
→ Secondary Change
→ Settle / Handoff
```

- **Baseline**：人物原本的任务、姿态、重心、视线、呼吸、手和道具状态。
- **Trigger**：真正进入人物感知的具体事件。
- **Latency / HOLD**：人物需要理解、拒绝相信或选择不回应的时间。
- **Attention Shift**：视线、头颈、动作节奏或倾听对象发生变化。
- **First Leak**：人物尚未完全控制的最小可见变化。
- **Regulation**：把反应压住、恢复原动作、改变语气或重新看向对方。
- **Displacement**：压力被转移到整理衣袖、扶杯、抹桌、换手握物等已有任务。
- **Secondary Change**：控制后的第二次泄露，通常比第一反应更能说明人物选择。
- **Settle / Handoff**：动作停在哪里，下一镜继承什么。

不必每次写满。一个克制反应可能只有：`触发 → 保持原动作半拍 → 手停住 → 继续做事，但不回答`。

## 二、动作通道

### 姿态与重心

承重脚、肩胯关系、脊柱张力、靠近/后撤、身体是否继续面向当前任务。适合中景和全景，也比脸部细节更容易跨镜头保持。

### 视线与眼睑

看向谁、何时移开、停留多久、是否重新抬回；眼睑开合与眨眼只在有触发和可见价值时使用。不要默认用眼睛放大证明惊讶，也不要用“瞳孔聚焦”替代明确注视目标。

### 呼吸、声音与停顿

吸气被打断、呼气延长、回答延迟、音量或句尾变化、吞咽、沉默。呼吸要与说话、动作负荷和身体状态相容，不能每逢紧张都写急促喘息。

### 嘴唇、下颌与面部张力

下颌短暂固定、嘴唇闭合、口腔准备说话后放弃、咀嚼或吞咽动作中断。脸部变化应从整个头面张力产生，不把嘴角当情绪开关。

### 头颈

朝向变化、下巴高度、是否倾听、是否避开。幅度通常小于身体调度，但必须有对象和原因。

### 手、道具与任务

握力、接触面积、动作中断、换手、放下、整理、擦拭、重复或漏掉步骤。优先利用人物本来就在做的事，避免无来源握拳、搓手或摸脸。

### 空间距离与关系

一步靠近、停止跨界、让开通道、把物件推回、保持背对。关系变化往往比眉眼更有叙事力量。

### 服装与头发响应

只记录身体动作、接触或风造成的物理反应；不让衣摆和头发自动飘动来代替表演。

## 三、通道预算

每个 Beat 选择：

- **Primary channel**：观众主要通过它理解变化；
- **Supporting channel 1–2**：加强或反向抵消主通道；
- **HOLD layers**：保持不动，防止画面噪声。

例如人物极力保持冷静时，主要通道可以是“手中动作停了半拍”，支持通道是“回答延迟”，脸和身体其余部分 HOLD。克制来自冲突，而不是所有动作都变小。

## 四、延迟、幅度与恢复

### 延迟

用可执行的相对时间：`听完最后一个词后`、`杯底碰桌时`、`对方转身之后`、`停半拍`。只有 Motion/Prompt 阶段且时长已锁定时才使用秒数。

### 幅度

相对基线描述：视线只移到物件而非对方、手指压力增加但手腕不动、肩膀保持而下颌短暂固定。不要连续堆“微微、轻轻、缓缓”。

### 恢复

人物是否收回反应决定含义：立刻恢复原动作、恢复但节奏变慢、试图恢复却漏掉步骤、干脆停止。恢复是动作链的一部分。

## 五、景别可读性

| 景别 | 优先可读通道 | 风险 |
|---|---|---|
| 全景 | 空间距离、路径、姿态、重心、任务中断 | 眉眼和嘴角细节不可读 |
| 中景 | 上身张力、手/道具、视线、呼吸节奏 | 太多小动作互相抵消 |
| 近景 | 眼睑、视线停留、下颌、嘴唇、吞咽、呼吸 | 容易过演或变成表情展示 |
| 特写 | 单一局部变化及其时间 | 失去人物任务与空间原因 |

如果关键变化只有特写才能看到，而上游 Shot 是全景，不能擅自把动作写得更细；返回 Shot Design 决定换景别、使用声音，或改为身体/任务层变化。

## 六、从抽象词到候选路径

以下只是可选择的机制，不是表情字典。

### 意外、困惑或发现

- 原动作停在未完成位置，视线先寻找信息来源，再决定是否转头；
- 问话已经到嘴边但先观察对方，回答延迟；
- 身体仍维持原方向，只有注意对象改变；
- 角色习惯控制表情时，第一泄露可以落在漏做一步、握物停顿或语序变化。

### 失落、悲伤或委屈

- 继续完成日常动作，但节奏变慢或重复一次；
- 视线避开关系对象，手仍维持照料或工作任务；
- 呼气没有完成一句话，随后选择更实际的动作；
- 不一定低头、嘴角下撇或哭泣，尤其当人物必须维持体面或照顾他人时。

### 坚定、决断或重新掌控

- 重心重新居中，手停止无效动作，视线落到明确对象；
- 先完成一个小而不可逆的实际动作，再说决定；
- 语句缩短、停顿减少，但不必“眼神锐利”或摆出英雄姿态；
- 平静可以来自动作顺序变清楚，而不是面部线条突然冷硬。

### 释然、无奈或接受

- 长时间维持的握力或姿态释放，呼气终于完成；
- 视线从单一对象扩展到环境，随后回到现实任务；
- 不再纠正某个小问题，或把物件归位后停止重复确认；
- 不必微笑；变化可以是停止抵抗、允许沉默或接受未完成。

## 七、克制反应示例

抽象要求：人物听到刺痛自己的话，表面平静，最后露出一点不适。

可观察写法：

```text
人物仍靠在原处，呼吸保持浅而均匀，视线没有立刻转向说话者。对方说完后，他继续完成手里的小动作，第一次没有回应；动作结束时手没有马上离开物件，停半拍，下颌短暂固定，随后才抬眼。眉间只在视线抬起前收紧一下，结束时已经恢复，回答仍未开始。
```

有效机制是“维持 → 延迟 → 任务中的停顿 → 一次短暂泄露 → 恢复”，不是把每个脸部部位都调成“难过”。

## 九、审查问题

- 删除情绪词后，观众还能通过动作理解变化吗？
- 动作是否真的由触发产生，而不是随机加生命感？
- 是否利用人物已有任务，而不是凭空增加小动作？
- 一个主要通道是否足够，其他层是否应该 HOLD？
- 表面控制与内部压力是否形成可见矛盾？
- 动作幅度与当前景别、时长相容吗？
- 结束状态能被下一镜继承吗？
- 是否把文化、性别、年龄或心理诊断刻板化为身体语言？
