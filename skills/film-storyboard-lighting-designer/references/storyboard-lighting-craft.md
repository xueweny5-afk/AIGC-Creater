# 分镜光影设计方法

本方法由用户提供的“分镜完成后逐镜补充光影”样例归纳而来。样例中逐镜整理主光、辅光、色温、明暗关系与人物受光的方向是有效的；具体窗棂光、冷暖对冲、暖日光、单侧窄光等属于片段方案，不能成为每个项目的固定套路。

## 一、三层光影合同

### 1. 世界层

由 World & Visual Bible / Scene Look & Light State 定义：时间、天气、地点、实际光源、方向、颜色关系、材料与空气。它回答“这个世界为什么这样亮”。

### 2. 镜头投影层

由本 Skill 定义：当前机位看见哪些光源作用，人物与环境怎样受光，画面明暗如何组织。它回答“这个机位怎样看见同一套光”。

### 3. 后期层

Post 负责镜间曝光、白平衡和颜色匹配，以及批准范围内的精修。它不能把错误光向、漂浮阴影或不存在的来源调成合理。

## 二、世界方向与画面方向

灯光连续性必须有两个坐标：

- **World-space source**：光源在地点中的固定位置和方向，例如南侧高窗、桌上油灯、街口招牌。
- **Camera-view projection**：在当前 Frame 中表现为画面左前、右后、顶部或背景方向。

摄影机反打后，世界中的同一扇窗可能从画面左侧变成画面右侧；这不是光源移动。只写“左侧主光”而不写世界来源，会导致跨镜跳光。

## 三、逐帧设计顺序

### 1. 叙事优先级

确认本帧必须读到的人、动作、表情、手/道具、空间信息和隐藏信息。光线可以引导注意，但不能改变故事或遮住 Must Show。

### 2. 光源清单

记录实际来源、位置、方向、面积/距离关系、硬软、遮挡和颜色。太阳与天空、窗光与室内反射、火与灯具要分开；不要把 Key/Fill/Rim 误当成固定三点布光。

### 3. 主体塑形

说明哪些面受光、哪些面进入阴影、眼睛是否需要可读、皮肤与年龄纹理如何保留、手和道具接触是否清晰。人物可以半遮挡或轮廓化，但必须由叙事和构图支持。

### 4. 环境与负空间

墙、地、顶、门窗、家具和地面会反射、吸收或遮挡光线。负补光不是额外黑色灯，而是缺少反射或使用遮挡形成的暗面。背景分离可以来自亮度、色彩、景深或遮挡，不必总加轮廓光。

### 5. 曝光和明暗结构

用相对关系描述：主体比背景亮/暗多少层级、黑位是否保留纹理、窗外是否允许接近白、灯具是否保留芯部。数值只有在相机或模型配置可验证时才写。

### 6. 色彩关系

先说明颜色来源：日光/天空、火焰、钨丝灯、荧光灯、招牌、墙面或地面反射。冷暖关系可以并存，但不能把情绪直接做成全局蓝染或黄染。肤色受环境影响但仍应符合人物与曝光状态。

### 7. 材料与空气

粗糙、光滑、湿润、金属、布料、皮肤、木石的高光宽度和反射颜色不同。雾、尘、烟、雨和蒸汽只有在有来源、分布和驱动时才显光；清洁空气不需要为了电影感制造光柱。

## 四、光影弧线

全片或段落的光影递进不是把画面从亮调到暗，而是由故事条件推动：

```text
Inherited baseline
→ Physical or narrative trigger
→ Source / occlusion / exposure relationship changes
→ Character and environment respond together
→ New stable state
```

有效触发包括：日照角度随时间变化、人物从室外进入室内、门窗开合、灯被点亮/熄灭、火势变化、天气遮住太阳、摄影机/人物进入新的光区。单纯“情绪更悲伤”不是光源变化的物理触发；它可以改变构图中的曝光选择，但不能让太阳换方向。

## 六、灯光编辑提示词骨架

```text
以 [Frame ID / source image] 为唯一编辑目标，只调整已批准的光影。

Change:
- 让 [世界光源] 从 [世界位置] 作用于场景，在当前机位表现为 [画面投影方向]
- 调整 [主体/背景] 的曝光、反差和颜色关系
- 让 [皮肤/服装/道具/墙地] 按各自材料共同响应
- 建立与 [前后 Frame] 一致的阴影方向与黑位层次

Preserve:
- 人物身份、年龄、表情、姿态、手部和道具状态
- 镜头、构图、画幅、景深、场景拓扑和所有物件位置
- 已批准的时间、天气、空气状态与故事信息

Constraints:
- 不新增无来源光、轮廓光、光束、雾、烟、道具、人物或文字
- 不改变光源世界方向，不磨皮，不极端 HDR，不压死暗部或炸白亮部
```

## 七、连续性审核

按顺序比较：

1. 实际光源是否仍在同一世界位置；
2. 摄影机变化后投影方向是否几何合理；
3. 人物转身时亮面、暗面和投影是否随身体正确变化；
4. 墙地、道具、服装和皮肤是否共同响应；
5. 阴影接触点、长度、软硬和方向是否连续；
6. 曝光、黑位、白平衡和肤色是否无因跳变；
7. Atmosphere State 是否一致，或变化有真实触发；
8. 关键表演与 Must Show 是否仍可读；
9. 变化是否属于光影，而不是偷偷改变构图或资产。

## 八、常见失败

- **独立漂亮、顺序跳光**：逐帧好看，但主光方向和曝光在剪辑中乱跳。
- **脸部贴光**：脸变亮，环境、颈部、衣物和投影没有响应。
- **无来源轮廓光**：人物边缘永久发亮，与空间中的光源无关。
- **反打镜像光**：画面左光在每个机位都固定从左侧来，世界光源随摄影机移动。
- **情绪滤镜化**：悲伤就全蓝、回忆就全黄、危险就全红。
- **夜景蓝洗**：所有表面同一种蓝色，实际灯具、天空和反射关系消失。
- **黑位涂死 / 亮部炸白**：用失去信息代替对比。
- **体积光滥用**：为了看见光束凭空添加雾尘。
- **后期越权**：试图靠 LUT 或局部提亮修复错误光向和阴影。
