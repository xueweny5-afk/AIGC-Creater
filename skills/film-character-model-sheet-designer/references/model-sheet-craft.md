# 角色多视图设定板创作方法

本方法由用户提供的人物模型提示词样例整理而来。样例中的四视图、白色摄影棚、柔光、皮肤微细节和禁止磨皮是有价值的方向，但固定色温、固定眼神光、固定肤色、8K 与颗粒不是跨角色通用规则。

## 一、资产层级

按以下顺序建立角色，不要从一张四宫格直接跳到“正式角色资产”：

1. **Canon Face**：正面、平视、中性表情、无遮挡，用于批准脸部身份。
2. **Canon Body**：正面全身，锁定身高范围、头身比、肩胯、四肢比例和自然站姿。
3. **Head Angles**：从批准脸部母图派生左右 45° 与左右侧面。
4. **Body Turnaround**：从批准身份与体态派生必要的全身视图。
5. **Detail Plate**：只在近景需要时增加眼、鼻口、耳、手、皮肤或标记细节。
6. **Contact Sheet**：把已批准独立图排成审阅板，不反向替代独立原图。

单次生成的多格图可以作为 `COMPACT CONCEPT BOARD`，适合方向探索，但模型常在格子之间改变耳形、鼻口比例、发缝、四肢长度或服装接缝，因此不能单凭它建立连续性。

## 二、视图协议

### 四视图快速板

适合概念评审和低风险角色：

1. 正面全身
2. 侧面全身，明确左侧或右侧
3. 背面全身
4. 正面或轻微 3/4 上半身身份细节

四格顺序、画幅、人物尺度和留白保持一致。最后一格负责脸部和皮肤判断，不应采用戏剧性肖像光。

### 全身六视图

适合跨镜头复用主角：

1. 正面
2. 左前 45°
3. 左侧
4. 背面
5. 右侧
6. 右前 45°

如果角色左右差异是连续性关键，可补充右/左背 45°；没有下游用途时不要扩张视图数量。

### 头部角度组

正面、左右 45°、左右侧面。保持同一表情强度、视线高度、发型状态、相机距离和光线。侧面必须检查额头—鼻梁—嘴唇—下巴的连续轮廓，不用正面五官简单“贴”到侧脸。

## 三、身份锁定层级

不要只写“完全相同”。从上到下列出能肉眼比较的锚点：

### 1. 头颅与脸部几何

- 头颅宽高、面中长度、颧弓和下颌宽度
- 额头曲线、发际线与太阳穴关系
- 眉形、眉眼距离、眼距、眼裂走向与眼睑结构
- 鼻根、鼻梁、鼻翼宽度和鼻尖体积
- 人中、唇峰、上下唇比例、嘴角和下巴形态
- 耳廓形状、大小、高度和贴离程度

### 2. 可追踪不对称

真实身份通常存在轻微左右差异，例如一侧眉峰、眼睑褶皱、鼻翼、嘴角或耳位。记录它们的方向，防止模型在不同视图中镜像或互换。

### 3. 发型结构

锁定发际线、分缝方向、刘海分区、长度、发量轮廓、卷曲程度、鬓角和后颈收束。仅写“黑色短发”不足以维持身份。

### 4. 肤色与稳定标记

肤色必须来自角色合同或参考图，不预设种族化色号。记录整体基调、面部区域差异、日晒或红润倾向，以及痣、疤、雀斑等标记的准确位置和尺度。

### 5. 体态与比例

锁定身高范围或画面标尺、头身比、颈长、肩宽与斜度、胸腰胯关系、手臂与腿长、手足尺度、体脂和肌肉分布、自然重心。不要用“修长、完美比例”替代可观察结构。

### 6. 服装与妆发

若设定板包含服装，锁定层级、版型、衣长、领口、袖口、腰线、接缝、扣合、材质垂坠、鞋型和配件位置。正式制作中人物身份、服装、妆发应有独立合同；合体图不能改写源资产。

## 四、姿态与摄影棚标定

### 姿态

- 自然站立，重心稳定，双臂自然离开躯干少许，手指放松且可见。
- 肩、骨盆与脚尖朝向符合指定视图，不扭腰代替转身。
- 表情中性但有生命感；不要僵硬军姿、T-pose 或时尚摆拍。
- 全身不裁头、不裁脚，不用前后伸手制造透视变化。

### 相机

- 同组全身图保持相机高度、距离、近似焦段、人物尺度与地平线一致。
- 使用接近正交的观察关系，避免广角近摄造成头大脚小或四肢缩短。
- 上半身细节板可以更近，但必须说明它不用于比较全身比例。

### 灯光与背景

- 背景使用白至浅灰无缝墙或干净中性棚，均匀、无纹理、无杂物、无文字水印。
- 主光以大面积柔光为主，让额头、颧骨、鼻翼、下颌和身体体积仍然可读。
- 补光只抬起黑位，不打平微阴影；分离光可选且必须弱，不污染肤色和轮廓。
- 使用中性、受控的白平衡；只有平台或项目校准要求时才给出色温数值。
- 眼神光形状是灯具结果，不是身份特征。需要时只要求自然、稳定、不过亮。

## 五、皮肤真实性的三层结构

### Macro：骨骼与软组织体积

先正确表现眼眶、颧骨、鼻翼、唇周、下颌、颈部和年龄相关软组织。光线必须产生可信微阴影，不能为了“干净”把脸打平。

### Meso：区域变化

皮肤不是单一色块。根据角色状态保留额头、鼻梁、脸颊、眼周、唇周和下颌的轻微冷暖、红润、色素、油脂或干燥差异。变化应细微且有生理依据，不添加未定义病理特征。

### Micro：表面细节

毛孔的大小、密度和方向随部位变化；细纹符合年龄和表情；睫毛、眉毛和桃绒具有真实尺度与受光。微细节不能依赖均匀颗粒、锐化边缘或噪点纹理，远景也不应出现不合尺度的巨大毛孔。

成像清晰度应来自真实光学解析力和正确对焦。胶片颗粒、数字锐化、HDR、Bloom 和磨皮都不是皮肤细节的替代品。

## 六、提示词编译顺序

```text
资产用途、Asset ID 与状态
→ 唯一身份参考及其角色
→ 本次视图协议与排列
→ 具体身份锁定项
→ 各视图姿态、相机与比例标定
→ 服装/妆发锁定项
→ 中性灯光、白平衡与背景
→ 皮肤 Macro / Meso / Micro
→ 当前风险对应的排除项
```

### 四视图快速板骨架

```text
为 [Asset ID] 创建同一角色的四视图审阅板，依次为正面全身、[左/右]侧面全身、背面全身、正面上半身身份细节。以 [IDENTITY reference] 为唯一身份来源；四格严格保持 [列出脸部几何、发型、肤色与标记、体态、服装]，只改变观察角度和取景范围。

全身格采用相同人物尺度、相机高度、自然中性站姿，头部和手足完整，近似正交观察，无夸张透视。上半身格保持中性表情和平视，用于检查五官、年龄与皮肤，不使用戏剧性肖像光。

白至浅灰无缝摄影棚背景，中性白平衡，大面积柔光，暗部保留骨骼与皮肤微阴影。皮肤先保持真实体积和区域性色彩变化，再呈现符合部位尺度的毛孔、细纹、睫毛阴影与桃绒；无均匀噪点毛孔、磨皮或数字锐化。
```

对正式资产，优先为每个视图编写独立提示词，只改变 `required view`，其余身份锁定段保持逐字一致。最终合板在独立视图批准后制作。

## 七、排除项与验收分离

### 常用排除项

只选当前相关项：

- 身份漂移：脸型、年龄、耳形、鼻口比例或稳定标记变化
- 镜像错误：发缝、不对称特征、痣疤和配件左右互换
- 结构错误：多肢少肢、手足畸形、五官扭曲、身体比例变化
- 视图错误：侧面不是严格侧视、背面回头、以扭腰冒充转身
- 服装漂移：版型、层级、接缝、扣合、图案、鞋和配件变化
- 棚拍干扰：投影、渐变、纹理、道具、文字、标注、水印或额外人物
- 皮肤失败：塑料、蜡感、油亮、磨皮、颗粒毛孔、过度锐化、重 HDR

### 视觉验收表

把以下内容留在 QC，不重复塞进 Prompt：

- 同一角度叠加或并排时，眼距、鼻口、下颌、耳位和发际线是否对应
- 左右稳定特征是否被镜像或消失
- 正面、侧面、背面的头身比、肩胯、四肢长度和手足尺度是否一致
- 发型背面结构能否解释正面与侧面的轮廓
- 服装接缝、层级和配件位置能否在各角度闭合
- 皮肤色彩与细节是否随光线变化但身份不变
- 每格的视图、裁切、人物尺度、背景和光线是否符合协议

## 八、返工写法

```text
Change:
- 仅修正 [失败字段和目标视图]

Preserve:
- 保持 [批准身份锚点、体态、服装、背景、光线和其他已通过视图]

Constraints:
- 不重抽身份，不镜像左右特征，不改变年龄、发型、肤色或身体比例
```

如果多个视图同时发生不同方向的身份漂移，返回批准的 Canon Face/Body 重新逐张派生，不在错误合板上继续叠加修补。
