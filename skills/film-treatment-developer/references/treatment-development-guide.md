# Treatment Development Guide

## 1. Treatment 与相邻阶段

Treatment 回答“完整故事或体验怎样展开、各段为什么相接、结束时留下什么”。它比 Story Blueprint 更具体，比 Screenplay 更抽象。

| 阶段 | 核心问题 | 本阶段禁止代做 |
|---|---|---|
| Story Blueprint | 故事的核心与运动是什么 | 完整过程 |
| Character System | 谁行动，为什么，有何边界 | 为角色安排全部事件 |
| Treatment | 行动、回应、信息或感知如何形成完整过程 | 场景写作、对白、镜头 |
| Screenplay | 观众在具体场景中看到和听到什么 | 镜头拆解与生成提示词 |

出现 `INT./EXT.`、具体场景标题、角色名加对白、逐句旁白或摄影指令时，停止并抽象回叙事层。

## 2. 高风险决定

下列 OPEN 项不能静默假设：

- 代价最终由谁承担；
- 主角是否主动伤害、牺牲或欺骗他人；
- 谁拥有知情权与同意权；
- 结局把哪个价值判断变成不可逆行动；
- 真实事件中某项未证行动是否发生；
- 连续剧本次范围是单集、试播还是阶段弧。

一次只暴露最上游的阻断问题。回答后再判断是否出现下一项，不把用户拖进问卷。

## 3. 正文顺读与连贯性检查

先写 Complete Treatment，再做 Sequence Map。叙事作品对主要段落依次问：

1. 什么既有状态使这个行动可能？
2. 谁做了什么，而不是“故事需要发生什么”？
3. 这个行动带来什么新限制或信息？
4. 下一步是否由这一结果触发？
5. 若删除或调换本段，理解、关系感受或结尾支撑会损失什么？作为诊断检查重复与顺序作用，不自动删除有意停留或用户必须呈现的内容。

每次重要变化后检查人物怎样理解、回应或不回应，回应为何引出后续；不能只串事件标题或借旁白解释缺失过程。不要求每段都安排心理解释、反应或转折；事实层未知的真实心理不能补写。

观察/诗性作品检查时间、劳动、关系、记忆或意象的关联与重复差异，积累可以改变人物、关系或观众理解，不强制产生最终抉择。非线性表达区分事件时间与呈现逻辑，保留必要定位线索；不因时序重组自动判错。

情绪变化要能回到正文中的关系、经历或信息/感知变化；前一段的余波如何进入后一段，应从正文读出。艺术方法要在展开过程中产生意义，不能只在摘要中标“梦境、诗意”。结尾回指前文铺垫或母题，开放解释不等于漏写必要过程；不以音乐、字幕或未来生成效果替尚未成立的文本补情绪。

完成后仅根据正文复述故事/体验路径，再与蓝图、人物系统和 Sequence Map 对照，定位跳跃、回应缺口、重复和未兑现处并修正。Treatment Review 用 PASS / REVISE / NOT_EVALUATED 记录 Scope & Evidence、Findings & Resolution 和审阅来源；自检标 SELF-AUDIT。PASS 只覆盖本次完整 Treatment，不表示独立冷读、用户批准或后续 G2 全部通过。Readiness READY 只能在本次正文与映射完整、审阅通过后填写。

## 4. 题材校准

### 历史 / 真实

- 用 `Claim ID` 支撑关键行动。
- 把“史料明确记载”“基于制度与空间的合理重建”“纯创作连接”分别标示。
- 人物系统已授权的 Dramatized Choices 单列为 CREATIVE_PROPOSAL，事实未知仍为 UNKNOWN；不扩大授权范围，也不把重构当史料。
- 不以结果倒推人物目的；不把群体写成同一种心理。
- 关键命令链、时间顺序或空间位置缺失且直接影响因果时，优先 Research Return。

### 人文 / 情感

- 允许没有反派、秘密和灾难。
- 给所有参与者独立生活边界，避免一人成为另一人的成长道具。
- 结局可以是一项小范围、不可逆且由本人同意的行为调整。
- 结尾也可体现习惯继续、关系重估或观众理解变化，不强制不可逆选择或成长。
- 避免自动使用拆迁、绝症、死亡、失散亲人、最后营业日等快捷装置。

### 科学 / 科幻

- 现实知识、合理推演和原创规则分层。
- 规则需要通过行动后果被理解，不用说明性独白替代。
- 不在 Treatment 中选择生成模型来掩盖规则不清。

### 神话 / 修仙 / 幻想

- 世界规则应影响行动、关系、理解或体验；检查无作用的设定展示，不为了证明规则而强加代价，也不擅删用户锁定内容。
- “正/邪”由行为、权利和后果体现，不由标签直接裁决。
- 禁止套用现成境界表、门派谱系、法宝、专名或标志性反转。

### 诗性 / 实验

- 继承故事蓝图的组织原则、时间逻辑、拟采用艺术方法与开放解释范围。
- 以完整散文展开意象、记忆或感知之间的联系，不做漂亮素材目录，不强制套因果与冲突升级。
- 人物可保持不变，象征性形象按其体验作用展开，不补主角式身世、目标和重大抉择。
- 抽象、梦境与象征无需证明现实发生过；对真实世界的事实声明仍保留依据与边界。

## 5. 范围继承

- `Standalone Film`: 本片内完成主要变化，不制造未授权续集钩子。
- `Prototype Unit`: 验证一个完整单元；不称为首集，不建立季弧。
- `Episodic Unit`: 当前单元独立完成；只继承已锁定的共享世界信息。
- `Serial Arc`: 写阶段起点、累积推进、适用的关键节点与结束状态；不自动拆成集数或强加不可逆事件。

发布结构 OPEN 但 Blueprint Scope 已是 Prototype Unit 时，原型可以继续。不要为了问“短片还是剧集”阻塞一次有效的原型测试。

## 6. 自检

- 叙事能否解释主要 Sequence 的因果，观察/诗性能否读出关联与体验积累？
- 人物行动、回应或维持状态是否来自人物系统，艺术方法是否有具体作用？
- 情绪递进是否来自正文，结尾是否有前文支撑？
- 正文与 Sequence Map 是否一致，是否把自检误称独立冷读？
- 是否尊重已定义的拒绝权、信息位置和道德边界？
- 是否把高风险 OPEN 项伪装成低风险假设？
- 是否增加了上游没有授权的重大悲剧或反转？
- 是否把现实推断或文学参考冒充事实？
- 是否出现任何剧本、镜头或 Prompt 语言？
- Next Stage 是否只有一个？
