# Character Development Guide

按项目模式使用相关部分，不要求所有项目采用同一种人物逻辑。

## 行为与关系审阅

先核对人物承担的故事作用与蓝图段落，再检查行为逻辑。核心人物的关注、通常策略、触发/限制和回应应能互相解释；配角只发展当前作用所需内容，象征或艺术化形象可承担感知、记忆或关系功能，不按核心主角要求补身世、外部目标和成长弧。真实人物与非虚构观察不能仅以象征功能代替其真实处境。

性格词要能指导后续选择，例如“回避冲突”说明其处理分歧的倾向与改变策略的条件；不在此处写具体情节、对白、手势或微表情。没有行动权限、等待或保持习惯可以成立，不靠给每个人添加秘密和冲突制造深度。

关键关系分开看双方：各自关心什么、怎样理解或误读对方、为何回应或不回应、这种差异怎样影响选择或关系感受。不得让配角只在主角需要时改变想法；真实人物未知的理解和需求保持 UNKNOWN，已授权的戏剧化选择另行标记。

变化可以发生于人物、关系或观众理解；人物坚持不变也可以有明确作用。Change / Stability Basis 说明变化条件、维持依据、蓝图关联与仍然开放的结果，不机械要求克服缺陷、觉醒、创伤揭露或成长。

按 Role ID、Relationship 和 Movement 记录审阅证据：行为能否从当前信息、关注与限制理解；双方回应是否一致；变化或稳定是否有支撑；事实与重构是否分开。现有 Decision Register 的 Character Review 使用 READY / REVISE / PARTIAL，注明范围、自检来源和阻断/延期项。READY 只覆盖完整审阅的人物范围，PARTIAL 不代表整部人物系统完成；无依据不得宣称独立审阅或用户批准。

## Fiction / Fantasy

- 先让世界规则具体落在角色的责任、收益和代价上，再设计身世。
- 区分 `Cultural Grounding`、`Type Convention` 与 `Original Proposal`。
- 正邪、门派、阶层和血统只是社会标签，不能替代人物的行为判断。
- 避免特殊血脉、失忆、灭门、隐藏天才、师徒背叛等默认捷径；确有必要时说明其不可替代的因果作用与相似性风险。

## Historical / Real Person

- 使用 `EVIDENCE_LIMITED`，人物卡优先记录身份、可核实行动、制度权限、所处压力和后果。
- 区分可核实行为、同时代评价、后世解释与创作推断。
- 没有日记、书信、记录或可靠证词时，不把内心动机写成事实。
- `External Objective / Inner Need / Fear / Worldview` 没有证据时写 `UNKNOWN / 不作断言`；不因字段存在就补写。
- 项目已明确允许戏剧化重构时，继承授权来源和适用人物/字段，把拟采用心理与行为放入独立 Dramatized Choices，使用 CREATIVE_PROPOSAL；事实字段未知仍为 UNKNOWN，不能用“合理”冒充史料。仅泛称“电影感、艺术化”不自动授权改变真实关系、历史结果或已锁定结局。
- 复合人物必须明确标记，不能让其承担真实人物未做过的关键行为。
- 重构与已锁定身份、关系、事实承诺或结局冲突时先返回项目/故事决定；事实依据不足则返回研究，不以添加虚构内容掩盖缺口。

## Social / Humanistic

- 对非虚构观察使用 `OBSERVATIONAL`；若只是概念测试而非真实被摄者，明确标成虚构测试角色。
- 不把职业、疾病、地域、贫困或身份直接当作性格。
- 观察对象可以保持不解释自己；行动、习惯和关系比强行设置人物弧更重要。
- 受影响者必须有与主角目标无关的生活、判断或拒绝权。
- 情绪来自时间、重复、距离与关系变化也可以成立，不要求创伤揭露、争吵、死亡或救赎。

## Science Fiction

- 把科学条件与人物相信的解释分开。
- 科学设定只限制可能行动，不自动决定人物价值观。
- 不用技术说明替代人物选择；关键行为必须来自责任、欲望或关系压力。

## Ensemble / Community

- 群像不等于平均分配篇幅。明确谁提供视角、谁制造改变、谁承担后果。
- 共同体可作为主体，但仍需记录内部差异和决策机制，不能写成同一种声音。
- 合并功能时检查信息来源、关系压力和行动能力是否仍然成立。

## Voice Without Dialogue

可记录：句子长短倾向、是否先讲规则或先讲感受、是否直接回答、在压力下更沉默还是更精确、如何掩饰不确定性。

不可记录：成段示范对白、标志性台词、模仿现有作者文风、可直接放入剧本的独白。

## Readiness for Treatment

只有在以下条件成立时路由到 `Treatment Development`：

- 人物有符合其故事作用的行为、回应或观察依据，不以能力条目数量达标；真实人物和观察主体的事实描述有依据，已授权重构与事实层分开；
- 关键关系的双方回应、陪伴或有意无回应有可理解的依据，并支持故事选择、体验或关系变化；
- 信息差与误解不会依赖编剧强行隐瞒；
- 人物变化范围与 Story Blueprint 的结局开放度兼容；
- 制作规模可控且连续性锚点明确。
- 变化或保持不变均能回指蓝图作用；Character Review 的当前范围为 READY，未解决项不影响本次交接。局部完成保持 PARTIAL，不能冒充完整系统；问题涉及上游时按责任返回。
