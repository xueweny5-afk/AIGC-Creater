# Video Prompt Patterns

视频 Prompt 描述输入画面之后发生的变化。它不能用长篇外观描述覆盖动作，也不能把抽象情绪直接当作表演。

以下是按需范式，须继承上游观看立场、构图、注意力、必要保持与结束状态，不强制每镜新触发、转折、微表情或固定摄影机。持续劳动、等待、观察可以写 Continuation Basis / HOLD Purpose。Presentation Mode / Artistic Rule IDs 的非物理变化独立于真实空气，不强制写实；具体控制未核实则待验证，不能靠自然语言保证。

## Core sequence

```text
reference declaration
→ one visible dramatic intention
→ current start state
→ trigger
→ chronological body / gaze / breath / hand action
→ one motivated camera event or explicit HOLD
→ environment and material response
→ sound / dialogue timing when supported
→ observable end state
→ continuity locks and exclusions
```

## Observable performance compiler

把“悲伤、紧张、怀念、释然”等结果词拆成：

1. **进入状态：** 姿态、重心、视线目标、手部接触和呼吸状态。
2. **触发：** 一句画外音、看见某物、接触发生、环境声停止等具体事件。
3. **变化节点：** 视线何时偏移、呼吸在哪里停顿、手是否先收紧再松开、声音是否延迟。
4. **退出状态：** 可供下一镜继承的姿态、视线、物件位置和未完成意图。

项目存在 `film-micro-performance-designer` 产出的 Performance Beat 时，以其基线、触发、主要/支持通道、HOLD 层和结束状态为母版；Prompt 只压缩当前 Clip 可见节点，不把表情词典或新的心理解释加回去。

示例骨架：

```text
人物起初正面安静站立，双手自然垂下，视线保持在画外说话者方向。听到画外提问后先停顿半拍，呼吸变浅，视线短暂落向地面，再抬回原目标；嘴角只出现很轻的克制变化，仍不立刻回答。摄影机固定，不推拉、不漂移。结束时人物保持原位，视线已重新抬起，回答尚未开始。
```

这类写法保留了教程中“画外触发—停顿—眼神变化—克制微表情”的有效机制，但不复制具体人物和对白。

### Start after the previous action

如果镜头重点是人物反应，让主要劳动或移动在开镜时已经暂停：人物已停下手里的活、手仍扶着道具、身体保留刚完成动作后的呼吸和重心。这样把有限时长留给触发和反应，也避免模型同时生成复杂劳动、转身、听见、回忆和回答。

### Delayed response and withheld completion

触发后先保留可观察的延迟，再决定是否完成语言或动作。`不立即回答`、`手停在接触前`、`视线抬回但尚未开口`都可以成为明确 End State。未完成不是含糊；它必须说明什么已经变化、什么被有意留给下一镜。

### Attention budget

表演是主任务时，按 Motion 的时间段安排主次与摄影机配合；HOLD 是有效选择，已批准的同步运镜也可保留。不能自动将摄影机改固定。背景支持主体，不依靠浅景深掩盖关系；艺术层按批准的注意力作用编译。

### Positive lock and mirrored exclusion

高风险字段先写正向目标，再用少量排除项保护，例如“年轻状态，保留劳动晒痕”对应“不出现老年皱纹”；“完全固定机位”对应“不推、不拉、不摇、不移、不漂浮”。排除项必须镜像当前正向合同，不能成为与任务无关的通用词表。

## Timeline use

单动作短镜头使用顺序句即可。仅在多阶段动作、对白同步、剪辑或声音事件确实需要时写时间段：

```text
0.0–1.2s HOLD current state
1.2–2.5s trigger and first reaction
2.5–4.0s primary action
4.0–5.0s settle into end state
```

时间段是意图分配，不代表模型具备逐帧确定性。各段不得重叠争夺主体，也不得超过生成时长。

### 多阶段视频：固定规则与注意力顺序

先锁定人物身份、产品结构、场景拓扑、色彩关系、世界光源和呈现规则，再按段落描述变化。固定项不必在每段重复，变化必须有动作、观察位置或已批准艺术规则作为依据。

先用一句话串起观众的观看顺序，例如“眼睛吸引注意 → 展开人物 → 产品使用 → 人物与产品共同呈现 → 产品收尾”。这是香水广告的任务示例，不是所有视频的固定叙事；只继承当前上游已批准的顺序，不擅自补齐喷洒、转脸、产品展示等事件。

多阶段段落的内部检查骨架：

```text
时间范围与主要观看对象
→ 继承的起始状态
→ 主要动作或持续保持
→ 摄影机路径与焦点变化（分别说明）
→ 从属的环境、材质和表演响应
→ 可供下一段继承的结束状态
```

主要动作与可见结果相连，例如“按压喷头一次，喷雾朝锁骨喷出，被侧后方光源照亮”。配角动作和环境响应不能争夺主要注意；不把摄影机运动、拉焦、变焦混写成同一个“推进”。时间码是意图安排，不是精确执行保证；最终正文仍按模型入口压缩。

### 一镜到底的连续性检查

一镜到底要求空间与状态持续可追踪，不能仅在负向词中写“无剪辑”。编译前检查：

1. **物件完整流转。** 产品在哪里、由哪只手握持、盖是否取下、喷口朝向哪里、何时接触台面、手何时松开。由手持变为独立陈列必须有可连接的放置过程；缺口返回上游或单列内容提案，不能静默添加动作。
2. **摄影机路径成立。** 说明起点、路径、终点与沿途空间；单条连续镜头不并列要求换用不同定焦镜头。多焦段作为备选时明确互斥；若采用变焦，单独说明，不冒充换镜。
3. **光源坐标明确。** 区分世界中的固定光源与画面中的左、右方向。环绕可以改变受光投影和逆光关系，不代表灯自动换位；人物、道具、阴影和反射应共同响应。亮部光晕还取决于光源、遮挡与观察方向，不能只写“转到阳光下”。
4. **高光和遮挡前后接得上。** 泛白、镜头炫光或前景遮挡不授权人物、持瓶手、产品和空间跳变。若创意实际使用隐藏剪辑，须如实标注，与用户严格无剪辑要求存在冲突时返回确认。
5. **景深与清晰目标相容。** 人脸和产品需要同时清晰时，检查二者距离关系及景深意图；不能一边要求极浅景深，一边要求任意前后距离均清晰。参数不能替代可见结果检查。
6. **时间与速度闭合。** 总时长包含必要动作、过渡与末尾停留；局部慢动作需要说明哪些对象或时段变慢，不能让无支撑水滴凭空持续悬停。帧率、变速和逐段控制按实际入口核实，未核实不写成已支持。

### 图生视频承接与交付检查

- 输入图已经承担的人物外观、瓶型和初始构图不整段重画；明确需要保持的锚点，正文重点写输入状态之后的变化。
- 从眼睛极特写拉至人物、完整产品或台面时，检查新显露区域是否有参考依据。未展示的区域标为待补参考或待验证，不声称一张首帧已锁定所有结构；仅内容交付仍可给出完整文字草稿。
- 把拍摄参数、创意时间线、平台参数和验收条件分开。长篇导演描述不等于可直接一次生成的已验证执行包；不支持目标时长或连续性控制时显式记录，不擅自用分段剪辑替代用户要求的一镜到底。
- 清理翻译歧义：`flacon` 是香水瓶，香水语境的 `juice` 是香水液体，`caustics` 是焦散或折射光纹；`bloom` 依语境译为高光晕开等成像效果。校正单位、时间码和指代，不把误译带进模型正文。

以上补充由用户提供的夜间厨房场景与30秒香水广告文本讨论归纳，属于写作与文本审查方法；未进行模型生成验证，不证明某种长度、焦段或时间线写法具有通用效果。

## Motion hierarchy

每个 Clip 只保留一个主要人物动作和一个主要摄影机行为。衣服、头发、灰尘、蒸汽、背景人物等从属于主动作，并由风、热量、接触或空间活动驱动。无动机时写 `HOLD`，不要用眨眼、喘息、持续飘发填满画面。

## I2V and start/end behavior

- I2V 不重述首帧已清楚呈现的脸、服装和构图，重点描述“接下来”。
- MID/END 作 CURRENT START 从当前阶段后继续；END 作 TARGET END 锁目标，不作为开场重播。REFERENCE ONLY 不定义时间零点。
- START_END 核实当前入口支持，继承 Motion 的物理/艺术连接方案与保持项；静态或文字通过不代表中间运动已验证，不能连接则返回责任上游。
- 多参考输入先声明各自职责与禁止覆盖，再写动作。

## Camera and sound

运镜必须有触发、路径、速度变化、终点和停止理由；固定镜头明确写 locked/static 并排除漂移。声音只有在当前模型支持时进入执行 Prompt，否则记录为后期/音频阶段的 `UNSUPPORTED` 去向。

故事含义可以在工作底稿中用一句诗性总结帮助人审查，但最终模型 Prompt 不能依赖“微笑里藏着后来很多故事”这类不可直接观察的句子。必须先由停顿、视线、嘴角、是否回答和镜头停留承载；诗性句是否保留由模型 Profile 和删词测试决定。
