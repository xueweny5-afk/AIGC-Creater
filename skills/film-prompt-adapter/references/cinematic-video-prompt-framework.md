# Cinematic Video Prompt Fixed Framework

这是一份完整性工作台，不是要求模型照单全收的长提示词。先用固定框架防止信息遗漏，再依据目标模型、输入模式和镜头风险压缩成可执行 Prompt。

各段是按需检查维度，不强制主冲突、触发转折、微动作、三层空间或现实摄影材质。继承批准的观看立场、构图、Continuation/HOLD 和艺术规则；物理作用只约束物理层，非物理层按 Artistic Rule 执行。图片描述单一瞬间，视频区分 CURRENT START / TARGET END / REFERENCE ONLY。任何创作选择以源合同授权为限，不从框架示例发明动作。反向审核检查完整输入组合；内容草稿列待补，不冒称可执行或模型通过。

## Four source classes

每个字段先标来源权限，避免“忠于原作”变成保守，也避免大胆创作破坏连续性：

- `LOCKED`：用户决定、批准合同、身份、时代、关键道具、故事结果和连续性事实；不得改写。
- `DERIVED`：可从批准信息直接推导的可见细节，例如湿地反光、风对布料的响应、上一镜动作余势；写明推导依据。
- `CREATIVE`：当前创作阶段拥有裁量权的选择，例如视点、前景遮挡、留白、镜头节奏、声音桥、意象和转场。默认允许大胆但连贯的创作，不必把一切降成最安全的普通覆盖。
- `PROPOSAL`：会改变已批准镜头、角色动机、空间事实、主要动作或结局的创作提案；单列影响，回到责任上游确认后再编译。

`CREATIVE` 不是“随便加词”。每项都要回答：它让观众更清楚地感到什么、为何适合这个时刻、是否造成新的生成或连续性风险。

## Thirteen-part authoring frame

### 1. 输入解析与参考锚定

提取时长、画幅、时代、地点、人物、事件、对白、天气、时间、风格、参考图、必须出现和禁止内容。逐张参考图登记用途、允许影响和禁止继承，并区分：

- 硬锚点：身份、五官、体型、服装、关键道具、时代和空间拓扑；
- 软参考：色调、构图、景深、颗粒、观看距离等可随剧情调整的表达；
- 排除项：参考中偶然出现但不应继承的人物、文字、水印、物体和错误细节。

冲突时按字段给优先级，不用“参考所有图片”代替分工。

### 2. 整体概念与叙事命题

用短段落说明：这段视频发生什么、唯一主冲突或情感事件是什么、观众最终应读到什么。优先写可见的事件结构，不用背景百科或空泛的“史诗、电影感”代替。

### 3. 动态描述

把剧本变成可见事件：此前发生了什么、当前主体在做什么、触发是什么、人物和环境如何响应、最终停在什么状态。动作遵守重量、惯性、接触和材料反应；环境变化必须有风、雨、水、热、烟尘、光源或人物行为等驱动。

### 4. 画面质感与摄影意图

描述成像取向、动态模糊、景深、颗粒、肤质和材料解析。摄影机、焦段、快门、曝光、白平衡等只有在已知且确实改变结果时才写；禁止用虚假精确参数冒充电影感。

### 5. 镜头语言

逐镜说明景别、角度、机位、主体关系、运动起点、触发、路径、终点与切点。一个镜头只保留一个主要叙事任务和一个主要摄影机行为。大胆创作优先体现在有意义的视点、遮挡、空间揭示、节奏反差和动作匹配，不等同于更多环绕、航拍和高速变焦。

### 6. 场景设定

明确时代、地点、空间结构、前中后景、建筑/陈设、天气、地面状态、环境活动与可见生活痕迹。场景不是背景壁纸，要参与叙事，但不能抢走主要注意。

### 7. 色彩与风格

定义主色、辅色、冷暖关系、饱和度、对比度、肤色和关键材质的颜色响应；同时列出不允许漂移到的商业调色、游戏 CG、过度 HDR 等方向。风格描述服务故事，不把影片名或通用“高级感”当作完成品。

### 8. 光影设计

逐空间或逐镜说明主光来源和方向、辅光/环境反射、色温、明暗关系、人物受光、材质高光、阴影保留和变化触发。同一场景保持世界光源连续；只有人物移动、遮挡、天气、门窗或时间变化才能改变画面投影。

### 9. 构图与空间层次

说明视觉中心、前中后景、负空间、遮挡、视线方向、群体密度、轴线和画幅安全区。构图要让权力关系、孤立、压迫、距离或亲密可见；不是把主体永远放在中心。

### 10. 情绪与可观察表演

把抽象情绪改写为姿态、重心、视线、呼吸、停顿、手与道具接触、微表情和退出状态。先写触发，再写延迟和变化；克制、未回答、未完成动作也必须有明确结束状态。

### 11. 分镜时间线与前后衔接

按最终时长拆分段落，记录每段的时间范围、主事件、镜头行为、声音落点和结束状态。继承上一段余势，并为下一段留下可连接的姿态、方向、道具、光线和环境状态；总时长必须闭合。

### 12. 声音设计

区分对白/画外音、环境声、动作同步声、声音桥、音乐和刻意静默。声音必须说明来源、进入和退出时机及叙事作用；模型不支持音频时转入后期，不用文字 Prompt 假装已执行。

### 13. 连续性锁定、排除与终检

锁定身份、服装、人物/道具数量、空间、轴线、动作阶段、光源和状态变化；列出最少且针对性的排除项。最后做反向恢复、时间闭合、参考冲突、注意力预算和可执行性检查。

## Bold-but-coherent creativity pass

完整框架填完后，再做一次主动创作检查：

1. 找出本段最值得被记住的一个视觉或声音决定；没有则说明方案可能过于平。
2. 在未锁字段中至少比较一个常规方案与一个大胆方案；大胆方案可以改变观看位置、留白、遮挡、节奏、声音桥或意象，但不能篡改故事事实。
3. 选择能强化当前叙事命题的方案，并记录 `Creative Intent / Audience Effect / Continuity Cost / Generation Risk`。
4. 删除只为“炫技”存在、无法改变观众理解的运镜、参数和装饰性粒子。

## Compile pass

十三项先作为人类可审查合同，再按模型压缩：

- 已由参考图或外部参数可靠承担的信息不重复；
- 单帧任务删除时间过程；
- I2V 从输入帧之后写变化，不重画首帧；
- 不支持的音频、负向词、时间控制转入外部参数或后期；
- 只保留会造成可观察差异的词；
- 十三项回执必须完整，但最终 Prompt 不必有十三个标题。
