# Asset Prompt Patterns

先读取资产合同的用途、Required Views、Presentation Mode 和已批准 Artistic Rule；下列正脸、六视图、材料细节只是按需选用的编译范式，不是每项资产的必做清单。只编译 REQUIRED 的视图/状态；DEFERRED 与 NOT_REQUIRED 不触发生成。中性呈现指便于辨认和比较，须保留已批准的绘画、抽象或非写实规则，不自动改成真实皮肤和摄影材质。仅背影、剪影等用途使用相应 Canonical Anchor，未验证的脸部不得据此宣称已锁定。

资产 Prompt 的目标是建立可跨镜复用的连续性基准，不是生成一张完成镜头。通用顺序：

```text
asset purpose and ID
→ derivation parent / reference bindings
→ locked identity or geometry
→ required view / state
→ material, construction and scale evidence
→ neutral presentation
→ must preserve / must avoid
```

## Character identity

### Canon face close-up

优先锁定：年龄范围、头面比例、稳定身份标记、皮肤局部差异、发际线/眉眼/鼻口关系。使用平视、正面、无遮挡、中性表情、均匀光线和简单背景。禁止戏剧性妆光、极端焦段透视、头发遮脸、强表情和服装抢占身份判断。

### Head angles and full-body six views

所需角度从覆盖当前用途的已批准 Canonical Anchor 派生，并绑定确切母版版本。每条只改变观察角度，保持该用途已锁定的身份与体态特征不变。合同要求完整六视图时使用正面、左前 45°、左侧、背面、右侧、右前 45°；独立源图优先，多格图仅用于审阅。

可复制骨架：

```text
以 [IDENTITY reference] 为唯一人物身份。生成 [view] 的 [head/full-body] 资产图；保持 [locked face/body traits] 完全一致，只改变观察角度。人物采用 [neutral posture/expression]，全身比例和手足清楚，均匀中性光，简单无干扰背景。不得改变年龄、脸型、体态、发型或身份标记；不得添加镜头级表演、道具、文字、水印或额外人物。
```

## Costume and makeup/hair

服装独立于人物身份编译，至少描述：轮廓、层级、版型、材料结构、缝线/扣合、垂坠或硬挺、光泽、磨损位置、配件和穿戴状态。妆发单独记录轮廓、分区、固定方式、质地和状态变化。不要让“古装、精致、破旧”等标签替代结构。

组合定妆必须声明参考职责：人物图只负责身份与体态；服装图负责结构和材料；妆发图负责造型；合体结果不得反向改写任何源资产。

## Location and environment

先做语义校准：明确这是哪个地点、什么时间/事件、哪些人正在怎样使用空间，以及观众需要读到的生活关系。不要从“夜晚旧屋、温馨客厅、年代感农村”等泛化标签直接开始。

先生成空间结构，再生成质感状态：

1. `TOPOLOGY`：出入口、固定锚点、尺度、主要工作面和正反方向关系。
2. `SURFACE`：墙地顶、木/石/金属/织物的接缝、边缘、老化和受光反应。
3. `SET DRESSING`：前中后景陈设密度、生活/劳动痕迹、物件所有者与使用逻辑。
4. `ATMOSPHERE`：天气、湿度、尘、烟、蒸汽或风；仅在有物理来源时加入。

环境示例应写成“旧木桌边缘因多年擦拭略发亮，墙角近地面有局部潮痕”，不要写“超真实旧房、电影感细节丰富”。

生活场景还要规定人物不是为镜头摆拍：每个人有不同但相容的任务，位置和动作来自空间功能；避免整齐排队、同时看镜头和装饰平均铺满。背景陈设只保留能证明时代、使用者、活动和空间关系的少量高辨识信息。

### 场景图片的可见事实骨架

按需采用以下顺序，不要求逐项填满，也不将某个示例的机位、年代或风格设为默认值：

```text
场景身份、用途与时段
→ 观察位置、朝向、高度及画面边界
→ 出入口、固定布局、尺度与通行关系
→ 少量证明空间功能的核心陈设
→ 与使用者及活动相符的材料状态和使用痕迹
→ 光源、照亮区域、遮挡阴影、材质反射与内外曝光关系
→ 成像取向、画幅及针对性排除项
```

- **先位置，后物件。** “左墙水槽、右侧灶台、尽头窗户”比罗列三件物品更能说明空间。写明左右是相对当前机位，或使用已批准平面图的固定方向；反打时不能把画面左右当成世界坐标。
- **观察视图不等于完整场景。** 单张门口视图只说明当前可见范围；跨镜复用还要依据拓扑合同固定门窗、通道、尺度与关键陈设。不要把一张气氛图称为已锁定完整空间的资产。
- **细节说明用途。** 抹布、水渍、磨损或整理方式应与活动相符，同时保留正常操作与行走空间；整洁、新旧程度按场景设定，不默认脏乱。资产基准图不为增加生活感擅自加入人物或镜头级动作。
- **光照写成因果。** 先写光源，再写受光、遮挡、反射与曝光结果；玻璃倒影、金属高光和窗外亮度应服从同一照明条件。摄影或真实材质要求仅用于相应呈现模式，幻想场景的超现实部分遵守批准艺术规则。
- **焦段不能代替构图。** 需要时补充焦段意图，但必须写清观察位置与画面关系；画幅同时交给平台实际参数，不靠文字承诺生效。

快速反查：读者能否指出“从哪里看、物件如何相连、谁怎样使用、光从哪里来”？只有“真实、精致、电影感”时，应回到可见事实补写。

## Props and material plates

道具 Prompt 包含真实尺度、结构、可见面、材料组合、握持/开启方式、磨损发生位置和当前状态。Material Detail Plate 必须说明材料在近景尺度下的纹理、边缘、连接方式与光照响应；避免均匀做旧、无来源划痕和整面相同反光。

## Asset acceptance clues

生成前把以下项目写成验收点而非继续堆进 Prompt：身份是否一致、角度是否正确、结构是否可制造、材料是否局部变化、文字/品牌是否干净、拓扑是否与批准视图相容。验收标准和生成语言应分离。
